Bender regular is the same 52,536-byte face used by the existing game font resource (`/fonts/bender-regular.otf`, originally supplied by TimWangZi/The-font-of-Arknights). This small boot copy lets the lobby room counter preload its digits without waiting for the optional resource downloader. The renderer's numeric family and this face have the same glyphs. It is not a new font design.
