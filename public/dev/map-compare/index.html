기존 맵과 원본 v0.2.5 비교

동일한 씬 자료·카메라·해상도(1280×800)로 촬영했습니다. 슬라이더를 움직여 같은 위치의 색상·재질·배경을 비교하세요.

기존 추가 구현
원본 v0.2.5

비교 결과

  • 11개 맵의 씬·조명 번들이 모두 같습니다(MD5 일치). 맵 원본의 차이가 아니라 추출·구역 선택·렌더링 방식의 차이입니다.
  • 기존 구현은 반사·노멀·발광 등 재질 표현과 별도 조명 보정, 보스 배경/미리보기 보완, 8인 연결 맵을 포함합니다.
  • v0.2.5는 바이너리 정점 데이터와 씬 구역 구분, 베이크된 그림자를 사용합니다. 재질의 반사·노멀 표현은 더 단순합니다.
  • 원본은 일부 구역에서 더 적은 렌더링 호출을 사용합니다. 배경 구성도 다르므로 실제 FPS나 전체 성능의 우열로 해석하면 안 됩니다.
  • 이 비교는 게임 구현을 전환하지 않습니다. 현재 로컬 서버의 맵은 기존 구현을 유지합니다.
비교용 원본 렌더러: v0.2.5의 BoardScene/재질 코드. 기존 렌더러: 한국어판의 네이티브 맵 및 배경 보완 코드. 8인 비교는 원본의 직접 지원 범위에 포함되지 않습니다.
