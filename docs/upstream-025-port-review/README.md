# 원본 v0.2.5 분리 로컬 병합

- 원본: `sganggs/Stronghold-Protocol`, `v0.2.5`, `cf7a9400270d5aa79b2e601e405dab782e25f120`.
- 한국어판 기준 커밋: `cc80a380`와 기존 작업 트리의 미커밋 변경사항.
- 체크아웃: `/workspace/Stronghold-Protocol_025_Local`.
- v0.2.4가 이미 기능별로 이식되어 있어, 원본 v0.2.4→v0.2.5의 221개 파일 변경을 세 방향으로 통합했다. 원본 전체 이력을 단순 병합하면 이미 반영된 과거 수정까지 충돌하므로 기준 릴리스의 변경분을 사용했다.
- 기존 체크아웃의 변경사항과 미추적 추가 파일을 복사해 보존했다. 커밋·푸시·운영 배포는 수행하지 않았다.

## 실행 구현과의 조정

| 영역 | 통합 방식 |
| --- | --- |
| Match / PlayerState / Battle | 원본의 분리 모듈 변경을 한국어판의 실제 실행 코드에도 적용했다. 랜덤 보스 짝을 독립 시드로 고정하고 공개 정보와 카메라에 연결했다. |
| 상점 | 이미 표시된 오퍼레이터의 구매·보상이 재고 소진 후에도 가능하다. 보유 수량은 재고에 반영한다. 재고와 무관한 지급은 한국어판의 명시적 면제 규칙을 유지한다. |
| Touch | 선택한 참가자가 탈락해도 팀 지급을 유지하고, 중복 전략의 스탯 증가와 8인 전장 배치를 보존한다. 준비 단계 의료 오브젝트는 조사할 수 있다. |
| 기계술사 / 스킬 | 록록의 이탈한 목표 추적, 본체와 드론의 별도 피해, 원본 수정 대상 키트 및 확대된 스킬 범위 발동을 활성 레지스트리에 연결했다. 원본 파일의 정확한 대상 목록은 아래 변경 기록을 참조한다. |
| 혼 | 발사 시 근접/원거리 판정을 고정해 날아가는 포탄의 광역 피해가 이후 목표 변경으로 달라지지 않게 한다. |
| 적 / 좌표 | 재생 후 선택 불가 상태, 경계 안쪽 보정과 동률 짝수 반올림을 적용한다. 8인 맵의 가변 행·열 처리를 보존한다. 투석기의 한국어판 연속 발사 구현을 유지한다. |
| 협력방어 인계 | 개막 효과를 구성한 뒤 이전 전장의 실제 HP 비율과 SP를 복원한다. 낮은 HP 비율과 소수 HP도 유지한다. |
| 렌더러 | 새로운 원본 씬 로더·재질·추출 기능을 추가하되 기존 네이티브 맵, 8인 연결 맵, 미리보기 배경 보완, 분할 사전 로딩과 레이아웃 캐시를 유지한다. |
| 피해 표시 | 기존 합산·모두·기본 표시와 피해 출처 메타데이터를 유지한다. 원본 표시 옵션은 별도로 선택할 수 있고 원본의 붉은 숫자/MISS 판정을 사용한다. 기존 무적 0·방어막 표시 규칙을 유지하므로 원본의 순수 튜플 이벤트 테스트와 표현 형식은 다르다. |
| UI / 설정 | 갱신 요청 중 중복 입력 방지, 불러오기 시 데이터 누락 보호, 신규 번역을 통합한다. 한국어판 선발·프리셋·실험실·채팅·커스텀 설정을 유지한다. |

원본의 변경 기록 전체: [docs/history/0.2.5.md](../history/0.2.5.md).

## 검증

- 원본 수정 및 한국어판 커스텀 기능 회귀 테스트 259개 통과, 실패·스킵 0개.
- 원본 테스트 중 즉시 배치/스킬 발동을 가정하는 테스트는 한국어판의 실제 배치·스킬·공격 모션 시간이 지난 뒤 판정하도록 대기 조건만 조정했다. 피해·목표·중첩 관련 검증 조건은 유지했다.
- 실제 Chromium에서 메인, 오퍼레이터 설정, 단독 준비/전투 및 실험실 설정/준비/전투 화면을 검증했다. 페이지 오류와 시뮬레이션 오류 기록은 비어 있었다.
- 외부 HTTPS 터널의 상태 확인과 HTTP 전송 경로를 검증했다. 브라우저 QA의 외부 연결은 TLS를 정상 검증하는 Node 중계 경로를 통해 확인한다.
- 모든 원본 테스트를 실행한 것은 아니다. 버전/문서 스냅샷과 원본 고유 이벤트 형식 테스트는 한국어판의 메타데이터와 표현 규칙이 다르다.

## 다시 실행

```bash
cd /workspace/Stronghold-Protocol_025_Local
npm_config_cache=/tmp/stronghold025-npm-cache npm ci
STRONGHOLD_PREVIEW_PORT=3031 NODE_USE_ENV_PROXY=1 node scripts/start-leithanien-local.mjs
```

운영 데이터는 이 체크아웃의 `.cache/leithanien-data`에 독립적으로 저장되어 있다. 기존 이미지 다운로드 캐시는 읽기/재사용을 위한 공유 경로가 일부 포함되어 있다. 새 인스턴스로 이동할 때에는 해당 캐시를 함께 보존하거나 리소스를 다시 다운로드해야 한다.
