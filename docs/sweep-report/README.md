## 구현

- 기존 원본 리포트의 3개 탭과 좌측 상세/우측 목록 구성 유지: 맹약(활성 필요 인원·단계·효과·소속 오퍼레이터), 전략(초기 HP·효과·모드·관련 맹약), 적 자료(리더·호위·전술 특훈·적 도감).
- 수치와 설명은 외부 위키로 덮어쓰지 않고 현재 운영용 게임 데이터에서 읽는다. 사용자가 수정한 조건과 커스텀 콘텐츠를 유지한다.
- 증강 탭: 실제 `createAugmentCatalog`를 모든 증강 라운드에 대해 실행하고 ID로 합친다. 현재 총 250종(아군 200·적 50), 각 증강의 이름·아이콘·등급·대상·효과·등장 라운드 표시. 이름/효과 검색 제공. 게임의 밴이나 미보유 오퍼레이터 설정으로 도감 목록을 숨기지 않는다.
- 우르수스·라이타니엔: 각각 소속 오퍼레이터 10명, 전용 전략 카셰이·위치킹, 일반·승급 맹약 장비 2개(은총·악보 제외), 관련 증강 연결. 우르수스에는 제국 드론 설명도 표시한다.
- 로비 기존 통계 자리 → 아이콘이 있는 S.W.E.E.P. 리포트 버튼. 닉네임 박스 → 통계 진입 버튼, 내부 우측에 막대그래프 아이콘. 키보드 Enter로도 진입 가능.
- 리포트 JS/CSS는 버튼 클릭 시 지연 로딩. 리포트 탭/항목을 바꾸면 해당 목록/상세의 스크롤을 처음으로 돌린다.
- 리포트·적 도감의 누락된 한국어 UI 문구 보완.

## 실제 화면 및 검증

실제 로비에서 연 리포트의 캡처이며, 별도 모형 화면이 아니다. 대용량 리소스 다운로드와 서비스 워커는 UI 검사에서 분리했고, 화면에 필요한 이미지는 준비된 운영용 파일 및 미러에서 받은 파일을 사용했다.
