# 중국판 누락 스킨·마코토 추출

현재 게임에 구현된 219명과 중국 공식 스킨 목록을 대조했다. [누락 목록](missing-skins.json):

| 오퍼레이터 | 공식 스킨 이름 | 누락 |
|---|---|---|
| 디아만테 | 斜照 | 선택 목록·모델 |
| 베이스라인 | 夜空星芒 | 선택 목록·모델 |
| 체르니 | 荒野寻音 | 선택 목록·모델 |
| 슈 | 源远流长 | 선택 목록·모델·FX 연결 자료 |
| 블레이즈 디 이그나이팅 스파크 | 夜行烛火 | 선택 목록·모델·FX 연결 자료 |
| 스와이어 디 엘리건트 위트 | 盛世之象 | 선택 목록·모델·FX 연결 자료 |

앞의 3종은 이미 스킨 FX가 있어도 모델 다운로드/선택 목록이 빠져 있었다. FX 추출 완료 목록만 보고 스킨 전체를 완료로 처리하면 찾을 수 없는 누락이었다. 마지막 3종은 중국 공식 최신 목록에 있으므로, 설치된 클라이언트가 해당 스킨을 포함하지 않으면 미검출로 보고된다.

## 실행

새 ZIP을 기존 **중국판 추출 도구 폴더**(`.venv`, `work`가 있는 곳)에 압축 해제하고 아래 명령을 실행한다. 기존 클라이언트와 추출 결과를 수정하지 않는다.

```powershell
.\EXTRACT-RECOVERY.ps1
```

기본적으로 가장 최근 `work/cn-client-*` 준비 폴더를 재사용한다. **최근 게임을 업데이트했다면** 준비 폴더도 갱신해야 하므로 설치 경로를 지정한다.

```powershell
.\EXTRACT-RECOVERY.ps1 -ClientPath '중국 클라이언트 설치 폴더의 실제 경로'
```

다른 준비 폴더를 지정할 때:

```powershell
.\EXTRACT-RECOVERY.ps1 -ClientView '준비된 cn-client-폴더의 실제 전체 경로'
```

한국 클라이언트 경로를 넣으면 중국판 전용 스킨을 찾을 수 없다. Python 실행 파일을 이름 문자열로 재조합하지 않고 기존 `.venv\Scripts\python.exe`를 직접 호출한다. 기존 Python 3.12 환경을 사용한다.

## 범위

- 현재 게임에서 선택/모델/FX 연결이 누락된 스킨.
- 예외로 유키 마코토: 기본/정예화 및 이름 있는 스킨 전체. 현재 P3R 스킨 1종이 있다.
- 클레멘타인 기본 그래픽도 함께 수집해 기존 미확인 선실/소용돌이 구성요소를 추가 진단한다.
- 비활성 그래픽 노드까지 포함한 모든 Spine, 전후면/대역/페르소나, 메시/재질/텍스처, 원래 애니메이션 및 컴포넌트 필드.
- 해당 스킨의 투사체·스킬·FX 참조와 하위 구성요소, 관련 SFX, 초상화/아바타와 마코토 스킬/모듈 아이콘.
- 이미 게임에 보관된 프리팹은 동일 이름으로 재수집하지 않고 참조를 남긴다. 현재 게임에서 모델이 없거나 연결되지 않은 경우는 FX 추출 완료 여부와 별개로 수집한다.
- 마코토 외 다른 미구현 오퍼레이터는 대상이 아니다. 필요한 공용 리소스와 소환물은 함께 수집한다.

스킨 목록은 최신 CN 공식 JSON을 조회하고, 실패하면 도구의 스냅샷을 사용했음을 보고한다. `skin_table.json`을 도구 폴더에 두면 그 파일을 명시적으로 사용한다. 클라이언트 원본의 script/bundle 코드를 실행하거나 원본 파일을 변경하지 않는다.

## 결과 전달

마지막 `UPLOAD:` 뒤의 파일을 **모두** 업로드한다. 20MiB를 넘으면 `.zip.001`, `.zip.002` 등으로 자동 분할한다. 이들은 하나의 ZIP을 나눈 조각이므로 `.001`만 보내거나 각 조각을 개별 압축 해제하면 안 된다.

`PARTIAL`/오류가 나와도 만들어진 ZIP 조각, `recovery-report.json`, 실행 로그를 보존한다. 미검출 스킨·모델·SFX·참조 해석 오류를 완료로 표시하지 않는다. 원본 클라이언트에서 실제 추출하는 전체 과정은 이 환경에서 실행할 수 없으므로, 선별/교차 번들/참조 안전성 테스트와 도구 패키지 검증을 수행한 상태다.

마코토의 [PRTS·영상 구현 기준](MAKOTO-REFERENCE.md)을 결과에도 포함한다. 영상 링크는 접근 제한으로 재생 검증하지 못했다.

## 기준 영상 함께 전달하기

현재 실행 환경에서는 주신 YouTube 링크가 HTTP 403으로 열리지 않는다. 영상 파일을 `reference-video.mp4`라는 이름으로 도구 폴더에 두면 같은 추출 결과에 자동으로 포함된다. 다른 파일명/경로도 지정할 수 있다.

```powershell
.\EXTRACT-RECOVERY.ps1 -ReferenceVideo '영상 파일의 실제 전체 경로.mp4'
```

영상이 없어도 리소스 추출은 진행한다. 영상 파일을 자동 게시하거나 게임 리소스 저장소에 올리지는 않는다.

## 모델 단계만 재추출 (2026-10-24 수정)

이전 결과에서 `merge_alpha() takes 2 positional arguments but 3 were given`이 나온 경우, 수정본을 기존 도구 폴더에 덮어쓴 뒤 다음만 실행한다. 이전에 성공한 FX·오디오를 다시 추출하지 않는다.

```powershell
.\EXTRACT-RECOVERY.ps1 -ModelsOnly
```

새 `cn-skin-models-*` 결과와 `model-repair-report.json`이 생성된다. UPLOAD에 나오는 모든 분할 파일을 올린다. 일부 스킨이 클라이언트에 없으면 PARTIAL일 수 있으며 보고서로 구분한다. 원래 추출 결과는 수정하지 않는다.
