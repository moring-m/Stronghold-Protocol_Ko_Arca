상세 통계에는 총 피해, 물리·마법·고정·원소 피해, 회복, 총 받은 피해 및 유형별 받은 피해, 보호막 흡수, 처치, 공격, 스킬 사용, 재배치, 전투불능, 전투 시간이 있습니다. 피해는 실제 체력 차감량이며, 소환물은 별도 행으로 집계합니다. 최초 배치는 재배치로 세지 않고 자동 복귀도 재배치에 포함합니다. 상세 결과를 제공하지 않은 합성 전투 결과는 집계에서 제외합니다.

## 검증

- 직접 관련 회귀 테스트 160개 통과. 데겐브레허 집중 검사 5개 통과.
- 이후 보조맹약 정책·실제 재접속·통계 전송·맹약 창 재검사 13개 통과. 능력 모션·통계 재검사 22개 통과.
- 4명이 각각 160개 오퍼레이터 기록을 보내는 최대 구성의 구조와 전송 크기를 검사했습니다. 상세 통계 때문에 기존 64 KiB를 넘으므로 상한을 512 KiB로 조정했습니다. 음수 등 잘못된 통계는 거부합니다.
- 실제 브라우저에서 맹약 16개를 넣은 경우 다음 아이콘의 노출 비율 **0.5**, 스크롤바 `none`, 드래그 후 이동, 드래그 시 팝업 0회, 일반 클릭 정상, 모바일 내부 스크롤을 확인했습니다.
- 결과 통계의 팀원·라운드 선택과 모바일 표의 내부 스크롤을 검사했습니다. 설정창의 보조맹약 정책 선택도 직접 확인했습니다. 브라우저 예외는 없었습니다.
- 확장 검사 460개 중 422개 통과·38개 실패, 전투 핵심 검사 75개 중 74개 통과·1개 실패입니다. 분리한 변경 전 코드에서도 같은 실패가 재현됐으며 이번 변경으로 추가된 실패는 없습니다. 기존 공격 시점·유도/눈 효과·재접속 알림·통계 기본값·스냅샷 기대값 검사 등에 해당합니다. 따라서 전체 테스트가 통과했다고 간주하지 않습니다.
