# 수배 툴팁과 돌파

- 수배 툴팁의 이름·분류·남은 작전 횟수를 직접 번역하여 렌더링한다. 기존 강조 설명은 유지한다. 실제 EffectsList/TooltipLayer를 렌더링하고 마우스로 일반·다회차 수배 아이콘에 올려 중국어 잔여가 없는지 확인했다.
- 돌파는 개인 일반 전투에서 실제 방어 포인트 진입 시에만 즉시 HP를 차감한다. 연합방어 재진입은 추가 돌파 차감 대상이 아니다. 기존 연합방어 결과 정산과 라운드 피해 상한은 유지한다.
- 공유 HP에서는 개인에게 배분된 표시 HP 대신 공유 잔액에서 차감한 다음 팀 전체의 표시 HP를 동기화한다. 플레이어의 표시 몫보다 큰 돌파 피해도 공유 잔액에서 처리한다.
- 누적 진행 보고·최종 결과의 동일 진입은 다시 차감하지 않는다. 시간 초과나 미등장 적도 즉시 차감 대상이 아니다.
- 돌파 선택지는 4·7라운드에만 등장한다. 이전 라운드에서 획득한 돌파 효과는 유지된다. 한국어·영어·일본어·중국어 설명도 일반 전투 대상으로 맞췄다.
- 검증: 전투·증강 테스트 113개, 수배 실제 호버 및 전체 번역 테스트 5개 통과. 공유 HP 40 → 일반 전투에서 10명 진입 후 30 → 연합방어 중 추가 돌파 차감 없음 → 기존 결과 정산 10으로 20을 확인했다.
