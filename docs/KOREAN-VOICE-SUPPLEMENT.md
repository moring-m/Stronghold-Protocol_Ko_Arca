# 한국어 음성 보완

AN-EN-Tags의 음성 재생 코드가 사용하는 `PuppiizSunniiz/Arknight-voices` 저장소에서, 기존 한국어 선택이 일본어로 대체되던 음성만 보완했다. 이미 연결된 한국어 음성과 일본어 선택은 변경하지 않았다.

총 98개, 5,007,653바이트(약 4.8 MiB). 출격·접적·선택·배치·전투 스킬·전투 결과 음성이다. 음성 갤러리 전체를 추가 다운로드하지 않는다. 한국어 폴더가 없는 나머지 6명은 일본어 대체를 유지한다. 이는 해당 사이트의 파일 보유 여부이며, 공식 한국어 더빙 출시 여부 전체에 대한 판단은 아니다.

파일은 원본 저장소의 커밋 SHA에 고정하고 Git blob SHA-1과 MP3 형식을 검증한 후 내려받았다. 로컬 파일의 SHA-256과 크기도 재검사했다. Chromium에서 오퍼레이터별 1개씩 디코딩하고 AudioContext로 재생 시작이 가능한 것을 확인했다. 새로운 한국어 파일은 기존 한국어 다운로드 대상 경로를 사용하며, 보유 파일 및 일본어 경로를 삭제하지 않는다.

- `content/custom/audio/korean-voices.json`: 재생 경로·고정 출처·크기·SHA-256
- `docs/KOREAN-VOICE-SUPPLEMENT.json`: 추가된 경로와 보완 불가 항목
- `tools/import-korean-voice-supplement.mjs`: 누락 파일 수집 및 준비된 운영 목록 반영
- `tools/build-battle-voices.mjs`: 다음 목록 재생성에서도 보완 파일 유지

검증: 누락 음성만 교체·기존 한국어/일본어 유지·부분 누락 대체·중복 적용 방지 단위 테스트 통과. 재수집 실행 시 이미 보완한 파일을 다시 다운로드하지 않고 기존 기록을 유지하는 것을 확인했다. 새 음성을 포함해 다시 운영 배포해야 운영 사이트에 반영된다.
