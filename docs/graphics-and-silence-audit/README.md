# 그래픽·설정·SP·침묵 검토 (2026-10-09)

현재 로컬 변경의 검토 기록이다. 운영 서버 배포·커밋·푸시는 이 작업에 포함하지 않았다.

## 설정 구성과 실제 적용

그래픽 탭은 맵 품질 → 렌더링 해상도 → 최대 프레임 → 애니메이션 품질 → 이펙트 품질 → 그림자 → 스킬 범위 → 유닛 공격 범위 → 자동 성능 조절 → 대미지 표시 순서다.

- 맵 높음: 원본 맵. 중간: 원본 맵의 보드 해상도 제한. 낮음: 원본 환경을 로드하지 않는 단순 3D. 최하: 원본 맵과 보드 아트를 로드하지 않는 기본 2D.
- 해상도: 50 / 75 / 100 / 125 / 150 / 200%. 기기의 배율과 곱해 실제 렌더 타깃에 적용하며 최대 4배로 제한한다.
- 프레임: 30 / 60 / 120 FPS. 자동 성능 조절도 선택한 프레임의 시간 예산을 사용한다.
- 애니메이션과 이펙트의 품질은 독립 설정이다. 범위 표시 토글도 각각 독립적이다.
- 그림자는 맵 그림자와 일반 유닛 그림자에 적용한다.
- 설정은 저장되고 기존 품질 설정에서 새 항목의 기본값을 가져온다. 맵 품질을 빠르게 바꿨을 때 이전 로딩 결과가 새 선택을 덮지 않도록 처리했다.
- 소리 탭: BGM·음성·한국어/일본어 음성·효과음·음소거. 채팅 탭: 알림음·미리 듣기·적용·대기시간·음량·진영 알림. 조작·언어 탭: UI 언어와 입력 안내.

## 라플란드 검증

사용자 제보의 라플란드는 기본 모델 `char_140_whitew`와 이격 모델 `char_1038_whitw2`를 모두 검사했다. 두 모델의 알파 설정을 공통 경로로 보정하고, 클리핑이 있는 이격 모델의 중간 렌더 타깃이 화면 해상도 4배를 따르는 것을 확인했다.

[100%](lappland-100.jpg) / [200%](lappland-200.jpg)는 현재 코드의 해상도 비교이며 수정 전/후 사진이 아니다. 스킨 이름이 특정되지 않아 모든 라플란드 스킨에서 제보된 회색 경계를 재현한 것으로 주장하지 않는다. 이번 변경은 해당 증상을 만들 수 있는 공통 텍스처·해상도 경로를 보정한다.

## 침묵: 위키와 데이터 대조

능력 정보가 있는 적의 고유 이름 220개를 PRTS에서 조회했다. 오퍼레이터와 이름이 같은 보스는 적 문서로 다시 조회하고, 리다이렉트·이름 뒤 공백도 처리했다. 침묵 면역 정보가 확인되는 218개는 게임 데이터와 일치했다. [원문 링크와 대조값](wiki-silence.json)을 남겼다.

문서를 확인하지 못한 2개는 `"炎佑"`와 `“裂管之音”/“断弦之音”`이다. 이 둘을 위키 검증 완료로 세지 않았다.

침묵 면역이 없다고 모든 재능·능력이 정지하는 것은 아니다. 개별 능력의 SILENCE 분류와 서버의 `sil` 처리도 검사했다. 오염된 적 두 종류의 사망 지속 피해 장판이 누락되어 수정했다. 원석충의 사망 폭발과 침묵 면역 적의 능력은 기존 분류를 유지한다. authored enemy 전체의 SILENCE 분류와 서버 처리 일치 테스트도 통과했다. 이 대조는 모든 적의 모든 스킬을 실전 재현했다는 의미는 아니다.
