# 분노 장판 및 스파인 알파 검토

## 분노 장판

- 중앙을 가로지르던 두 장의 면을 제거하고, 각 타일 네 변(중앙에서 ±0.475칸)을 따라 위로 0.45칸 높이의 반투명 붉은 면을 배치합니다. 밝은 하단에서 상단으로 사라지는 그라데이션과 위로 이동하는 밝기 변화를 적용합니다.
- 원본 메쉬에서 표면 높이를 구하고 그 위에 배치합니다. 바닥 글로우는 윤곽선에만 표시하여 원래 지형 그림을 덮지 않습니다. 원본 맵에만 추가되고 대체 맵에는 추가하지 않습니다.
- PRTS [특수 지형](https://prts.wiki/w/特殊地形)의 [활성 원석 지형 이미지](https://media.prts.wiki/6/6d/%E7%89%B9%E6%AE%8A%E5%9C%B0%E5%BD%A2_%E6%B4%BB%E6%80%A7%E6%BA%90%E7%9F%B3.png)를 다운로드하여 확인했습니다. 이것은 원본 바닥 텍스처 참고 자료이며 **움직이는 글로우의 게임플레이 스크린샷은 아닙니다**. 원본 효과의 높이·속도와 완전히 동일하다는 확인은 하지 못했습니다.
- 현재 원본 act1autochess_m04의 실제 감염 타일을 Chromium으로 캡처했습니다: rage-outline.png. 테스트용 임의 타일을 찍은 이미지가 아닙니다.

## 알파 로딩

- Pixi 7의 기본 PNG 로더는 worker에서 기본 createImageBitmap으로 먼저 디코딩합니다. 스파인 아틀라스가 나중에 적용하는 PMA 옵션이 디코딩 시점에 반영되지 않아 PMA 원본을 이중으로 곱할 수 있습니다. BaseTexture.alphaMode만 뒤늦게 바꾸는 것으로 디코딩을 되돌릴 수 없습니다.
- 스파인 페이지에만 전용 파서를 적용했습니다. HTMLImageElement와 명시적 WebGL unpack 설정으로 일반 알파는 업로드 시 1회 곱하고, PMA 원본은 다시 곱하지 않습니다. BaseTexture 및 ImageResource의 설정을 일치시키며 아틀라스의 페이지별 PMA 표기를 우선합니다. 일반 이미지 다운로드 경로는 바꾸지 않았습니다.
- 스킨 메타데이터 생성 시 PMA=false를 무조건 기록하던 부분도 아틀라스 표기를 사용하도록 수정했습니다.
- 라플란드/텍사스 기본 웹 모델과 스즈란 세 스킨에는 pma:true 표기가 없습니다. PMA를 일괄 강제하는 방식은 적용하지 않았습니다. 원본 텍스처에 PMA를 강제로 적용한 비교에서는 밝은 가장자리 번짐이 발생합니다. 제보된 회색 테두리가 이 모델의 PMA 설정 오류라고 확정하지 않았습니다.

## 스즈란 웨이스트랜드 블로섬

- 사용자 답변으로 해당 스킨을 특정했습니다. 세 스즈란 스킨 및 라플란드·텍사스 기본 스킨의 앞/뒤 총 10개 모델을 검사했습니다.
- 69개 애니메이션에서 각각 5개 시점, 총 345개 자세를 검사했습니다. 누락된 아틀라스 region이나 비정상 좌표는 없었습니다. 180/270도 아틀라스 회전도 런타임에서 지원합니다.
- 실제 원본 3D 전장에서 저·중·고 그래픽 설정과 캐시된 impostor 경로로 표시했습니다. 다섯 모델 모두 로딩 및 표시를 완료했습니다. 웨이스트랜드 블로섬 깨짐 자체는 이 환경에서 재현되지 않았습니다.
- 스파인 뼈대, 공격/스킬 클립 선택, 애니메이션 시간, 메시 정점, 스킨 그림 파일은 변경하지 않았습니다. 공통 알파 디코딩 경로를 수정했으나 이것만으로 제보된 스킨 문제가 해결되었다고 단정하지 않습니다.

## 검증

- 에셋 및 원본 지형/수명 테스트: 49개 통과.
- Chromium 픽셀 테스트: 1개 통과. 일반 RGBA(128,64,32,128)와 PMA RGBA(64,32,16,128)를 검은 바탕에 합성한 결과가 둘 다 (64,32,16,255)입니다. 실제 WebGL 업로드 및 색상 추출을 검사합니다.
- 기존 공격 모션 및 이동 타이밍 회귀: 12개 통과.
- 이 보고서의 검증은 전체 게임/모든 오퍼레이터에서 모든 시점의 문제가 없다는 보장이 아닙니다.
