## 촬영 범위

이번에 기본 공식 이펙트를 추가한 9명의 일반 공격 명중 이펙트를 비교했다. 실제 전장 렌더러와 기존 공식/간소 이펙트 코드를 Chromium에서 실행해 24장을 촬영했다. 같은 맵·카메라·공격 대상에서 대표 명중 이펙트를 재생한 비교다. 실시간 멀티플레이나 모든 스킬의 타이밍을 검증한 자료는 아니다.

| 오퍼레이터 | 기본 공식/간소 | 스킨 비교 |
|---|---|---|
| 비헌터 | 촬영 | 허니 플런더: 별도 명중 교체 없음, 기본과 동일 |
| 보타니 | 촬영 | 제공된 자료에 해당 스킨 없음 |
| 레토 | 촬영 | 제공된 자료에 해당 스킨 없음 |
| 우쿠시크 | 촬영 | 제공된 자료에 해당 스킨 없음 |
| 이스티나 | 촬영 | 세이버 북: 스킨 외형과 교체 FX 촬영 |
| 토가와 사키코 | 촬영 | 선율의 주인: 스킨 외형과 교체 FX 촬영 |
| 체르니 | 촬영 | wild#8: 기본 외형에서 스킨 FX 촬영 |
| 디아만테 | 촬영 | epoque#37: 별도 명중 교체 없음, 기본 외형 촬영 |
| 베이스라인 | 촬영 | witch#5: 기본 외형에서 스킨 FX 촬영 |

체르니·디아만테·베이스라인의 해당 스킨 모델은 현재 게임 목록에 등록되어 있지 않다. 비교를 위해 외형을 새로 등록하지 않았으며, 스킨 열에서 기본 외형을 사용한 항목을 명시했다.

`captures.json`은 각 화면의 외형/스킨 키, 실제 재생한 공식 FX 키, 공식 FX 활성 여부, 모델 준비 여부를 기록한다. 최종 24장 모두 모델 준비 완료, 페이지 JS 오류 0건이다. 원본 화면은 `shots/`에 있다. 통합 이미지는 이 원본을 잘라 배치했으며 게임 이펙트를 합성하거나 다시 그리지 않았다.

## 함께 수정한 사항

- 공개 방의 AI 수를 인원수와 같은 줄 오른쪽 끝에 배치했다. 실제 방에서 오른쪽 간격 0px 및 같은 줄 배치를 확인했다(`room-check.json`).
- 한국어 기본 방제를 `닉네임 박사님의 n인 시뮬레이션`으로 변경했다.
- 스킨 FX 선택에서 추가 오퍼레이터의 `skinId` 및 외형 에셋 키 경로를 지원했다. 기존 `skin` 경로도 유지한다.
- 전장 메타데이터 정리 함수에서 기존 `skin` 정보를 보존하도록 했다. 실제 엔트리 포인트와 추가 스킨 경로 회귀 검사를 추가했다.

관련 테스트 6개 통과. 커밋/푸시하지 않았다.
