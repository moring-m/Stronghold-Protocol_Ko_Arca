# 모바일 UI 배율

설정 → 그래픽의 `모바일 UI 배율`: 50/60/70/80/90/100/110/125/150%, 기본 100%. 설정은 기기 브라우저에 저장한다. 터치 전용 모바일/태블릿에서 적용하고 데스크톱에는 적용하지 않는다.

CSS transform이나 글자 크기 대신 모바일 브라우저의 viewport width/initial-scale을 변경한다. 따라서 전체 페이지의 배율과 레이아웃 뷰포트가 함께 바뀌며 기존 캔버스/버튼 입력 좌표 처리도 그대로 사용한다. 100%로 돌아가면 원래 viewport 메타 설정을 복원한다. 화면 회전 시 변경된 실제 뷰포트 너비를 반영한다.

Chromium 모바일 에뮬레이션(844×390)에서 설정 드롭다운으로 직접 변경했다.

- 100%: layout width 844, native scale 1
- 80%: layout width 1055, native scale 약 0.8
- 125%: layout width 675, native scale 약 1.25
- 100% 원복, 새로고침 후 80% 복원 확인
- 390×844로 회전 후 약 0.8 유지, 레이아웃 너비 488 확인
- 페이지 JS 오류 0건. 상세 `check.json`과 실제 화면 PNG 참고.

배율 처리 및 기존 설정 로직 테스트 49개 통과. Windows/Safari 실기기 검증은 하지 않았다. 커밋/푸시하지 않았다.
