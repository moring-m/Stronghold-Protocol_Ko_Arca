# v0.2.4a 로컬 검증

원본 v0.2.4의 기능별 이식부터의 변경은 [게임 내 패치노트](../../shared/patchNotes.js)와 [변경 기록](../../CHANGELOG.md)에 정리했다. 기존 포크 설정·선발·밸런스·애니메이션 요구를 유지하며 원본 파일 전체를 덮어쓰지 않았다. 현재 패치노트 상태는 `testing`이며 운영 배포·커밋·푸시는 수행하지 않았다.

## 이번 수정

- 일반 선발 오퍼레이터는 선택된 단계 버튼 재클릭이 재선택으로 처리되던 동작을 수정했다. `미선발` 버튼의 전체 해제도 유지한다. 스킬·스킨·모듈 설정은 남기며, 원형 오퍼레이터의 5/6단계 선택은 독립적으로 해제한다.
- 실제 모집 설정 화면에서 단계 선택 → 같은 버튼 재클릭 → 저장 → 새 방 생성·게임 시작을 수행해 서버의 선발 목록이 비어 있음을 확인했다. 전투 시작 후의 설정 잠금은 유지한다.
- 일부 선발 소환물이 보내는 `arts` 공격 이펙트를 기본 마법 투사체로 렌더링한다. 서버의 공격 속도·피해·투사체 판정은 변경하지 않았다. 선발 5/6단계 일반·승급형의 모든 선택 가능한 스킬을 대상으로 평타/활성 스킬의 원거리 프로필이 지원되는 이펙트 유형을 사용하는지 검사했다. 사키코는 기존 스냅샷 기반 음표 렌더링을 유지한다. 모든 스킬의 개별 전용 연출을 완전히 검증했다는 의미는 아니다.
- 충전 표시를 글꼴 17→12로 축소해 SP바 아래로 이동하고, 바 너비 안에 들어오게 조정했다. 다른 하단 게이지와 자리를 나눠 사용한다.
- 인디고 외 에벤홀츠·비이은 공통 `trait.stored` 대신 각자의 별도 충전 상태를 사용한다. 실제 추가/변환 충전량과 최대치를 HUD 및 스냅샷으로 전달한다. 비이의 변환 에너지 1개는 원래 충전 에너지 수만큼 표시한다. 재배치 초기화도 확인했다.

## 검증 결과

- 버전, 프리셋, HUD, 충전, 선발, 공격 모션/타이밍, 대역/소환물: **88개 통과, 실패·건너뜀 없음**.
- 실제 서버·Chromium의 선발 해제/다음 판 반영 테스트: **1개 통과**. `SP_E2E=1 CHROME_PATH=/usr/bin/chromium node --test test/ui/recruit-024a.browser.test.js`.
- 실제 인디고·에벤홀츠·비이 스파인 모델 3개에 테스트 충전 스냅샷을 전달해 SP바 아래 표시, 작은 글꼴, 페이지 오류 없음 확인. [캡처](mystic-charges.png).
- 외부 HTTPS 링크에서 버전 응답·게임 hello/welcome 핸드셰이크·방 생성 확인. HTTP 방식으로 게임 프로토콜을 중계하는 로컬 미리보기 전송을 사용한다. 클라우드 Chromium의 외부 인증서 신뢰 문제 때문에 외부 URL의 서비스 워커 화면 검증은 완료하지 못했으며, TLS 검증을 유지한 Node 클라이언트로 외부 전송을 확인했다. 로컬 Chromium 화면/게임 테스트는 통과했다.
- JavaScript 문법 검사 및 `git diff --check` 통과.
- 기존 미스틱 캐스터의 광범위한 이식 테스트: 18개 중 14개 통과, 4개 실패. 이번 변경의 충전 표시용 profile 필드를 제거한 이전 구현으로도 같은 4개가 실패함을 확인했다. 배치 후 즉시 충전/스킬 수치를 기대하는 기존 테스트와 현재 배치·갱신 시점 차이가 있으며, 이 결과를 전체 통과로 보고하지 않는다.
- 기존 `test/ui/loadout.test.js`는 옛 112명 목록·내보내기 형식·잠재 설정 전송 형식을 기대하는 항목 등 5개가 실패했다. 이번 선발 동작은 운영 데이터 전체와 실제 서버를 사용한 새 테스트로 별도 검증했다.

## 정보 확인·결과창 UI 후속 수정

- 시작 조건 다시 추첨 컨트롤을 하단 조작 영역으로 이동했습니다. 중복 제목·상시 설명은 숨기고 투표 중 설명·찬반·취소 컨트롤은 유지합니다.
- `维伊`를 비이로 정정했습니다. 실제 위(`余`) 번역은 유지하며 비이의 재능 설명과 번역 생성 원본도 함께 수정했습니다.
- 실시간 결과 요약과 상세 전투 통계 양쪽에서 채팅이 왼쪽 열의 실제 레이아웃을 차지하도록 변경했습니다. 저장된 통계 재열람에는 실시간 채팅을 추가하지 않습니다.
- Chromium 1600×900, 1000×600에서 채팅 열기·통계 전환을 확인했습니다. 채팅과 돌아가기 버튼·팀원 결과 영역이 겹치지 않고 수평 넘침 및 페이지 오류가 없습니다. 브라우저 확인은 UI 배치 검증이며 전체 리소스 다운로드 검증은 아닙니다.
- 버전·진영 프리셋 관련 검사 12개 통과, 수정 JavaScript 문법 검사 통과.

## 설정·세로 목록 후속 수정

- 사이트/설치 앱 제목은 위수 협의로 통일했습니다. 단축키 설정은 키 입력 대기 동안 capture 단계에서 키를 받으며 Esc는 바인딩만 취소합니다. 다른 컨트롤을 클릭하거나 창을 닫으면 입력 대기를 해제합니다.
- 오퍼레이터/선발 세로 목록은 한 줄을 유지합니다. 단계 배지·직군·맹약·스킬·모듈은 아이콘이며, 스킬/모듈 아이콘 버튼으로 즉시 변경합니다. 이름·설명은 툴팁과 접근성 이름으로 제공합니다. 선발 선택은 같은 줄의 - / V / VI 버튼입니다. 미선발 단계 배지는 없습니다.
- 관전 설정 하단 안내 삭제, 커스텀 설정 명칭 통일, 관련 맹약/맵 목록의 기존/커스텀 구획을 추가했습니다. 커스텀 맵도 비활성화 카탈로그와 실제 추첨 제외 규칙에 포함됩니다.
- 현재 렌더러에서 맵 11종을 960×600으로 다시 촬영했습니다. 각각 board3d.originalStage가 해당 ID이고 원본 3D가 활성화되며 context loss가 없음을 확인했습니다. 게임 추첨 목록의 맵 8개가 비활성화 선택 화면에 표시됩니다. 미리보기 URL의 버전 인자를 갱신해 이전 썸네일 캐시를 갱신합니다.
- 일반/승급 전체 특질을 다시 비교했습니다. 성약 이그제큐터·니어 더 래디언트 나이트·데겐블레허의 중복 내부 설명을 제거합니다. 니어의 승급 설명에 번호 참조가 없는 경우도 실제 부여 ID로 연결합니다. 비질의 별도 처치 효과 등 독립 조건은 보존합니다.
- 관련 자동 검사 26개 통과. 실제 Chromium에서 제목, 초상화 크기 일치, 미선발 배지 없음, 스킬/모듈 아이콘 변경·저장, 선발 선택, 단축키 Z 변경/Esc 취소, 기존/커스텀 구획과 맵 선택을 검증했습니다. 목록은 1600×900과 640×360에서 확인했습니다. 사진을 기준으로 전체 폭의 고정 열(오퍼레이터·직군·맹약·스킬·모듈·선발)로 정렬했으며 잠재·육성도는 목록에서 제외합니다. 좁은 화면은 목록 내부의 가로 스크롤을 사용해 열 정렬과 아이콘 크기를 유지합니다. UI 조작 검증은 다운로드 큐를 비운 별도 테스트 서버를 사용했으며 전체 리소스 다운로드 검증을 뜻하지 않습니다.

### 행 높이·필터 전환 버튼 재검증

- 행은 1920px 기준 56px로 맞췄습니다. 초상화/아이콘/여백도 줄여 실제 콘텐츠가 행 높이를 늘리지 않게 했습니다.
- 열 제목이 실제 DOM에 오퍼레이터·직군·맹약·스킬·모듈·선발 순서로 나타나고 목록 안 잠재·육성도 select가 0개임을 Chromium에서 확인했습니다.
- 목록/초상화 전환 버튼은 직군·맹약·조정만 보기 필터와 같은 줄의 오른쪽에 있으며 직군 필터 버튼과 같은 높이입니다.
- 1600×900에서 실제 행 높이 50px 미만, 640×360에서 목록 내부 가로 스크롤 및 열 정렬 유지 확인. 미리보기 서버를 재시작해 최신 파일을 새 빌드 태그로 제공합니다.

### 목록 헤더·상세 패널 재검증

- 열 제목을 스크롤 영역 밖으로 분리하고 가로 스크롤만 동기화합니다. Chromium에서 제목 하단이 첫 행 상단을 넘지 않음을 확인했습니다. 데스크톱 상세 패널을 복원했습니다.
- 일반 단계는 초상화 왼쪽에 별도 표시하고 선발은 단계 배지를 제거했습니다. 선발 선택 버튼의 V/VI는 TierChip 아이콘입니다. 행 높이를 조금 늘렸으며 스킬/모듈은 기존처럼 바로 변경됩니다.
- 직군은 필터/상세 패널과 같은 대형 직군 이미지를 사용합니다. 누락된 모듈 PNG 128개와 직군 PNG 8개를 리소스 매니페스트의 에셋 저장소에서 다운로드했습니다. 모듈 130개 전체 경로에 파일이 있고 PNG 서명을 확인했습니다. 출처/결과는 module-icon-fetch.json 및 profession-icon-fetch.json에 기록했습니다.
- 관련 자동 검사 10개 통과. UI 검증은 다운로드 큐를 비운 서버에서 진행했으며 전체 다운로드 검증과는 별개입니다.


## 실험실 추가 및 선택 UI 검증

- 기존 Match 엔진을 브라우저의 로컬 요청 어댑터로 실행한다. 실험실에서는 WebSocket을 닫고 방 생성·전투 요청을 게임 서버로 보내지 않는다. 정적 코드·리소스 제공은 기존 HTTP 경로를 사용한다.
- `node --test test/match/laboratory.test.js test/ui/skins.test.js test/ui/shop-controls-20261011.test.js`: 14개 통과, 실패·건너뛰기 없음. 모든 난이도와 일반/히든 보스 선택, Pith 시작 보상, 중첩 설정, 자유 획득·배치·장착, 일반 게임의 실험실 요청 거부를 검사했다.
- Chromium에서 난이도 선택 → 맵/보스/전략 설정 → 준비 → 중첩 적용·자유 획득 → 전투 → 종료 → 기존 로컬 통계 기록 저장을 확인했다. 실험실 실행 중 WebSocket이 null임을 확인했다. 640×480에서 메뉴의 좌우 경계가 화면 안에 들어오는 것을 검사했다.
- 선택 화면은 같은 높이의 3개 박스로 구성하고 목록·설명을 내부 스크롤한다. 실제 보스 10종·전략·맹약 아이콘을 기존 리소스 출처에서 확보했다. 보스 설명은 리치 텍스트를 나누기 전에 전체 문장을 번역해 미번역 원문이 조각별로 남는 문제를 해결했다.
- 상점 위치의 실험실 메뉴는 위쪽 접기/탭, 내부 등급·맹약 필터/검색, 아래 카드 목록으로 구성한다. 전체 리소스 다운로드·모든 전용 애니메이션을 완전히 검증했다는 의미는 아니다.

- 추가 Chromium 검증: 설정 3개 박스의 높이 동일, 페이지 overflow hidden, 일반/히든 보스 10종 전체 설명에 미번역 한자가 없음, 보스 아이콘 로드 완료를 확인했다. 실험실 카드 탭·II단계 필터·장비 목록·모바일 좌우 경계 검사를 통과했다.
- 오퍼레이터 설정에서 모든 표시된 이름의 scrollWidth가 clientWidth를 넘지 않는지 확인했다. 직군 셀 클릭, 탭별 프리셋 버튼 1개, 기존 필터 줄의 보기 전환, 스킬·모듈 설정, 상세 패널, 좁은 화면의 내부 가로 스크롤 검사도 통과했다.
