## 기존 동작 보존을 위해 보완한 부분

- 덕로드: 원본의 단일 보유자 조회를 그대로 쓰지 않고 공통 전략과 개인 전략의 모든 복사본을 유지했다. 같은 라운드/시드는 이제 의도적으로 같은 교체를 한다. 분포 테스트는 매치 시드를 바꾸어 검사한다.
- 정비 보상: 선택 단계 전 보상을 없애는 것에 그치지 않고 특질 순회의 `onPrepStart` 허용 조건과 연습실/실험실의 첫 보상도 연결했다. 우르수스 특질·승급 후 재적용을 별도로 확인했다.
- 공격 모션: 포크의 `atkStart`가 있는 경로는 선행 모션을 중복 실행하지 않는다. 적의 변신 후 슬롯 변경은 형태별 공격을 보존하고, 이 변경이 마코토의 공격 A/B 교대를 덮어쓰지 않도록 적 모델에만 적용했다.
- 리소스: 적 11개의 `spine.anims.skill/skills`만 변경했다. URL·텍스처·모델·사용자 스킨/FX/SFX 매니페스트의 나머지 필드는 보존했다. 기존 음원/스킨을 다시 다운로드하거나 저장소에 올리지 않았다.
- 피해 처리: 커스텀 함수형 피해 API를 유지했다. 원본의 유순서 보호막/회피/피해 처리 전면 교체와 그에 종속된 숨겨진 코어 변경은 여전히 제외했다. 관통 수식은 이미 독립 병합되어 있다.
- 운영: Worker/예행연습 풀·다중 시즌 프로세스·압축 문맥 유지·delta 프로토콜은 미도입. 1.4GiB 메모리 배분, 구버전 유지/종료, 라우터 및 배포 스크립트는 변경하지 않았다. 신규 온라인 제한도 기본 비활성이다.
