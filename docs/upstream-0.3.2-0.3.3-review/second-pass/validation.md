## 실제 브라우저

[실제 마코토 스킨 종료 화면](actual-render-finished-skin.png), [측정 JSON](actual-render-finish.json), [브라우저 로그](actual-render.log).

실제 Pixi/Spine/스킨 리소스를 사용했다. 전투 입력이 멈춘 동안 공격/반복 효과를 유지했고, 명시적 종료 뒤에는 `Doll_Skill_3_P1_Idle`/효과 0개로 정리되었다. 브라우저 오류는 없었다. 반복 효과 수명 검증에는 실제 렌더러에 합성 반복 효과 1개를 추가했다. 모든 효과가 자연 전투에서 생성되었다는 의미는 아니다.

새 적 스킬 슬롯·앞/뒤 모델 전환은 실제 매니페스트 기반 렌더 단위 테스트로 확인했으며 모든 적/스킨의 실제 브라우저 스크린샷을 촬영한 것은 아니다. 원래 범용 render-demo의 기본 모델 누락으로 발생한 제한 시간 실패는 성공으로 집계하지 않았다. 전체 SWEEP 리포트 조작 브라우저 회귀도 미실행이다.

1차 검토의 실제 브라우저 캐시 동시 갱신 5건·상점 1건 통과 증거는 상위 logs 폴더에 보존했다. 본 재검토는 해당 구현을 변경하지 않았다.

## 재현

저장소 루트에서 Node로 final-tests.json을 읽고 `node --test --test-concurrency=2`의 파일 인수로 전달한다. 테스트 실행기는 기존 Windows 명령 길이 대응을 유지했다. 상위 reproduce/makoto.mjs, reproduce/roster.mjs에 기준/작업 체크아웃과 출력 경로를 지정해 고정 입력을 재생성할 수 있다. 양쪽에 같은 프로덕션 데이터/선택적 캐시/벤더를 준비해야 비교할 수 있다.

고정 입력의 일치는 모든 맹약·증강·스킨·라운드·기기 조합의 완전한 동등성 증명은 아니다. 이번에 고친 적 스킬 회차, 부착/밀기, 정비 보상 시점, 추가 폭격의 결과는 의도적으로 달라진다. 그 외 사용자 추가 기능은 별도 회귀로 검사했다.
