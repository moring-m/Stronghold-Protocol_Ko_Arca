## 판단 기준

병합은 독립적으로 검증한 변경, 부분 병합은 명시한 일부만 이식, 기존 유지는 로컬 구현을 선택했다는 의미다. 기존 유지가 원본의 새 기능을 전부 제공한다는 뜻은 아니다. 제외는 해당 원본 변경을 적용하지 않았다는 뜻이다.

게임 결과 보존은 무관한 전투/커스텀 경로에 적용했다. 혈박 HP 감소, 블레미샤인/실버애시 스킬 조건, 설계사 방향 방어, 관통 순서는 병합 대상 버그를 고치는 의도된 예외다. 전체 적/스킬/기기 조합의 동등성을 증명한 것은 아니다.

### 실제 렌더 확인

[실제 스킨 렌더 스크린샷](actual-render-finished-skin.png), [측정값](actual-render-finish.json).

현재 프로덕션 스킨 모델/리소스를 사용한 마코토 S3 첫 대역 공격 화면을 확인했다. 입력을 일시정지했을 때 반복 효과는 유지되었고(14개), 명시적인 전투 종료 뒤에는 `Doll_Skill_3_P1_Idle`, 효과 0개로 정리되었으며 브라우저 오류는 없었다. 정리 수명을 검사하려고 실제 FX 렌더러에 합성 반복 효과 1개도 함께 주입했다. 따라서 스크린샷/모델은 실제 렌더이고, 모든 효과가 자연 전투에서 발생했다는 뜻은 아니다.

원본의 범용 `render-demo` 브라우저 테스트는 이 환경에 기본 모델 리소스가 없어 로딩 제한 시간에 실패했다. 그 테스트를 성공으로 집계하거나 그대로 추가하지 않았고 위 실제 사용 가능한 스킨 경로로 별도 확인했다. SWEEP CSS는 제한된 규칙 변경/소스 검토까지 진행했으며 실제 전체 리포트 조작 회귀는 미실행이다.
