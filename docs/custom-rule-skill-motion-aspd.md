# 커스텀 규칙: 스킬 모션 공격속도 적용 — 영향을 받는 스킬

규칙 ID `skillMotionAspd` (커스텀 설정 › 규칙). 켜면 아래 스킬의 고정 시간이 `공격속도 ÷ 100`(0.2~6배로 제한)에 맞춰 줄어들거나 늘어납니다. 공격속도 200이면 절반, 50이면 두 배입니다. 끄면 기존과 같습니다.

'공격속도 상한 해제' 규칙을 함께 켜면 배율 상한이 6배(공격속도 600)에서 30배(공격속도 3000)로 올라갑니다.

기준 코드: `server/sim/motionSpeed.js`, `shared/attackTiming.js`의 `IMPACT_CAST_SKILLS`, 각 오퍼레이터 키트(2026-11-05 기준).

## 2. 일정 간격으로 타격·조준하는 스킬 (6종)

공격 대신 스킬이 스스로 일정 간격으로 타격하는 스킬입니다. 시전 모션 시점은 그대로 두고, 타격 간격만 공격속도 비율로 바꿉니다.

| 오퍼레이터 | 스킬 | 바뀌는 것 |
|---|---|---|
| 탈룰라 | 3스킬 작열하는 광환 | 파동 발사 간격. 지속시간은 같아서 공격속도가 높으면 파동 수가 늘어남 |
| 패신저 | 3스킬 찬란히 찢어진 조각 | 폭풍(4초) 안의 타격 간격. 타격 수가 늘어남 (시전 모션은 1번에도 해당) |
| 로사 | 3스킬 눈사태 사격 | 작살 타격 간격. 같은 시간에 타격 수가 늘어남 |
| 르무엔 | 3스킬 | 조준 중 탄약 소모(조준 1회 = 탄약 1발) 간격. 5발을 더 빨리(또는 느리게) 조준. 첫 조준은 그대로 즉시 |
| 엔텔레키아 | 2스킬 진홍빛 장벽 | 피의 낫 타격 간격(기본 0.5초). 같은 지속시간에 타격 수가 늘어남 |
| 데겐블레허 | 3스킬 조용한 마무리 | 베기 간격. 베기 횟수는 고정이라 스킬과 무적 시간이 그만큼 짧아짐(또는 길어짐) |

## 3. 유키 마코토의 대역 전환

1·2·3스킬 모두 해당합니다. 전환 모션, 그동안의 무적·행동 불가 시간, 전환 안의 타격 시점이 같은 비율로 바뀝니다. 화면의 전환 모션도 같은 속도로 재생합니다. 각 전환은 시작 순간의 공격속도를 씁니다.

| 전환 | 기본 시간 |
|---|---|
| 페르소나 등장 | 2초 |
| 대역 교체 (3스킬) | 1.5초 |
| 퇴장 | 1초 |
| 총공격 | 1.6초 (타격 0.3초, 섬광 0.167초) |
| 3스킬 치유 파동 | 0.5초 |

페르소나 지속시간(20초)은 모션이 아니므로 바뀌지 않습니다.

## 영향을 받지 않는 것

- 이미 공격속도를 따르는 스킬: 지속형 스킬의 공격, 다음 공격 강화형 스킬 등
- 같은 "간격" 값을 쓰지만 공격을 대신하는 타격이 아닌 것: 지속 피해 틱, 시간에 따라 오르는 버프, 둔화·오라 펄스(라이타니엔, 글래디아 토네이도 등), 수르트의 체력 증가, 르무엔 2스킬의 조준 배율 누적
- 모든 스킬에 공통인 0.5초 스킬 표시 시간(화면 표시용)

## 확인 범위

- 테스트로 확인: 파인콘 1스킬 시전 시간, 유키 마코토 등장·대역 교체 시간, 탈룰라 3스킬 파동 수, 르무엔 3스킬 조준 간격, 엔텔레키아 2스킬 타격 수
- 테스트하지 않음: 패신저·로사·데겐블레허 3스킬, 나머지 시전 스킬의 개별 시간
- 실제 게임 화면에서 모션 속도를 보지 않았습니다.
