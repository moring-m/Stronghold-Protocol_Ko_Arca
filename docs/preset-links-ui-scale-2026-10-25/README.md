# 프리셋 연동 선택 창·선호 배지·전체화면 배율

2026-10-25. 테스트 서버에 반영했으며 커밋·푸시·운영 배포는 하지 않았다.

## 변경 사항

- 선호/선발 프리셋의 진영 연동 드롭다운을 버튼과 진영 아이콘 선택 창으로 변경했다. 기존 진영 연결과 저장된 프리셋은 유지한다.
- 바로 옆에 전략 연동 버튼과 전략 초상화 목록·검색을 추가했다. 진영과 전략은 각각 독립적으로 연결할 수 있으며, 동일한 진영 또는 전략을 다른 프리셋에 연결하면 이전 연결을 해제한다. 연동 해제도 선택 창에서 가능하다.
- 전략 연동은 **전략 선택 단계 완료 시** 적용한다. 선발 설정은 이후 잠기므로, 연결된 선발 구성을 서버에 미리 동기화하고 최종 전략 확정 후 잠금 전에 적용한다. 수동 확정·시간 초과·무작위 전략의 실제 확정 결과를 지원한다. 선호 프리셋도 완료된 전략을 기준으로 한 번만 활성화한다. 이후 UI 상태 갱신은 수동 변경을 덮어쓰지 않는다.
- 저장/불러오기 코드에 전략 연결을 포함한다. 구형 프리셋은 전략 연결 없음으로 유지한다. 현재 카탈로그에 없는 전략·선발 항목은 전송에서 제외하며 저장된 원본은 삭제하지 않는다.
- 상점의 선호 오퍼레이터·장비 표시를 파란 배경의 `선호` 배지로 변경했다. 기존 민트 배경 `선발` 배지와 위치·크기·굵기를 맞췄다.
- 모바일 DOM 전체화면에서는 viewport-meta 배율이 무시될 수 있어 CSS 배율과 기존 좌표 보정 경로를 사용한다. 전체화면 해제 시 모바일 viewport 배율로 복원한다. 데스크톱 배율 동작은 유지한다.
- 추가된 연동 기본 UI 문구를 영어·일본어·중국어 언어팩에도 추가하고 해시를 갱신했다.

## 검증 범위와 한계

- 프리셋·진영/전략 연동·저장 동기화·실제 WebSocket 서버·시간 초과/무작위 선택·선발·기존 전투 포기·배율 회귀 **62개 통과**. [로그](unit-tests.log).
- 실제 Chromium에서 기존 모든 진영의 복구/이동/잠금 및 전략 확정 후 선호/선발 동기화 브라우저 회귀 **2개 통과**. 오래된 전략 연결 제외, 중복 적용 방지, 서버에 이미 적용된 구성의 로컬 반영 시 잘못된 잠금 안내를 띄우지 않는 것도 확인. [로그](browser-tests.log).
- 진영·전략 선택 창에서 실제 클릭·검색·연결 이동을 확인했고 JavaScript 오류 0건.
- 모바일 배율은 표준/WebKit 전체화면 전환·배율 변경·해제 복원 단위 테스트와 브라우저의 **모의 전체화면 이벤트**를 확인했다. 이 환경의 headless Chromium에서는 네이티브 전체화면 진입을 검증하지 못했다. 실제 Android/iOS 기기에서 확인이 필요하며, 실기기 전체화면 성공을 주장하지 않는다.
- strict import 및 `git diff --check` 통과, 변경 파일 lint 오류 0개(기존 경고만 존재).

릴리스 상태 갱신: 이 문서는 검증 당시의 기록이며, 해당 변경은 이후 [v0.3.3a 릴리스](../releases/v0.3.3a/README.md)에 포함했습니다.
