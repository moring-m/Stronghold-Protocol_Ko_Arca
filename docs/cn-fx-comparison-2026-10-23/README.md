## 판단

모든 스킨 모델 로딩 완료, 페이지 JS 오류 0건, FX 로딩 실패 0건이다. 아코르트는 스킨 전용 교체표가 없어 기본 FX를 유지한다. 인사이더는 명중 FX 교체가 아닌 투사체 정의/발사 위치 연결을 쓰며 별도로 실제 비행을 재생했다. 해당 그래픽 투사체의 trail 키 자체는 기본과 같을 수 있다.

대표 공격/스킬 FX 비교이며 모든 스킬의 원본 클라이언트 타이밍·피해·패턴을 검증한 자료는 아니다. 이 범위에서 표시와 파일 의존성 검사를 통과한 19종만 리소스 저장소에 올렸다.

마운틴 marthe#13은 스크린샷의 대표 공격은 표시되지만, 스킬 이펙트 교체 목적지 2개를 확인하지 못했다. 전체 연결이 정상이라고 판정하지 않고 **이번 업로드에서 제외**했다. 기존 마운틴 boc#3·epoque#15는 그대로 유지한다.

19종의 페이로드 1,069개(28,852,382바이트), 이펙트 357개/투사체 정의 20개/텍스처 312개/메시 92개를 추가했다. 실제 브라우저에서 357개 FX 및 의존 리소스를 모두 불러왔으며 정의·텍스처·메시 누락은 0개다. 기존 260종의 키와 데이터가 보존되는지 확인했고 깨끗한 빌드 디렉터리에도 설치했다. 관련 테스트 47개 통과.

현재 게임에 없는 오퍼레이터용 240종은 이번 업로드에 포함하지 않았다. 게임 소스 저장소 커밋/푸시, 리소스 참조 SHA 변경, 운영 배포는 하지 않았다.
