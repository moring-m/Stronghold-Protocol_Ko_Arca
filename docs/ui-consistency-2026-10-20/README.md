# 공통 UI 치수 정리 · 실제 화면 비교

[변경 전/후 통합 이미지](comparison.png) · [원본 크기 비교 페이지](comparison.html)

로비·대기실·오퍼레이터 설정·통계·실험실·설정창을 실제 애플리케이션에서 열어 Chromium으로 촬영했습니다. 왼쪽이 기존 화면, 오른쪽이 수정 화면입니다. 기존 배경·장식·PC 버튼 배치를 유지하고 치수와 글꼴 기준을 통일한 최종 수정본입니다. 처음 시도했던 PC 두 줄 개편과 대기실 버튼 이동은 제외했습니다.

- PC 기본 상단 바 높이 88px, 좁은 PC 폭에서는 공통 104px. 버튼은 높이만 36px로 맞추고 기존 색상·테두리·질감·패딩·폰트·아이콘을 복원했습니다. 일반 제목과 오퍼레이터/통계 제목 탭은 모두 22px·굵기 700·줄 높이 27.5px로 통일했습니다. 모바일 제목은 모두 18px입니다.
- 기존 굵은 글꼴·녹색 테마·장식과 각 화면 고유 기능을 유지합니다. 게임 방법 버튼은 모든 페이지에서 아이콘만 표시하고 접근성 이름을 유지합니다.
- 모바일에서는 기존 로비와 같은 제목/도구 구분을 적용해 제목과 버튼이 겹치지 않도록 합니다. 도구가 많은 경우 해당 영역에서 가로 스크롤할 수 있습니다.
- 설정·커스텀 설정·프리셋 창의 제목 크기, 입력칸과 하단 버튼 크기, 선택된 탭의 강조와 키보드 포커스를 공통 기준으로 정리합니다.
- 전투 중 HUD와 스킬·등급별 게임 아트에는 이 규칙을 적용하지 않습니다.

PC 1440×1000, 모바일 390×844로 촬영했습니다. 상단 바 비교는 해당 실제 페이지의 상단 190px를 캡처했으며 설정창은 전체 화면을 사용했습니다. 통합 이미지는 이 원본 스크린샷들을 HTML 비교 페이지에 배치한 뒤 다시 Chromium으로 촬영한 한 장의 PNG입니다.

검증: 실제 페이지를 순서대로 열어 높이·제목 중앙 정렬·가로 넘침·게임 방법 버튼의 정사각형 크기·돌아가기와 설정창 열기/닫기를 확인했습니다. 재현 명령은 `SP_E2E=1 SP_COMPARE_SCREENSHOTS=1 node --test test/ui/navigation-consistency.browser.test.js`입니다.


후속 수정: 선발 설정은 5·6단계 장비 설정을 공유하고, 선택된 선발을 단계별 색상의 2×2 칸으로 표시합니다. 각 단계 인원수는 해당 영역 위에 표시합니다. 빈 칸은 검색창만 있는 초상화 선택창을 엽니다. `after-recruit-picker.png`는 실제 검색·선발 과정의 화면입니다. 선택/해제·양방향 스킬 공유·검색 선발을 브라우저로 검증했습니다.

핑의 기존 표현을 복원하고 대기실 원본 버튼·설정 플러그인 탭을 제거했습니다. 대기실 초대코드를 상단 높이에 맞췄으며 난이도/리롤 영역의 왼쪽 위치와 전체 너비를 동일하게 맞췄습니다. 관전이 꺼진 방에 실제 코드를 입력해 관전을 시도했을 때 전용 한국어 안내가 나타나고 입장되지 않는 것을 검증했습니다. Touch의 일반/색상 태그 설명 번역을 보완했으며, 운영 데이터의 전략 이름·효과명·일반/태그 설명을 한국어 표시 계층으로 통과시켜 중국어가 남지 않는지 확인했습니다.


추가 정렬 보완: 선발한 오퍼레이터를 모집 목록 앞으로 이동하던 정렬을 제거했습니다. 모듈 선택지 수가 서로 다른 두 6단계 선발을 사용해 스킬/모듈/해제 버튼의 시작 좌표가 동일한지 확인했습니다. 선발·선호 프리셋 창의 코드 생성/불러오기/새 프리셋 버튼은 좌측 영역 전체 너비를 공유합니다(`after-recruit-presets.png`). 커스텀 프리셋 작업 버튼도 균등한 열 너비를 사용합니다. 상단 바의 큰 버튼·위험 버튼은 공통 버튼 높이의 적용 대상에서 제외하며, 방 나가기 버튼은 기존 0.64rem 정사각형 크기를 유지하는지 확인했습니다.


대기실 추가 보완: 난이도/리롤 두 행의 라벨은 공통 `max-content` 열을 사용하여 가장 긴 한국어 문구의 너비를 확보합니다. 선택 영역은 그 오른쪽에서 같은 위치·너비를 유지합니다. 채팅 제목을 진영 선택·설정 버튼과 같은 헤더 행 왼쪽으로 이동하고, 별도 제목 행을 없애 메시지 영역이 참가자 카드 높이를 채우게 했습니다. `after-room-layout.png`에서 전체 배치를 확인할 수 있습니다.
