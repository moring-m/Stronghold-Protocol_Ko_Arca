# 증강 조정 및 모바일 상단바 수정

- 증강 모드의 고정 보스 HP 400%를 기본 100%로 변경. 4·7·10 라운드에서 등장한 등급당 실버 ×1.3, 골드 ×1.5, 프리즘 ×1.7을 한 번씩 누적 곱합니다. 골드·골드·프리즘은 ×3.825입니다. 별도 HP 증강 자체의 효과와 커스텀 모드의 설정은 유지합니다.
- 적 증강: 재생 100/170/250, 상태이상 지속시간 +50/70/100%, 원소 피해 +50/80/120%, 이동 속도 +15/25/35%, 아군 방어력 감소 15/30/50%, 아군 지속 HP 감소 40/70/100.
- 아군 마법 저항 감소를 마법 피해 증가로 대체. 모든 적의 마법 피해 ×1.1/1.2/1.3, 기존 마법 저항 감소 아이콘 대신 마법 피해 룬 사용.
- 돌파는 실제 방어 포인트 진입 때마다 별도 HP 1 차감. 일반 정산의 적 수·라운드당 피해 상한과 분리합니다. 중복 누적 보고와 최종 결과를 중복 차감하지 않습니다. 시간 초과와 미등장 적은 돌파 차감 대상에서 제외합니다. 클라이언트 전투·서버 스트리밍·서버 계산 타임라인을 연결했습니다.
- 웨이브 캐스터: 공격 판정은 변경하지 않았습니다. 주 대상에게 공격 이펙트를 생성한 후 같은 공격의 주변 피해 대상에는 중복 생성하지 않습니다. 웨이브 리더와 캐스터 쾌속정에도 적용됩니다.
- 모바일 상단바: 짧은 터치 가로 화면과 좁은 화면에서 제목/도구 두 행, 높이 80px, 일반 버튼 32px로 정리했습니다. 데스크톱은 기존 크기를 유지합니다.

## 위키 대조

[PRTS 控潮术师](https://prts.wiki/w/%E6%8E%A7%E6%BD%AE%E6%9C%AF%E5%B8%88): 일반 공격은 목표가 있는 칸과 상하좌우 4칸의 아군 전체에 마법 피해와 공격력 80%의 침식 손상을 가합니다. 3명 제한 공격이 아닙니다. 사용자의 추가 설명에 따라 피해 판정은 유지하고 렌더링의 중복 이펙트만 수정했습니다.
