## 검증

- 직접 재현 및 기존 소환물·대역·지마·공격 타이밍·전략·재고·황제의 은총 테스트: 105개 통과, 1개는 기존 선택적 리소스 조건으로 건너뜀.
- 렌더링·다운로드·신규 제보 등 별도 테스트 묶음: 72개 통과. 위 묶음과 일부 중복된다.
- 실제 서버/브라우저: 관전자 준비 → 전투 카메라 자동 전환 확인. 같은 게임 컴포넌트에 단일 참가자 연합방어 필드 메타데이터를 전달해 좌측 전장 카메라 수렴 확인. 전략 카드 CSS 문구도 확인.
