# 상점 배치·HP 표시·단축키 수정

- 설정 → 조작·단축키 → 장비 칸 왼쪽 배치. 기본은 기존 오른쪽이며 켜면 레벨 카드보다 왼쪽 끝에 표시됩니다. 구매 요청의 서버 슬롯 번호는 그대로 사용합니다.
- 전투 중 유출 수를 예상 HP 차감으로 표시하지 않습니다. 상단과 참가자 목록 모두 실제 HP를 유지하고 서버 정산값이 도착하면 갱신됩니다. 유출 집계와 정산 규칙은 유지합니다. 보스의 실제 공유 HP 변경은 기존대로 표시합니다.
- 상점 레벨업으로 늘어난 기물 슬롯은 기존 기물 슬롯의 왼쪽에 추가됩니다. 기존 카드·판매 상태·동결 상태와 장비는 보존되며 새 칸은 기존 규칙대로 다음 새로고침에서 채워집니다.
- 상점 위 작은 접기 버튼을 제거했습니다. 자금 영역의 접기 버튼과 접힌 상점의 펼치기 버튼은 유지합니다.
- 단축키 설정을 실제 입력에 연결했습니다: 새로고침 R, 동결 F, 레벨업 D, 퇴각 Q, 판매 X, 준비/일시정지 Space, 상점 접기/펼치기 C. 각 키를 변경하고 기본값으로 복원할 수 있으며 중복 키는 교환합니다. 입력창·IME·반복 입력·방향 선택 중에는 잘못 실행하지 않습니다. 접기/펼치기 및 다른 상점 버튼의 키 표시는 저장한 설정을 따릅니다.
- 인위적으로 근접 무기의 끝을 따라 그리던 꼬리 효과를 제거했습니다. 스파인 원본 그림 및 원본 애니메이션 효과는 유지합니다.

검증: 상점 레벨업 및 설정/단축키 로직 52개, 팀 HP 표시·준비 버튼 2개, 근접 꼬리 미생성 1개 통과. Chromium에서 장비 칸이 레벨 카드보다 왼쪽에 배치되고 작은 접기 버튼이 사라진 것을 확인했습니다. C를 K로 바꾼 설정 저장과 버튼 표시도 확인했습니다.

넓은 기존 테스트에서는 이번 변경과 무관한 실패도 있습니다: playtest3의 기존 준비 안내 소스 정규식 및 backups 데이터 사전 로딩 검사, fxproj의 playAbility 없는 가짜 actor 검사. 전체 테스트 통과로 보고하지 않습니다.
