# 전투 시작·마코토 성능 점검

2026-10-24 로컬 수정. 커밋·푸시·운영 반영하지 않음.

## 확인한 비용과 수정

| 대상 | 확인한 처리 | 변경 |
|---|---|---|
| 공통 전투 시작 | 다른 전장 레이아웃의 선택적 미리 만들기가 전투 중에도 실행됨. Chromium 프로파일에 scene의 surfaceForArea/vertex 등이 나타남 | 현재 전장 표시는 유지하고 다른 맵의 미리 만들기만 전투가 끝날 때까지 대기 |

## 수정 전후 측정

같은 실제 전투 이벤트를 Chromium/SwiftShader의 게임 렌더러로 재생했다. 구간 전체의 `_impOver` 누적 비용은 기본 약 108→49ms, 스킨 약 133→68ms. 이는 특정 CPU 작업의 비용이며 전체 FPS 개선율이 아니다. 전체 프레임 비용에는 첫 로딩·GC·환경 변동이 있어 일괄 개선율을 주장하지 않는다. [전](render-before.json), [후](render-after.json).

Node 시뮬레이션은 조건별 5회 중 중앙값. 10초의 S3 P2 구간에서 마코토 8명일 때 버프 재생성 14,400→0회, 실행 약 14.18→4.88ms. 1명은 약 2.58→1.02ms. 입력·효과 수치를 줄여 얻은 결과가 아니다. [전](simulation-before.json), [후](simulation-after.json).

## 결과 동일성

기본/스킨 × S1/S2/S3 총 6개 전투에 동일한 입력을 넣고 원래 v0.3.1i의 마코토 코드와 수정 코드를 비교했다. 각 930개 프레임, 총 5,580개 프레임의 스냅샷과 이벤트를 포함한 기록이 JSON 전체 비교에서 동일했다. [비교 결과](battle-parity.json).

피해·회복·회피율·대상 선택·스킬/대역 시간·모션·효과의 크기와 방향은 변경하지 않았다. 계산 재사용 및 리소스 준비 시점만 바꾼다. 확인한 조건 밖의 모든 전투를 전수 검증했다는 뜻은 아니다.

실제 휴대폰·사용자 GPU에서의 FPS 및 운영 서버의 부하를 측정한 것은 아니므로, 제보된 모든 랙이 해소됐다고 확정하지 않는다. 전체 저장소 테스트 재실행 대신 해당 경계/FX/전투/맵/배치 관련 회귀 검사를 실행한다.

## 추가 검증

관련 회귀 검사 173개 중 172개 통과, 선택적 리소스 검사 1개 생략, 실패 0개. import 경계 검사 통과. 수정 코드 ESLint 오류 0개(기존 경고 유지).

마코토가 없는 오퍼레이터 4명의 준비 화면에서 FX 정의 2→54개, GPU 준비 큐 125→0개를 확인했다. 준비 중 표시되는 공식 효과는 0개였다. [준비 결과](prep-fx-validation.json). 이 검사는 FX 준비 경로를 확인한 것으로, 로컬에 일부 일반 오퍼레이터 모델이 없어 4명의 모델 화면을 모두 정상 촬영했다는 뜻은 아니다.
