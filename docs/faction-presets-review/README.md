# 진영 연동 프리셋과 PR #9 검토

## 진영 연동

- 선호 프리셋과 선발 프리셋은 별도 관리하며, 각각 진영당 하나만 연결된다.
- 진영 연결을 다른 프리셋에 지정하면 이전 연결이 해제된다. 연결 취소는 현재 구성에 영향을 주지 않는다.
- 채팅 진영 선택 요청이 성공한 뒤 연결된 프리셋을 적용한다. 연결이 없는 진영 또는 진영 선택 취소는 기존 구성을 유지한다.
- 선호 프리셋은 전투 중에도 전환한다. 선발 프리셋은 대기실·정보 확인·전략 선택 단계까지만 전환한다.
- 선발 프리셋은 현재 선발 인원과 해당 인원의 스킬·모듈·스킨을 저장한다. 불러올 때 일반 오퍼레이터 설정은 유지한다. 빈 선발 프리셋은 선발을 해제한다.
- 인원 제한과 중복 선발 등 기존 검증을 거친다. 잘못된 프리셋은 경고하고 현재 구성을 유지한다.
- 선발 프리셋 데이터는 브라우저에 자동 저장하며, 불러온 구성은 기존 loadout 동기화로 서버에 보낸다.
- 프리셋 목록 선택은 미리 보기다. 선발 구성 교체는 불러오기 또는 채팅 진영 선택으로 한다.

## 추가 요청

- 사키코 음표/비눗방울의 렌더링 배율을 0.5→0.65로 변경했다. 이전보다 가로·세로 크기가 30% 증가한다.
- ‘위’의 일반·승급 특질이 염국에만 적용된다는 제보는 현재 코드에서 재현되지 않았다. 기본 데이터 8개 진영 검사를 추가했고, 운영용 데이터의 실제 배치에서도 9개 진영이 정상 획득한다. [운영용 데이터 검사 기록](yu-production-check.jsonl). 일반 특질에는 같은 가로줄 3명 조건이 있다. 제보 버그를 고쳤다고 주장하지 않는다.

## 검증

- 프리셋·선호·확장 프리셋·UI 계산·이펙트 검사 105건 통과.
- PR 관련 확장·리방·UI 검사 61건 통과.
- ‘위’ 집중 검사 2건 통과(여러 진영 및 일반·승급 조합 포함).
- 기존 loadout 검사의 3건 실패는 기대값이 export/동기화의 ops 필드를 반영하지 않은 부분이다. 이번 변경에서 loadout export/동기화 형식은 수정하지 않았다.
- 브라우저 화면 검사·진영 선택 통합 검사에서 JavaScript 오류 없음.

진영 연동과 음표 배율 변경은 로컬 작업이며, PR 병합과 별도로 아직 커밋·푸시하지 않았다.

## 0.2.2d 추가 반영

황제의 은총 가격은 5원으로 수정했고 생성기에도 반영했다. 침수 지상 적의 내려가는 높이를 -0.18에서 -0.28로 조정했다(오퍼레이터는 기존 높이 유지). 은신 안개의 가로·세로 크기를 20% 줄였다. 기존 우르수스 오퍼레이터와 겹치는 헬라그·로사·지마 더 레이징 타이드의 선발 변형은 숨겨 서버에서도 선택을 거부한다. 패치노트 최신 버전은 0.2.2d다. 렌더링·프리셋 검사 95건이 통과했다. 새 미리 보기 서버에서 페이지, 장비 데이터 가격, 외부 접속 및 게임 연결 생성/종료를 확인했다.
