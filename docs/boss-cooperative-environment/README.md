# 보스전·연합방어 배경 최종 검토

보스전의 실제 전투 좌표는 유지한다. 적 확인 구역은 뒤 중앙(열 6–14, 행 8–12)에 두고, 주변 배경은 원본 연합방어 환경을 사용한다. 적 확인 구역을 제외한 위쪽의 별도 전장은 제거했다.

윗줄 전체를 일반 타일로 채운 이전 시안은 폐기했다. 현재 경계는 중앙 열 6–14에만 남아 있고, 양옆은 각 맵의 원본 환경이다. 바닥 아래의 절단면과 지지 지형을 보존해 뒤쪽이 뚫려 보이는 현상도 수정했다.

11개 맵 × 7개 시점(보스 전체·좌측·우측·적 확인·넓은 적 확인·연합방어 우측·연합방어 전체)의 77장을 기록했다. results.json은 추가 전장 타일 0, 이전 적 확인 구역 타일 0, 현재 적의 좌표, 브라우저 예외를 기록한다. 모든 맵의 브라우저 예외는 0이었다. 사진에서 초상화 마커로 보이는 일부 모델은 로컬 검증 환경의 해당 모델 리소스가 없는 경우다.
