# 잠수부: 공격 모션 도중 이동하는 표시 수정

`enemy_1158_divman`의 생산 데이터: Attack01 0.833초, 타격 마커 0.467초. 정상 타격 후의 모션 잔여 시간은 약 0.366초다.

공격 시작 이벤트 처리 시 모델이 아직 없거나 시작 표시를 놓친 경우에도, 타격 이벤트는 도착한다. 기존 렌더러는 공격 주기가 모션보다 길면 적의 모션을 첫 프레임부터 다시 시작했다. 서버는 이미 타격을 끝내고 후반부 시간만 기다리므로, 화면에는 모션이 남아 있는 동안 이동이 재개됐다. 잠수부 기본 공격속도 조건에서 타격 이벤트 이후 약 0.467초를 화면에서 불필요하게 다시 재생할 수 있었다.

이 경우 적의 표시만 실제 타격 마커부터 재생한다. 정상적으로 공격 시작을 수신한 모션은 원래 첫 프레임부터 재생한다. 오퍼레이터의 기존 전체 모션 재생 fallback은 유지한다. 서버의 이동 제한·타격·공격 주기 코드는 이번 수정에서 바꾸지 않았다.

## 재현과 확인

- `test/render/diver-attack-recovery.test.js`: 실제 생산 데이터의 잠수부와 서버 시뮬레이션을 실행하고, 같은 이벤트/스냅샷 시점의 SpineActor 재생 상태를 비교한다. 메타데이터는 실제 게임의 것이며 Pixi 객체는 테스트용이다. 실제 모델 영상 촬영이라고 주장하지 않는다.
- 공격속도 100/200/600 및 공격 시작 이벤트 정상 수신/표시 누락 조합을 검사한다. 스냅샷은 서버의 미래 상태를 미리 읽지 않고 표시 시각에 도달한 것만 적용한다.
- 초기 코드 사본에서는 타격 프레임 재생 및 공격속도 100/200의 시작 누락 이동 검사 3건이 실패했고, 수정 후 새 검사 8개가 모두 통과했다.
- 고공속에서 공격이 연속되어 실제 이동이 없는 경우는 이동을 강제로 만들어내지 않는다. 공격 시작 취소·대역·공격 후반부·표시 순서 등 기존 회귀 검사도 함께 실행한다.

커밋·푸시·운영 반영하지 않고 로컬에만 적용했다. 이 경로는 재현·수정했지만, 모든 적의 모든 이동/모션 불일치를 전수 촬영한 것은 아니다.
