# 증강 아이콘 변경 목록

2026-10-19. 아이콘 표시만 변경했으며 증강 이름·효과·수치·추첨 조건은 변경하지 않았다. 커밋·푸시하지 않았다.

총 **35개 계열, 71종**을 변경했다. 맹약 이외 증강에서 사용하는 서로 다른 아이콘은 **22개 → 48개**로 늘었다. 같은 계열의 I·II·III은 같은 아이콘을 사용한다. 맹약 이름이 들어간 증강은 기존 맹약 아이콘을 유지한다.

## 출처와 적용 범위

- 원본 리소스 저장소: [ArknightsAssets2](https://github.com/ArknightsAssets/ArknightsAssets2/tree/44b3d7b3fad6f50ca505bc41414a2fea8eaa0c48). 원본 커밋을 고정했고 Git blob 및 SHA256을 검증했다.
- 통합전략의 선택지·성장 아이콘, 전투 훈련·전투 UI의 기호형 아이콘을 사용했다. 장비 인벤토리 그림은 사용하지 않는다. 다른 콘텐츠의 아이콘을 가져온 것이며 그 콘텐츠의 원래 효과를 증강에 추가한 것은 아니다.
- 배정: `shared/augmentIcons.js`, 선정 근거: `content/custom/augments/icon-assignments.json`, 원본 경로·고정 URL·체크섬: `content/custom/augments/icons.json`.
- 증강 선택 창·적 증강 목록·효과 목록·새 판 기록·S.W.E.E.P. 리포트가 동일한 아이콘 배정을 사용한다.
- 기존 판 기록에 저장된 이전 아이콘 경로는 유지한다. 배포 리소스 목록에도 이전 파일을 남겼다.
- 새 이미지 35개는 기호형 문양으로 구성했다. 기존 HP·방어력 아이콘 중 출처 목록에 빠져 있던 2개도 검증 목록에 보완했다.
- 리포트의 증강 아이콘 영역에 한해 검은 실루엣 강제를 해제해 선택한 문양 원본이 보이도록 했다.

## 검증
