# 스킨 이펙트 점검

- 280개 스킨의 4,449개 교체 연결을 정적 검사했다. 등록된 연결의 누락은 0개다. 좌표 설정이 기본 이펙트와 다른 연결 320개는 원본 연출 차이일 수 있으므로 일괄 보정하지 않았다. 전체 스킬의 실제 화면 검증을 뜻하지 않는다.
- 아스카론 ‘빛을 향한 어둠’ 기본 공격을 같은 전장·카메라·재생 시점에서 직접 렌더링했다. 큰 참격 연출만 0.5배로 보정했다. 기본 스킨, 타격 표식, 스킬 범위와 전투 판정은 유지한다.
- 데겐블레허의 스킨 전용 참격은 정상이라는 사용자 확인에 따라 원본 크기를 유지한다. 기본 참격의 0.5배 보정은 기본 파일에만 적용하고 스킨에 전파하지 않는다. start_02 바닥 범위도 원본 크기를 유지한다.
- 실제 캡처: `before/shots/char_4132_ascln-skin.png`, `after/shots/char_4132_ascln-skin.png`. 기본 스킨과 간소 비교도 각 폴더에 있다. 단일 효과 재생을 통한 검증이며 전체 공격·스킬 타임라인 검증은 아니다.
- 방 개수는 전투 HUD와 동일한 Bender를 사용한다. 기본 UI에 52,536바이트 폰트를 포함하고 메인 HTML에서 preload한다. 선택 리소스 워커가 받는 폰트와 분리된 URL을 사용하므로 최초 다운로드·미러 응답을 기다리지 않는다. 브라우저의 HTTP 캐시를 사용한다.
