# 오퍼레이터 설정·설명 강조·유키 마코토 번역

- **스탯 표:** `dstats`·`dstat`·`drange`·`rgrid`의 기본 CSS가 지연 로딩되는 전투 화면 스타일에만 있었다. 공통 `components.css`로 옮겨, 전투 화면 방문 여부와 관계없이 오퍼레이터 설정에서 4열 × 2행 표와 공격 범위를 표시한다. 레이아웃·수치를 새로 계산하지 않고 기존 스탯 컴포넌트를 유지한다.
- **강조:** 공통 `RichText` 설명 렌더러에서 번역 후 누락된 수치·능력치·상태 키워드·괄호 주석의 강조를 보완한다. 기존 공식 경고/감소/상태/특수 강조 태그는 그대로 우선한다. 일반 설명과 증강의 기본 강조 색 규칙을 맞췄다. 스킬·재능·특성·모듈·장비·맹약·증강에 공통 적용하며, 별도 일반 텍스트로 출력하던 선택창·리포트·진영·결과 증강·장치 설명도 같은 렌더러로 연결했다.
- **마코토:** [사용자가 제공한 나무위키](https://namu.wiki/w/유키%20마코토(명일방주))의 문장·용어로 특성, 재능 2개, 스킬 3개, 모듈 설명과 이름을 맞췄다. 실제 선택한 육성/잠재/모듈 단계의 수치는 블랙보드에서 계속 채운다. 번역 원문은 `content/custom/makoto/ko.json`에 분리해 빌드해도 유지한다.
- **원문 오류 예외:** 커뮤니티 S2의 ‘HP가 자신의 HP의 …보다 낮은 적’은 원본 중국 클라이언트의 `生命值低于结城理攻击力` 및 기존 구현과 다르다. 이 부분만 ‘HP가 유키 마코토 공격력의 …보다 낮은 적’으로 표기했다. 전투 동작은 변경하지 않았다.
- **선발 순서:** 5·6단계 모두 유키 마코토를 맨 앞으로 배치했다. 선택 여부에 따라 나머지 목록을 재정렬하지 않는다.

## 검증

- 관련 번역·설명·스탯·마코토 테스트 **34개 통과**.
- import 경계 검사 통과, 변경 JavaScript lint 오류 0개(기존 미사용 변수 경고는 유지).
- 전투 화면의 CSS를 로드하지 않은 실제 오퍼레이터 설정에서 확인: 스탯 `display:grid`, 4열, 셀 8개. 마코토 스킬 설명의 강조 요소 35개. 브라우저 JavaScript 예외 0개.
