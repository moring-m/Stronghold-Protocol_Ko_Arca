# 유키 마코토 간소 이펙트

- 대역 준비/본체 복귀: 청록색 전환 링·입자.
- 공격/회복 범위 전환: 시뮬레이션과 공유하는 실제 13칸을 보라색/녹색으로 짧게 표시.
- 3스킬 회복: 실제 회복 대상에 녹색 링. 기존 회복 이벤트가 숫자를 표시하므로 추가 0 회복 숫자나 중복 숫자를 만들지 않음.
- 2스킬 처형: 대상 적 위치의 붉은 십자 섬광·링.
- 3스킬 약점 타격: 물리/마법 결과를 금색/보라색으로 구분.
- 총공격: 시작의 붉은 신호 → 금색 섬광 → 참여 대원 각각의 실제 위치에서 13칸 영역과 충격 링.
- 간소 모드에서도 공식 처리기가 표시 완료를 반환하던 문제를 수정. 공식 모드의 대상 효과도 실제 재생 성공 여부를 반환하도록 변경하여 누락 리소스가 간소 표시를 가로막지 않게 함.
- 기존 간소 입자/링을 재사용하므로 추가 다운로드가 필요하지 않음. 맵 품질 옵션과 연결하지 않음. 전투 판정·수치·대역 시간은 변경하지 않음.

관련 렌더/전투 회귀 테스트 30개 통과, import 경계 검사 통과, 변경 파일 lint 오류 0개. 렌더 테스트는 공식 모드에서 간소 모드로 변경했을 때의 차단 해제, 실제 대상 위치, 언덕 높이, 대원별 범위, 중복 회복 숫자 방지를 확인한다.

`makotoExecute.png`, `makotoHeal.png`, `makotoAllOut.png`는 공식 이펙트를 끈 실제 게임 렌더러에서 해당 전투 이벤트를 직접 주입해 표시만 점검한 스모크 테스트 화면이다. 전투 판정 검증은 별도 실제 시뮬레이션 테스트로 수행한다. 결과는 `simple-smoke.json`에 기록한다.

Cloudflare 고정 주소 연결 절차: [안내 문서](../cloudflare-local-preview.md).

커밋·푸시·배포는 수행하지 않았다.
