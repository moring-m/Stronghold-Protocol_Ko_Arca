# 화면 언어 및 언어팩

- 첫 방문 기본 언어는 한국어. 명시적으로 고른 한국어·중국어·영어·일본어는 JSON 환경설정으로 보존한다. 이전 문자열 형식의 언어 설정도 읽는다.
- 닉네임 입력 화면과 설정에 동일한 언어 선택기를 배치했다. 화면 언어는 오퍼레이터 음성과 독립적이다.
- 한국어는 기본 번역 계층을 사용한다. 중국어·영어·일본어는 선택 시 해당 언어의 별도 다운로드 안내를 보여 준다. 중국어 팩은 한국어로 추가한 콘텐츠의 중국어 번역을 포함한다. 취소하거나 실패하면 기존 언어를 유지한다.
- 선택한 팩의 용량과 다운로드 진행도를 표시한다. SHA-256 및 JSON 검증 후 CacheStorage에 보관하며, 설치된 팩은 다시 내려받지 않는다. 일본어 원본 팩의 영어 대체 번역도 의존 파일로 함께 받는다.
- UI는 원본 저장소의 `public/i18n/en.json`, `ja.json`을 재사용했다. 일본어 UI는 원본 언어팩의 번역 상태를 따른다. 게임 데이터는 `tools/build-i18n.mjs`로 ArknightsAssets/ArknightsGamedata 공식 EN/JP 클라이언트에서 생성했다.
- 커스텀 모드·공개 방·연습실·설정 등 추가 UI의 기본 용어는 `public/i18n/<언어>/fork.json`에 보완했다. 공식/원본에 없는 개별 커스텀 설명은 보완 사전 `audit.json`에 연결했다.
- 공식 데이터 번역은 표시용 오버레이이며 시뮬레이션의 원본 데이터는 바꾸지 않는다. 언어 전환은 새로고침으로 적용된다.

## 갱신

```sh
NODE_USE_ENV_PROXY=1 node tools/build-i18n.mjs --lang en --data content/production/data --out public/i18n/en/data.json
NODE_USE_ENV_PROXY=1 node tools/build-i18n.mjs --lang ja --data content/production/data --out public/i18n/ja/data.json
node tools/build-korean-ui.mjs
node tools/build-language-packs.mjs
```

실제 브라우저 테스트: 기본 한국어, 네 언어 선택 및 재접속 유지, 선택 언어로 표시되는 다운로드 안내, 취소, 공식 영문 오퍼레이터 이름, 설정에서 전환, 설치된 언어팩 재사용을 검증한다.

최초/전체 리소스 다운로드 안내에 화면 언어 선택을 추가했다. 선택 즉시 안내 전체를 해당 언어로 표시하며, 확인 후 해당 언어팩을 설치하고 기본 리소스 다운로드를 이어간다. 한국어는 추가 언어팩 다운로드가 없고 중국어도 커스텀 콘텐츠용 번역 팩을 함께 받는다. 개별 음성/공식 이펙트 다운로드에는 이 선택기를 추가하지 않는다.

## 모바일·다국어 레이아웃 점검

- 원인: 1400px 이하 로비 규칙과 터치 화면 규칙이 제목을 별도 행에 배치했다. 터치 화면의 미디어 조건도 높이 600px 이하에 한정되어, 배율을 축소하면 다른 규칙이 적용되었다.
- 수정: 터치 화면은 높이와 무관하게 제목·왼쪽·오른쪽 도구를 같은 행에 배치한다. 제목은 중앙에 유지하고 좁은 화면의 도구 영역은 내부 스크롤로 처리한다.
- 언어 선택은 설정의 다른 선택기와 동일한 열·폭·높이·기본 화살표를 사용한다. 언어 항목 이름은 선택 언어로 번역한다.
- 로비 설명·인원·관전 설정·설정 항목/도움말·다운로드 상태와 개별 음성/이펙트 안내를 보완했다. 공식 데이터의 이름 사전도 표시용 번역 계층에 연결했다.
- 숫자와 접미사가 별도 DOM 노드로 출력되던 인원 버튼은 완성된 번역 문장으로 렌더링한다. 바닥맵 수 등 숫자가 들어간 안내도 패턴 번역을 추가했다.
- 영어·일본어·중국어의 긴 모드 이름, 실험실 설명, 관전 문구가 카드 밖으로 잘리지 않도록 배치와 글자 간격을 조정했다.
- 실제 브라우저에서 네 언어 × 1280×591 / 1680×774 / 844×390 / 390×844를 검증했다. 설정의 네 탭에서 항목 이름에 한국어가 남는지도 검사했다.
- 실제 화면: `layout/<ko|en|ja|zh>-lobby.png`, `layout/<ko|en|ja|zh>-settings.png`.

## 전체 문자열 검사와 수정 결과

검사 목록은 [text-inventory.csv](text-inventory.csv), 언어별 집계는 [coverage.json](coverage.json)에 기록했다. UI·서버 안내·패치노트와 운영/커스텀 데이터의 한중 문자열 **15,877개**를 추출했다. 에셋 경로·아이콘 메타데이터는 제외했다. 장식용 영어 표제와 코드 식별자는 번역하지 않는다. 정적 목록 외에 서버가 재작성한 수배 설명도 검사했다.

| 문제 | 수정 | 확인 결과 |
|---|---|---|
| 패치노트 본문이 `data-i18n-skip`으로 제외됨 | 제외 속성 제거 및 전 버전 제목·항목 번역 연결 | 658개 제목·항목을 영어·일본어·중국어로 실제 번역기로 검사 |
| 추가 오퍼레이터의 한국어 이름·설명이 원본 언어팩 키와 불일치 | 캐릭터 ID와 공식 한·영·일·중 데이터 대응, 한국어 원문 오버레이 지원 | 언어 변경 시 운영 게임 데이터는 수정하지 않고 표시만 변환 |
| 추가 증강 설명의 수치·용어가 기계 번역에서 누락 또는 변형됨 | 165개 증강 설명을 세 언어의 명시적인 효과 문장으로 작성 | 모든 설명의 번역 존재 및 숫자 보존 검사 |

| 언어별 길이로 모바일 제목·설정 선택기 배치 불일치 | 기존 상단바 한 줄 배치 및 선택기 열·폭 통일 | 네 언어 및 네 화면 크기 브라우저 검사 |

현재 추출 목록에서 번역 누락·잔여 원문 문자·자리표시자 검증 오류는 **0건**이다. 이는 자동 검사 범위의 결과이며 모든 문장의 자연스러움을 보증하는 수치는 아니다. 공식/기존 번역을 우선 재사용했고, 없는 설명·과거 패치노트에는 수동 보완과 기계 번역을 사용했다. 핵심 증강 효과와 라이타니엔·비비아나 설명은 수치·효과 방향을 별도로 교정했다.

보완 번역에는 Google 번역의 결과 일부와 로컬 NLLB-200 distilled 600M 결과가 포함된다. NLLB 모델은 `JustFrederik/nllb-200-distilled-600M-ct2-int8`의 CTranslate2 변환본이며 원본은 Meta NLLB-200, CC-BY-NC-4.0 라이선스다. 모델·런타임·다운로드 캐시는 저장소에 넣지 않는다.

### 전장 #01

추가 맵 선택에 포함하고 험지·극한·초월에서 선택 가능하게 했다. 표준에서는 이 추가 선택지를 숨긴다. 표준의 원래 기본 전장 #01은 그대로 유지한다. 기본 맵 추첨 풀과 원본 데이터는 바꾸지 않는다.

### 첸 더 던스트릭 3스킬

검기의 `현재 적 HP × 스킬 비율` 계산값이 **300,000 초과**이면 그 타격을 무효 처리한다. 300,000 이하는 기존 최소 공격력 배율과 방어 계산을 따른다. 커스텀 보스 단일 피해 상한을 0·100,000·1,000,000으로 설정해도 이 무효 조건은 유지한다. 일반 공격 및 3스킬의 일반 공격 강화는 변경하지 않았다. 5/6단계, 일반 적/보스, 경계값 직전·동일·초과를 검증했다.

## 고유명사·동적 문장 재점검

이전 자동 검사의 “누락 0”은 사전 존재와 원문 문자 잔여만 확인한 결과였다. 공식 용어 준수와 문장 의미를 보증하지 못했고, 실행 중 생성되는 일부 문장이 누락되어 있었다. 검사 범위를 다음과 같이 보완했다.

- **속세의 음**: 임의 번역 `Worldly Melody` / `俗世の音`을 공식 **Voice of Mundane / 塵界の音**으로 수정. 중국어는 **尘世之音**. 근거는 공식 클라이언트 `enemy_handbook_table.json`의 `enemy_1530_white.description`에서 언어별 동일 레코드에 등장하는 표현이다. [공식 영문 데이터 추출본](https://github.com/ArknightsAssets/ArknightsGamedata/blob/master/en/gamedata/excel/enemy_handbook_table.json)
- 라이타니엔 맹약의 일반·강조·중첩 계산 설명, 관련 장비와 증강, 과거 패치노트에서도 같은 명칭을 사용하도록 교정했다. 강조 태그가 있는 설명은 강조 표시를 유지한다.
- 추가/선발 오퍼레이터의 이름은 공식 캐릭터 ID로 대응한 한국어·중국어·영어·일본어 이름을 우선 적용한다. 고유명사 교정 근거와 생성 스크립트는 `tools/i18n/official-terms.json`, `curate-official-terms.mjs`에 저장했다.
- 증강 CSV 기본 문장 외에 맹약·장비를 조합한 최종 이름/설명을 생성하여 번역 사전에 추가했다. 기존 정적 목록에서 빠졌던 생성 문장과 우르수스·라이타니엔 보고서 설명도 검사한다.
- `formatBondEffect`는 **템플릿 번역 → 중첩 수치 채우기** 순서로 변경했다. 수치가 들어간 문장을 사전에서 찾지 못하던 문제를 해결했고, 라이타니엔의 활성 인원별 지속시간도 언어와 강조 태그에 관계없이 채운다.
- 브라우저에서 모든 맹약의 중첩 0/25/137 설명과 보고서 설명, 전 라운드의 생성 증강 명칭/설명을 검사했다. 라이타니엔 25중첩에서 공격력 비율 1.25%, 3인 지속시간 5초·6인 11초와 공식 명칭을 확인했다.
- 관련 단위/브라우저 테스트 18개 통과. 전체 문장이 원어민 수준으로 검수되었다는 의미는 아니며, 나머지 기계 번역 문장에는 추가 교정이 필요할 수 있다.

공식 명칭과 동적 증강 사전을 재생성할 때는 다음 순서를 사용한다.

```sh

node tools/i18n/curate-runtime-catalog.mjs
node tools/i18n/audit-all-text.mjs

node tools/build-korean-ui.mjs
```

## 리포트·닉네임 힌트·증강 강조 보완

- 닉네임 입력 힌트는 입력 노드의 번역 제외와 동적 숫자 삽입 때문에 원문이 남았다. `t()`의 `{max}` 변수를 사용해 입력 속성 자체를 선택 언어로 렌더링한다.
- 증강 선택창은 숫자에 강조 태그를 먼저 붙여 사전의 원문 키와 불일치했다. `formatAugmentDescription`에서 번역 후 강조하도록 바꾸었다. 같은 함수를 리포트, 증강 선택, 적용 중인 증강 툴팁, 적 증강 목록에 사용한다. 수치·핵심 용어를 강조하고 괄호의 조건/제한은 보조색으로 구분한다.
- 라이타니엔·우르수스 인게임 설명을 표시 전용 템플릿으로 통일했다. 현재 중첩의 계산된 수치는 유지하고, 중첩당 계산식과 기본값/추가값의 장황한 분해 대신 다른 맹약처럼 “중첩 수에 따라 변경”을 표시한다. 6인 조건은 기존 구분 색을 유지한다.
- 시뮬레이션의 데이터·효과·계산식은 변경하지 않았다. 25중첩 기준 라이타니엔 1.25%/활성 6인 11초/+6초, 우르수스 공격력 +45%/최대 HP +32.50%/공격력 가산 비율 10.38%를 확인했다.
- 한국어·영어·일본어·중국어로 실제 닉네임 화면과 S.W.E.E.P. 네 탭을 열어 원문 잔여와 증강 강조를 확인했다. 관련 테스트 15개 통과.
