## 기존 조건 보존 확인

- 라이타니엔: 속세의 음 기본 80 + 공격력 기본 1% + 중첩당 0.01%, 동일 시전자/대상 0.1초 재부여 제한, 6인 지속시간 기본 +5초 및 25중첩당 +1초. 에벤홀츠 +1%/+2%, 비비아나 8회 피해 조건과 라이타니엔/카시미어·기민 중첩 등 데이터와 전투 경로 점검.
- 증강: 획득 확정 단계에서 적용, 개인/적 선택·투표·밴 및 중복 후보 제한·확률·리롤 설정. 기존 소드마스터 단계별 확률과 추가 공격 0.18초 유지.
- 커스텀: 일반/히든 보스 배율, 일반 적 배율 분리, 기본 30만 피해 상한의 초과분 절단, 중첩 상한 해제, 공통 전략과 개인 전략의 별도 적용.
- 8인: 4개 연합방어 전장, 4배 전투시간, 9개 공동 선택, 맹약/오퍼레이터 밴 제거, Touch 네 전장 설치, 퀸투스 합성 방지.
- 프리셋: 선호·선발 진영 연동과 불러오기 경로 검증.
- 원본의 몸체/충돌 범위 개선과 르무엔 수배 대상별 상태 관리, 새 승객 탑승/하차 기능을 유지한다. 사용하지 않는 옛 `tier1..6.js`의 설명·코드를 현재 동작으로 잘못 판단하지 않도록 실제 `nativeRegistry → ops/*` 등록을 기준으로 확인했다.

## 검증과 한계

- 적 특수 효과·8인 기습/치료·닌동 첫 추가 피해 등 집중 검증: 300개 통과.
- 증강·라이타니엔·사키코·일반/히든 보스 배율·공통 전략·승객·프리셋·한국어 등 별도 집중 검증: 149개 통과. 위 실행과 일부 항목이 겹치므로 합산한 고유 테스트 수를 뜻하지 않는다.
- 오퍼레이터·특질·장비·소환물의 노출 설명을 브라우저 번역기로 검사: 중국어 잔여 0, 중복 문장 0.
- 게임 UI 소스 문자열을 실제 한국어 번역기로 검사: 남은 한 항목은 주석을 문자열로 오인한 추출 결과이며 표시 문구가 아니다. 플러그인 작업대 UI 문자열 검사도 중국어 잔여 0.
- 내부 중국어 데이터 원문은 전투 수치·조건 파싱에 쓰이므로 한국어 표시 사전만 수정했다. 데이터 원문을 번역해 전투 로직을 바꾸지 않았다.
- 분리 적/오퍼레이터 코드의 미정의 변수 검사는 오류 0. 기존 미사용 대입 경고 2개는 남는다.
- 전체 콘텐츠 테스트는 병합 전 로컬에도 실패 항목이 존재한다. 집중 검증 통과를 전체 전투 효과의 완전한 정상 작동으로 확대 해석하지 않는다. 수치·시간을 고정한 예전 검사와 커스텀 데이터/최신 전투 프레임의 차이를 구분해야 한다.

### 전체 검사 비교와 검사 자체의 보정

동일한 원본 로컬의 콘텐츠 검사도 비교했다. 병합 전에는 2,625개 중 2,458개 통과·167개 실패였다. 수정 후 넓은 검사에서는 2,704개 중 2,534개 통과·170개 실패였으며, 실패 제목을 중복 제거해 비교했을 때 새로 실패한 것은 3등급 전체 검사 하나였다. 이를 개별 재현한 결과 인포서의 피해 없는 밀치기 스킬이 일반 공격 기회를 없앤 경우를 ‘피해를 주지 못함’으로 판정한 검사 문제였다. 실제 밀치기 이펙트의 대상 수가 양수인지 검증하도록 수정한 뒤 해당 검사도 통과했다. 별도 맵 검사는 새로 늘어난 맵 13개를 이전의 11개로 고정해서 실패했으며, 네 전장의 진입점을 모두 검증한 뒤 맵 개수를 13개로 갱신했다. 두 검사 재실행 모두 통과했다.

화면 복귀·한국어·8인 렌더링·보스 사망·밴 규칙·커스텀 규칙 재검증은 27개 모두 통과했다. 기존 실패 항목(고정 공격/시전 프레임, 원본만을 가정한 콘텐츠 집계 등)은 이번 검토로 전부 해결했다고 주장하지 않는다. 전체 검사에는 여전히 실패가 있으므로 전체 통과 상태의 배포 승인 보고서가 아니다.

이네스·호른 등의 수정 여부는 오래된 통합 tier 파일이 아니라 현재 등록되는 ops 파일로 대조했다. 중간 대조에서 통합 tier 파일의 차이를 이식 후보로 검토했으나, 실제 실행되는 ops 파일에 이미 들어 있던 수정과 원본의 새 개선을 우선하여 최종 코드에 반영했다. 현재 실행 경로의 첫 피해 추가 타격, 기습·스킬 조건 등 집중 검증 결과를 근거로 판단했다.
