## 로컬 실행

의존성은 기존 로컬의 `node_modules`, 커스텀 테스트 데이터는 기존 `.cache`를 재사용한다. 커밋된 배포 데이터로 HTTP 서버를 확인했다. 서버를 실행하려면 이 폴더에서 다음을 사용한다.

```bash
node --input-type=module -e "import {startServer} from './server/index.js'; await startServer({port:3048,host:'0.0.0.0',dataDir:process.cwd()+'/content/production/data'});"
```

현재는 검증용 서버를 종료했으며 운영 서버는 변경하지 않았다. 사용자 요청 전 커밋하지 않는다.
