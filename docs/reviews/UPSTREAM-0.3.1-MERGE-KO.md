## 주요 상류 변경의 선택

1. **린 시 S3**: 지속 이중 공격/코인 축적을 유지하고 10코인에서 자동 종료·폭발하지 않는 원본 0.3.1 변경을 반영. 별도 커스텀 요구와 충돌하지 않는다.
2. **캐서린 전략**: 플레이어당 게임 전체에서 실제 획득한 변이 세포 1회 제한을 반영. 보기만 한 경우에는 차감하지 않고, 획득 후 대기 중 선택지에서도 제거한다. 퀸투스 지급은 독립적으로 취급한다. 커스텀 보관 공간 정책은 유지한다.
3. **연합 방어 파생 적**: 소환·분열한 파생 적의 LP 중복 차감을 막는 기존 수정에 상류의 서버 검증을 통합한다. 원래 예정된 적과 런타임 파생 적을 구분하는 검증을 보강하는 방향이다.
4. **공식 이펙트**: 루트의 편집용 이동값 제거, 부착점 회전, 축별 스케일, 뒤 레이어 정렬, 회수 투사체, 채널링 루프 및 폼 전환 처리를 통합한다. 회수 투사체는 실제 반환 속도와 움직이는 시전자의 현재 위치를 사용한다.
5. **공식 장판/위**: 적별 장판 연결과 위 3스킬 벽 수명·방향·폴백 표현을 반영한다. 공식 효과 사용 시 기존 절차형 효과를 함께 그리지 않는 커스텀 정책을 유지한다.
6. **개인 외형·테마·플러그인 UI**: 개인 스킨과 다른 참가자 스킨 표시, 테마 변수, 공지 및 선택 창의 기반을 반영한다. 한국어 설정 UI와 최초/선택형 리소스 다운로드는 기존 커스텀 흐름을 유지한다.
7. **오퍼레이터 특질 DSL**: 획득·배치·준비·전투 효과를 반영한다. 중첩을 바꿀 수 있는 선언은 서버 권한으로 실행한다. 기존 클래스 메서드가 상류 분리 모듈을 가려 새 훅이 빠지는 부분을 실제 획득/배치 경로에 연결했다.
8. **개발 도구**: 플러그인 제작·검증·단독 시험 도구와 개발용 테스트 방 기반을 반영한다. 개발용 테스트 방은 서버의 명시적 활성화가 필요하며 기존 연습실을 대체하지 않는다. 테스트 기록은 통계에 저장하지 않는다.
9. **맵 리소스**: 상류의 무손실 노멀/금속/발광 맵 처리와 PMREM 해제를 반영한다. 사용자 요청의 사막 모래 셰이더, 물, 장판, 색조·명암 및 맵 품질과 전투 이펙트의 독립성은 보존한다. 발광 처리를 추가한 뒤 기존 명암 보정을 유지한다.
10. **저장 공간**: 영구 저장소 요청과 미사용 가져온 리소스 정리 기반을 반영한다. 기존 캐시의 대량 `keys()` 열거를 피하는 처리와 운영 릴리스 간 리소스 재사용은 보존한다.

## 추가 요청: 오퍼레이터별 간소 폴백

전체 설정의 전역 활성 상태 대신, 각 오퍼레이터가 실제 공식 인덱스에 있는지 판정한다. 디아만테처럼 등록되지 않은 오퍼레이터는 공격·스킬·피격·은신/상태/스킬 범위 표시를 간소 방식으로 사용한다. 등록된 오퍼레이터는 기존 공식 효과를 사용한다. 커스텀 플러그인 효과가 처리한 이벤트는 다시 간소 효과로 중복 표시하지 않는다. 추출은 나중에 진행한다.


## 실제 원인과 수정 결과 상세

1. **보스전 2배속**
   - 기존 문제: 일반 전투의 강제 속도 정책과 보스의 시계가 별도였다. 시뮬레이션만 빨라지면 서버 마감·표시 시간·초과 시간과 서로 어긋날 수 있었다.
   - 수정: 커스텀 `bossBattleSpeed`를 일반·히든 보스의 공통 속도와 게임 시간에 연결했다. 서버 마감은 게임 시간/속도, 화면 시간은 실제 경과×속도로 계산한다.
   - 결과: 기본 1배속, 선택 시 시뮬레이션과 초가 함께 2배속. 일반 전투 정책은 유지한다.
2. **폰트 다운로드 404**
   - 원인: 폰트 선언에 원본 TTF/OTF와 선택형 WOFF2 경로가 함께 들어 있었고, 다운로드 수집기가 대체 경로까지 모두 필수 파일처럼 수집했다.
   - 수정: 원본 경로가 있으면 원본을 선택하고, WOFF2만 있는 선언은 WOFF2를 선택한다.
   - 결과: 제보된 Bender Light/Regular, Novecento Wide Normal의 미존재 WOFF2를 필수 다운로드로 요청하지 않는다. 미러를 제거하거나 폰트 자체를 바꾸지 않았다.
3. **가상적:총의 대상 선택·공속**
   - 확인: PRTS는 현재 방어력 최댓값 우선, 동일 대상 공격마다 +80 공속(최대 5회), 대상 변경 시 초기화라고 명시한다. 최대 공속에 도달했다는 이유만으로 강제 교체하는 조건은 없다.
   - 결과: 침식으로 현재 방어력 순위가 역전되면 공격 대상이 바뀌는 실제 전투를 검사했다. 순위가 유지되는 한 같은 대상을 계속 공격할 수 있다.
4. **가상적:총 계열의 추가 패턴 차이**
   - 돌진 원인: 돌진 시작 때 목표의 좌표만 저장하여 움직이는 대상을 따라가지 못했다.
   - 돌진 수정: 선택한 유닛을 추적한다. 대상이 퇴장하면 마지막 좌표를 유지하되 도착으로 판정하지 않고 남은 지속시간까지 유지한다.
   - 피해 전달 원인: 도감의 요약 문구를 추정하여 다른 파생 유닛에도 피해를 분배하고, 가까운 총을 선택했다. PRTS 상세 설명은 어그로가 가장 높은 총 1명에게 동일한 무출처 HP 손실을 전달한다.
   - 피해 전달 수정: 최고 어그로 총 1명만 전달받도록 변경. 다른 파생 유닛에 대한 추가 전달은 제거했다.
   - 횟수 보호막 원인: 물리·마법용 보호막이 트루 대미지까지 차단했다. 트루 대미지는 통과하고 보호막 횟수도 소비하지 않도록 변경했다.
   - 결과: 이동 목표 추적, 퇴장 후 지속시간, 가까운 총과 최고 어그로 총이 다를 때의 전달 대상, 트루 대미지 관통을 별도로 검사했다. 맵 템플릿이 해당 돌진을 비활성화한 일반 보스전은 기존 원본 템플릿을 따른다.
   - 루시엔: 순간이동이 한 프레임에 끝나던 구현을 0.5초 이동으로 수정했다. 이동 중 무적·공격/이동 중단·강제 이동 및 불균형 면역, 1초간 저지 불가를 분리하고 환영 소환은 성공한 이동에만 연결했다.
   - 알리스테어: 방패 방향이 장비가 놓인 위치로 결정되던 것을 최초 오른쪽, 이후 좌우 교대로 수정했다.
   - 알리스테어의 충격식 시전 장치: 기존 구현은 ‘보스의 다음 공격을 아츠로 바꾸고 무장 해제’하는 대체 효과였다. PRTS대로 장비 위치에 독립적인 황금의 메아리(`trap_185_vtlntw`)를 소환한다. 장치의 8000 HP/425 ATK/150 DEF/70 RES, 3.8초 아츠 공격과 마름모 2칸 범위를 적용하고, 보스 자신의 공격 타입은 바꾸지 않는다. 이 장치의 아트는 로컬 추출본에 없어 일반 표시 폴백을 사용한다. 장비를 소모하여 장치를 생성하는 실제 전투 검사를 추가했다.

5. **리롤마다 캐시 준비 진행도 표시**
   - 원인: 로스터 변경을 처리하는 준비 큐가 완료했던 이미지·모델도 다시 준비 대상으로 잡았다. 이 진행도는 네트워크 다운로드뿐 아니라 디코딩·모델 준비도 포함한다.
   - 수정: 준비 완료 키를 기억하여 같은 대상을 중복 처리하지 않는다. 실패한 작업은 완료 처리하지 않아 다음 변경 때 재시도한다.
   - 결과: 이미 준비된 오퍼레이터만 나오는 리롤은 같은 작업을 다시 큐에 넣지 않는다. 처음 보는 오퍼레이터는 정상적으로 준비한다.
6. **제국 드론 공식 조준·범위**
   - 조준 원인: 공식 투사체가 발사 때의 고정된 지점만 참조했다.
   - 수정: 조준 확정 전에는 대상의 현재 렌더링 위치를 참조하고, 시뮬레이션의 목표 변경·확정 이벤트를 받는다. 확정 뒤에는 목표가 이동해도 확정 좌표를 유지한다.
   - 범위 원인: 시뮬레이션과 기존 간소 범위는 확장됐지만 공식 스캔 프리팹에는 현재 반경이 반영되지 않았다.
   - 수정: 공식 스캔 효과의 루트 배율을 현재 반경/기본 반경으로 갱신한다. 공격 속도에 따른 포탄 시간과 개별 발사 타이머는 유지한다.
   - 결과: 좌표 추적·교체·확정·늦은 확정과 연속 발사 검사를 추가/유지했다.
7. **래트킹·제셀톤 등의 체력 50% 효과 위치**
   - 원인: 발/피격점/머리 부착 효과의 로컬 위치에 모델 Graphic 기울기가 반영되지 않았다. 운영 프리팹 `skulsr_buff_01_start`도 해당 계열이다.
   - 수정: 상류의 공통 부착점 회전을 적용한다. 개별 유닛에 임의의 한 타일 오프셋을 더하는 보정은 하지 않는다.
   - 결과: 같은 부착점을 쓰는 다른 효과에도 공통 적용된다. 합성 좌표 검사를 통과했으며 실제 전체 추출본의 모든 유닛을 시각 검수한 것은 아니다.
8. **판매·구매 단축키 대상**
   - 원인: 마지막 선택 대상이나 타일만 쓰면 커서가 모델 머리 위에 있어도 뒤 타일을 선택할 수 있었다.
   - 수정: 키 입력 시 포인터를 다시 검사하는 기존 처리를 보존하고, 렌더링된 모델의 화면 경계와 앞뒤 순서를 우선 검사한다.
   - 결과: 선택 대상과 커서 대상이 다른 DOM 폴백의 실제 키보드·포인터 검사 통과. 이미지/모델을 쓰는 경계 계산도 같은 대상 조회 경로에 연결했다.
9. **의태**
   - 확인 결과: 지정 대상과 동일한 기본 오퍼레이터의 미승급 복사본을 보드·대기석·임시석에서 세며, 의태 획득은 재고를 요구하지 않는다. 지정 대상과 다른 종류의 2명은 조건에 해당하지 않는다.
   - 결과: 해당 경로에서 재고 때문에 복제가 차단되는 오류는 재현되지 않았다. 재고 소진 상태의 의태 검사도 통과했다. 확인되지 않은 새로운 규칙은 추가하지 않았다.
10. **데겐블레허 3스킬 등 공식 효과 크기**
    - 원인 범위: 기존 렌더러가 프리팹 루트의 편집용 이동값과 입자별 비균일 축/현재 로컬 스케일을 원본과 다르게 처리할 수 있었다.
    - 수정: 루트 이동·회전, 피벗, 축별 스케일에 관한 상류 공통 수정을 통합했다.
    - 결과: 합성 프리팹의 수치·방향 검사는 통과한다. 데겐블레허의 실제 공식 아트 크기를 원본 클라이언트와 나란히 비교한 결과는 아니므로 임의 축소율을 확정하지 않았다.
11. **디아만테 등 공식 효과 미보유 오퍼레이터**
    - 원인: 운영 공식 인덱스에 디아만테가 없으며, 기존 추출기는 커스텀 생산 데이터의 오퍼레이터를 빠뜨릴 수 있었다. 전체 모드는 전역으로 간소 효과를 억제했다.
    - 수정: 추출기의 생산 데이터 수집을 보완하고, 실제 공식 인덱스에 없는 오퍼레이터는 간소 공격·스킬·상태 효과를 사용하도록 오퍼레이터별로 판정한다.
    - 결과: 공식 효과가 있는 오퍼레이터는 공식, 없는 오퍼레이터는 간소로 동작한다. 사용자 지시에 따라 실제 클라이언트 추출은 보류했다.
12. **공식 모드의 커스텀 은신 효과**
    - 확인/수정: 공식 효과가 실제 사용되는 오퍼레이터에는 커스텀 은신 안개와 일반 상태 효과를 겹쳐 표시하지 않는다. 공식 효과가 없는 오퍼레이터의 간소 폴백에는 간소 은신을 허용한다.
    - 결과: 전체 모드의 공식/간소 혼용 기준이 전역 옵션이 아닌 해당 오퍼레이터의 실제 보유 여부와 일치한다. 속세의 음 등 공식 대체물이 없는 별도 커스텀 효과의 기존 정책은 유지한다.

## 병합 후 발견해 보완한 연결 누락

- 특질 장비 지급의 `fromPool:false`와 `requirePool:false`가 서로 달라 고정 보상이 재고에 막혔다. 두 호출 형식을 호환하고 실제 획득 경로에서 검사했다. 기존 커스텀의 무료 장비 `stockCopies:0`와 혼합 합성 시 재고분 합산은 유지했다. 상류의 고정 지급품까지 재고 소유 수에 더하는 정책은 기존 정책과 달라 채택하지 않았다.
- 새 분리 모듈의 메서드가 기존 커스텀 클래스 메서드에 가려져 새 훅이 실행되지 않는 부분이 있었다. 획득/배치 특질, 선택 창, 테스트 명령, 보스 시작·마감과 결과 제출의 호출을 연결했다.
- 플러그인의 준비 중 스킬/모듈 변경은 서버 허용·UI 버튼·부분 설정 병합·소환물 재검증을 함께 연결했다. 기존 브리핑/전략 선택 단계의 조정과 커스텀 오퍼레이터/모집 선택 설정은 유지한다.
- 장비 편향 상점은 활성 맹약을 현재 시점에 계산한다. 변형 구조체 강화 규칙은 서버·전투 입력·전투의 플레이어 상태·클라이언트 교체 창에서 동일하게 읽는다. 규칙을 끄면 기존 칸 정책이다.
- 개인 스킨 동기화를 메인 진입 경로에 연결하고, 스킨이 지정되지 않은 승급 오퍼레이터의 아트 참조는 E2 초상화를 선택하도록 수정했다.
- 규칙 충돌 안내가 플러그인 이름과 규칙을 잃지 않도록 상류의 현지화 오류 설명을 반영했다.
- 외형 플러그인 예제의 음성 참조를 현재 언어별 음성 구조와 호환되게 바꾸고 필요한 추가 권한을 명시했다. 예제 검사: 문제 0, 경고 0.

### 전체 검사에서 남은 항목

- 광범위 match 검사 스냅샷: 1113개 중 1025 통과, 86 실패, 2 건너뜀. 이 실행 뒤 캐서린 제외 목록, 무료 장비 재고, 콘텐츠 선택 정보 전달과 명령 생성기 오류를 수정하고 해당 묶음을 다시 통과시켰다. 광범위 전체를 다시 돌려 모두 통과시킨 숫자로 대체하지 않는다.
- 이전 커밋을 별도 임시 기준본으로 실행했다. 이전 코드에서도 보스 파트너 미리보기/관전 선호 등 같은 실패가 재현됐다. baseline은 검사 파일 수도 다르고 일부 로컬 vendor/언어 파일이 없어 단순 실패 수 차이를 개선 수로 주장하지 않는다.
- 기존 테스트가 가정하는 일부 규칙은 커스텀과 다르다. 무료 장비 재고를 소유 수에 더하는 상류 검사, 개인 선택 재고의 협력 배수, 탄약/에너지 단일 설정, 기존 사망 효과 시간 등의 기대값을 맞추려고 사용자 정책을 바꾸지 않았다.
- 전체 플러그인 검사 스냅샷: 512개 중 497 통과, 14 실패, 1 건너뜀. 이후 특질 원본 바이트 비교 기준, 승급 초상화, 최소 GameData 스텁 처리, 외형 예제, 변형 규칙 연결을 수정해 관련 개별 검사를 재실행했다. 일부 루프 검사/상점 재고 스텁은 커스텀 구현과 기대가 다르며, 스크립트의 5초 preflight 시간 초과 검사도 남아 있다. preflight/프로브 코드는 기존 커밋과 동일하므로 이번 병합의 변경으로 단정하지 않는다.
- 로컬에 `data/i18n/ja.json`, 일부 추출된 맵/공식 아트가 없어 해당 실파일 검사와 엔진 2D/3D 전체 브라우저 검증은 완료하지 못했다. 원본 아트를 저장소에 임의로 포함하거나 누락을 통과로 처리하지 않았다.
- 데겐블레허 등 실제 효과의 원본 클라이언트와 동일한 표시 크기, 모든 적의 반체력 효과 위치를 실제 아트로 전수 비교한 상태는 아니다. 공통 좌표/스케일 코드와 관련 프리팹/합성 검사는 확인했다.
- PRTS 모바일에서 총·주·관·퀸투스·사미와 총의 파생 유닛 본문을 확인했다. 루시엔/알리스테어 문서는 일반 페이지 요청의 503/리다이렉트 오류 후 모바일 API로 본문을 확보해 대조했다. 황금의 메아리 장치 본문도 확인했다. 일반 스테이지의 기본값과 위수 프로토콜 템플릿의 덮어쓰기 값은 구분하며, 템플릿의 명시적 999초 등은 기본 적 문서 값으로 덮지 않는다.

### 선택하지 않은 추가 규칙

상류의 고정 장비 지급품 소유 수 재고 차감은 기존 커스텀의 무료 지급품 재고 면제와 다르므로 제외했다. 보상 자체는 재고가 비어도 지급되고, 실제 상점 구매/반환/합성은 구매에 사용한 재고분만 계산한다. 플러그인 및 새 내부 호출의 옵션 이름만 호환했다.

- 시작 HP 전략: 시작 HP 계산이 개인 전략의 totalHp만 읽었다. 공통 전략의 기본 HP 대비 증감을 합산한다. 예: 기본 30에서 개인/공통 골리아가 각각 45이면 60, 개인 스즈란 20 + 공통 골리아이면 35. 최종 HP는 최소 1이다.
- 중복 적용: 개인·공통 파가니니는 각각 소비 자금을 누적하여 55에서 보상을 한 번씩 지급한다. 아미야는 별도 전투 버프로 적용되어 100 공격력에 각 20%씩이면 140이다. 터치의 중복 수에 따른 팀 의료 오퍼레이터 강화도 기존 테스트로 확인했다. 공통 전략 체크박스 자체는 같은 항목을 여러 번 추가하지 않는다.
- 8인 오퍼레이터 밴: 커스텀 설정에 초상화가 있는 오퍼레이터 밴 목록을 추가했다. 선택은 저장·정규화·설정 집계에 포함되며 8인의 맹약 밴 제거 처리에서도 유지된다. 해당 오퍼레이터는 공동 재고 및 증강 후보에서 제외하고, 일반/승급 형태를 직접 보상으로 지급하는 경로도 차단했다. 선택하지 않은 8인 게임에는 기존처럼 자동 밴이 없다.
- 검증: 공통 전략·명시적 오퍼레이터 밴·비활성 맹약 전략 보상·개인 영입 밴·설정 재추첨 테스트 27개 통과. import 경계 검사, 수정 UI 문법 검사, diff 공백 검사 통과.
- 전체 기존 전략 테스트는 37개 중 34개 통과. 캐서린의 구형 보상 기대값, 에르멩가르드의 부활 우선순위 기대값, 이에 따른 커버리지 실패 3개는 변경 전 기준 로그에서도 확인되는 미해결 항목이다. 이번 결과를 전체 테스트 통과로 해석하지 않는다.

## 최신 요청 반영: 보스 패턴 원복·전투 시간·데겐블레허

이 절이 앞서 작성한 PRTS 보스 패턴 변경 설명보다 우선한다. 사용자의 요청에 따라 `server/sim/content/bosses.js`는 v0.3.0c1(현재 HEAD)과 동일하게 되돌렸다. 총의 돌진 추적, 부품 실드/전이, 루시엔 이동/무적, 알리스테어 방패·황금 잔향 소환을 포함한 이번 PRTS 패턴 수정 전체를 철회했다. Battle의 루시엔 전용 이동 중 불균형 방지 변경도 원복했다. 보스 스탯 커스텀 설정, 피해 상한, 기존 전투 효과 수정, 2배속 옵션은 유지한다.

- 전투 시간: 커스텀 게임 규칙에 일반 라운드와 보스 라운드 시간을 분리했다. 일반은 기본 시간 사용을 체크하면 기존 라운드별 시간(예: NORMAL의 1~2라운드 45초, 후반 115초)을 그대로 사용하고, 해제하면 1초 단위로 최대 1800초까지 입력한다. 8인 연합방어도 직접 설정한 시간에 별도 4배를 곱하지 않는다. 보스 기본 카운트다운은 120초, 직접 입력 범위는 1~3600초다. 기존 보스전의 시간 이후 HP 감소 규칙을 유지하며 AI 팀의 추가 유예도 시간 변경분에 맞춰 이동한다. 2배속은 설정한 게임 시간을 실제 시간의 절반에 진행한다.
- 데겐블레허 3스킬: 시전자 중심의 `start_01`, `start_02`, `end` 참격 프리팹의 시각 배율을 0.5로 조정했다. 이 프리팹의 약 5칸 규모 오프셋을 두 칸 스킬 범위와 타일 가장자리에 맞추는 시각 보정이다. 원본 클라이언트 런타임 배율을 추출해 재현했다고 주장하지 않는다. 적에게 붙는 `hit_1/2`, 무기 발광 `start_03/04`, 다른 오퍼레이터의 이펙트와 실제 피해/판정은 변경하지 않았다.
- 검증: 최종 보스 패턴·속도·커스텀 시간·이펙트 테스트 349개 통과, 추출물 경로가 없는 실물 리소스 비교 7개 건너뜀. 실제 Chromium에서 기본 일반 45초/보스 120초, 일반 직접 설정 전환, 73/180초 서버 저장을 확인했고 페이지 오류는 없었다. import 경계 검사·diff 공백 검사 통과. 원본 클라이언트와의 이펙트 픽셀 단위 비교는 하지 않았다.
- Forge 플러그인은 설치하지 않았다. 45개 검증 및 배포 목록 30종의 기능별 병합 판정은 `forge-0.3.1/REPORT-KO.md`에 별도로 보관했다.

추가 이펙트 확인: 런타임 배율이 Local 모드 파티클의 크기에는 적용되지 않고 발생 위치에만 반영되던 경로를 수정했다. 제작된 부모 노드 배율을 무시하는 원래 Local 규칙은 유지하고, 명시적인 런타임 배율만 한 번 적용한다. 실제 공식 프리팹 3개(start_01/start_02/end)를 CPU로 생성해 0.2초 시점 쿼드 외곽이 각각 정확히 0.5배로 줄어드는 것을 확인했다.

### 이펙트 크기·지연 재점검

- 공식 프리팹이 비동기로 준비되면 대기 중 흐른 전투 시간을 무시하고 0초부터 재생하던 문제를 수정했다. 기존 wind-up 건너뛰기 시간과 로딩 대기 시간을 합산하고, OnPlay 자식에도 전달한다. 일시정지 중에는 시간이 늘어나지 않는다.
- OnFinish 자식 생성 시 런타임 크기가 유실되던 경로도 부모 배율을 유지하도록 수정했다.
- 실제 공식 인덱스·프리팹을 연결한 데겐블레허 S3 이벤트 재현에서는 start_01/start_02/end의 rootScale=0.5를 확인했다. 사용자 화면에서 크기가 그대로라는 현상 자체는 아직 재현하지 못했으므로 시각적 해결로 단정하지 않는다. 임의로 추가 축소하지 않았다.
- 검증: vfx-effect, vfx-skill-casts, vfx-orient 62개 중 61개 통과, 1개 건너뜀. import 검사 및 diff 공백 검사 통과. 로컬 서버 재시작 후 변경 코드 응답 확인. 운영에는 배포하지 않음.

### 반복 공격 타이밍 및 범위 표시 보정 수정

- 원인: v0.3.1의 명시적 `atkStart`는 Spine 애니메이션만 시작했다. 기존 공식 FX는 미래 `atk`를 예측하는 `windUp`에만 연결되어 있었고, 이미 준비 중인 애니메이션이 예측 시작을 거절하면 타격 시점에 준비용 FX까지 처음부터 재생했다.
- 수정: `atkStart`에 타격과 동일한 시각적 공격 종류를 선택 정보로 추가하고, 렌더러가 해당 시점에 공식 cast FX를 시작한다. 해당 타격에서는 strike 단계만 재생하며, 취소·누락·전장 초기화 때 준비 상태를 해제한다. 과거 기록의 이벤트는 기존 예측 경로를 유지한다. 전투 피해·공격 간격은 바꾸지 않는다.
- 공격 준비 애니메이션의 재생 속도와 남은 길이를 FX로 전달한다. FX의 원래 재생 속도 적용 여부와 상한을 지키고, 투사체 비행 시계는 변경하지 않는다.
- 크기 수정: 데겐블레허 `blkkgt_skill_03_start_02`는 참격이 아니라 `range_line`/`ground`로 구성된 바닥 범위 표시였다. 이를 0.5배 대상에서 제외했다. 실제 공식 인덱스/프리팹과 스킬 이벤트를 연결하여 start_01/end는 0.5, start_02는 1, 적중·무기 발광은 1임을 확인했다. 위의 이전 기록에서 start_02까지 축소한 설명은 이 수정으로 대체한다.
- 다른 런타임 크기 보정도 조사했다. 일반적인 범위 프리팹에 축소를 적용하는 공통 규칙은 없으며, 제국 드론 조준 표시는 실제 공격 반경에 맞추는 보정이다. 드론 범위 보정은 유지한다.
- 검증: 관련 렌더/전투/소환체 테스트 93개 중 92개 통과, 1개 자산 의존 테스트 건너뜀. Chromium의 실제 app 이벤트 처리 경로에서 4회 연속 공격을 전달하여 start 4회(1.0/2.2/3.4/4.6초), strike 4회(1.4/2.6/3.8/5.0초), 타격 시 전체 재시작 0회를 확인했다. 이 브라우저 검증은 phase 분기를 관찰하기 위해 cast 그리기를 계측했으며 최종 시각 비교 검증으로 간주하지 않는다. 데모 초기 로드 중 일반 Event 오류가 하나 관찰되었다.
- 별도 기존 애니메이션 테스트 전체 실행에서는 3개 실패가 있었고, 이번 Spine 필드 추가를 제거한 비교 실행에서도 같은 3개가 실패했다. 따라서 전체 테스트가 통과했다고 보고하지 않는다. import/공백 검사 통과.
