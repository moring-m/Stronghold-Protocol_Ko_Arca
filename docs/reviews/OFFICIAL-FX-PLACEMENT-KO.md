# 공식 이펙트 원점 및 상태 표시 점검

인디고와 포덴코 기본 공격의 실제 투사체 파일에는 각각 `[0.481, 0.775, 0]`, `[0.432, 0.16, -0.262]`의 루트 위치가 저장되어 있었다. 이는 제작 시 프리팹을 놓았던 위치이며, 런타임 발사 원점에 다시 더할 값이 아니다. 기존 행렬 처리는 이 값을 이미 계산한 총구 위치에 추가했다. 확인한 공식 프리팹 중 203개에 0이 아닌 루트 위치가 있었다.

`Effect._matrices()`가 런타임 앵커를 기준으로 루트를 놓도록 수정했다. 저장된 루트 위치만 빼고, 자식 노드의 상대 위치와 루트 애니메이션의 변위는 보존한다. 모델·텍스처·프리팹 파일 자체는 바꾸지 않았으므로 이 수정 때문에 리소스를 다시 받을 필요는 없다.

전체 모드에서는 기존 표준 상태 도형과 은신 안개를 표시하지 않는다. 공식 상태 이펙트는 이벤트 외에도 스냅샷의 상태·플래그를 통해 동기화한다. 따라서 관전·중도 진입·이펙트 설정 전환에서 보호막 플래그만 있는 유닛도 공식 보호막을 복구하고, 해제 시 정리한다. 같은 상태를 매 프레임 중복 생성하지 않는다. 속세의 음과 커스텀 부식은 표준 상태 도형과 별도이므로 그대로 유지된다. 상태 HUD와 체력바도 유지한다.

다운로드 안내와 진행도는 기존 `panel`, `brackets`, `btn` 테마를 사용하며, 선택 메뉴도 설정과 같은 어두운 배경과 민트 포커스 표시를 사용한다. 모바일에서도 선택 메뉴와 버튼의 글자 크기를 확보한다. 다운로드 안내가 표시되는 동안에는 아래 설정 모달이 입력 포커스를 가져가지 않는다.

검증: 실제 인디고·포덴코 프리팹의 런타임 루트와 총구 앵커 일치, 자식 좌표 및 애니메이션 변위 유지, 기존 원점·방향 처리 테스트, 보호막 플래그 동기화·해제, 전체 모드의 커스텀 상태 도형 제거와 속세의 음·부식 보존, 데스크톱·모바일 안내 테마와 설정 모달 포커스 테스트.


## 배치 방향 처리 후속 점검

- 작업 위치: 원본 로컬 `Stronghold-Protocol_Ko_Arca`. 커밋·푸시는 요청에 따라 보류.
- 미즈키 등 공격 시전 행의 `useFourDirectionalFace` 옵션이 재생 함수로 전달되지 않아, 배치 방향 대신 공격 대상 위치로 방향을 계산했다. 일반 공격·스킬·재능·드론 시전 경로에 옵션을 전달하도록 수정했다. 추출 도구와 스킬 계획 변환에서도 필드를 보존한다.
- 스즈란 3스킬처럼 소유자의 배치 방향을 사용하는 유지형 효과는 최초 방향을 계산한 뒤, 유지 중에는 위치만 따라가고 방향을 갱신하지 않았다. 소유자 방향을 사용하는 유지형 효과도 갱신하며, 지연 로딩과 하위 연쇄 효과에서는 해당 효과 자신의 방향 설정을 사용한다.
- 정보 객체에만 배치 방향이 있는 경우에도 `info.dir`을 읽는다. 공격 대상 쪽으로 회전해야 하는 일반 효과는 기존 규칙을 유지한다.
- 미즈키의 기본 공격 및 스킬 시전 효과와 스즈란 3스킬의 실제 파일로 네 방향 월드 행렬을 검사했다. 전체 추출 자료에서 배치 방향 기반 회전형 효과 82종 및 네 방향 시전 행을 순회 검사했다.
- 관련 전투 이펙트 회귀 검사 150개 통과·1개 자원 조건 생략. 별도 실제 Chrome의 이펙트 합성 검사 2개 통과. 실제 게임의 모든 오퍼레이터·스킨을 육안 확인한 결과는 아니다.
