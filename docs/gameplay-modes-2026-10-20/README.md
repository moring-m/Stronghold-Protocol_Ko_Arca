# 게임 모드 · 단축키 수정 검증

- 새 방 기본값: 커스텀. 대기실 우측 상단에서 클래식·증강·커스텀 선택.
- 클래식: 커스텀 미적용. 증강도 꺼짐.
- 증강: 증강 항상 활성화. 등급 기본 가중치 실버/골드/프리즘 2/5/3.
- 증강 적 HP/공격/방어/마법 저항: 140%/120%/120%/150%.
- 증강 일반·히든 보스 HP/공격/방어/마법 저항: 400%/120%/120%/150%.
- 클래식·증강에서 커스텀 변경은 UI와 서버 양쪽에서 차단. 저장된 브라우저 설정 및 방의 커스텀 초안은 유지하며 커스텀으로 돌아오면 복원.
- 모드는 전투 결과·중도 이탈 기록·내보내기·압축 기록에 보존. 이전 기록은 모드를 추측하지 않음.
- 설명은 짧게 상시 표시. 설명 접기·펼치기 버튼 제거.

단축키 문제는 타일 101의 오퍼레이터에 커서를 두었는데 앞줄 105 모델의 투영 사각형이 먼저 선택되는 것으로 재현했습니다. 일반 클릭·호버와 동일한 타일 판정으로 통일했습니다. 최근 구매를 보존한 채 다른 오퍼레이터만 판매/퇴각하는 동작, 빈 타일·제거된 대상·설정창·준비 완료 시 차단을 기본·2D·3D 화면에서 검증했습니다.

검증: `test/gameplay-modes.test.js`, 커스텀 규칙·보스 스탯·증강·선택 판정 회귀 테스트, 실제 대기실 모드 전환 및 로컬 저장 보존·통계 화면, `test/ui/hover-hotkeys.e2e.test.js` 3개 렌더링 모드. 스크린샷은 Chromium에서 실제 UI를 촬영했습니다.
