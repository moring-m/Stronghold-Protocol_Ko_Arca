# 프리셋 이름·아이콘과 수배 선택 카드 번역

2026-10-25. 후속 요청 반영. 커밋·푸시·운영 배포하지 않았다.

- 선호/선발 프리셋 목록 버튼은 이름과 연결된 진영 아이콘·전략 초상화만 표시한다. `빅토리아 연동`, `선발 1명`, 오퍼레이터·장비 개수 등 부가 설명을 제거했다.
- 전략 초상화는 진영 아이콘과 같은 작은 정사각형 슬롯에 배치한다. 아이콘에 마우스를 올리면 번역된 이름을 확인할 수 있다.
- 전략 연동 버튼과 선택 창에서 이름을 문장에 합쳐 자동 번역에 맡기지 않고 개별 번역 후 표시한다.
- 수배 선택 카드에서 강조 설명과 일반 설명의 동등성을 비교할 때 양쪽을 같은 표시 언어로 비교하도록 수정했다. 이전에는 한쪽만 번역돼 같은 설명도 다른 것으로 판단할 수 있었다. 설명을 결정하는 경계와 이름·설명이 합쳐지는 마우스 안내도 명시적으로 번역한다.
- 실제 데이터의 아츠 마스터 A1/A2 선택 카드 4종을 Chromium의 ChoiceView로 렌더해 카드 이름·본문·마우스 안내에 중국어가 남지 않고, 번역 후에도 공식 강조 설명이 선택되는지 확인했다. 전투 효과·보상·기간은 변경하지 않았다.

검증: 단위/회귀 33개, 프리셋 동기화 브라우저 2개, 수배 브라우저 1개 통과. 수배 브라우저는 카드 본문 4종 및 효과 마우스 안내를 함께 검증한다. strict import·diff 검사 통과, lint 오류 0개(기존 choiceOverlay.js 경고 2개).
