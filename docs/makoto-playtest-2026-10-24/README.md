## 검증

- 실제 서버 전투를 기록하여 Chromium의 게임 렌더러에서 재생했다. 기본/스킨 각각 S1, S2, S3 첫 폼·두 번째 폼·총공격 10장. `validation.json`에 모델 로딩 및 공식 FX 상태를 기록했으며 오류 0개다. 2D 전장에서 공식 FX를 켜고 촬영했다.
- `s3-base-23.3.png`는 초기 간소 표시 진단 촬영으로 최종 10장에 포함되지 않는다.
- `audio-validation.json`: 연결 오디오 131개 전부 ffmpeg 디코딩 성공.
- `download-validation.json`: 고정 커밋의 아이콘과 새 SFX 실제 다운로드 및 SHA-256 일치.
- `test/content/makoto.test.js`: 단계/스킬/모듈, 치명상 전환, 자동 발동 제한, 공유 종료 시각, 회복 우선순위, 처형 재시도 제한, 회피 정리 및 실제 선발 모델 경로 검증.
- 관련 렌더·오디오·리소스·목록 테스트 122개 통과, import 경계 검사 통과. ESLint 오류 0개(경고 11개). 전체 저장소 테스트 전부를 실행한 것은 아니다.

## 근거와 제한

PRTS의 결성리/结城理 자료, 추출된 공식 테이블·Spine 이벤트, 제공된 Drive 영상, 나무위키 커뮤니티 번역을 참고했다. 이 게임의 자동 전투에 맞춰 대역의 수동 재전환을 자동화하지 않는 것은 사용자 지정 동작이다. 원본 영상과 모든 프레임이 동일함을 보증하지 않는다.

슈·블레이즈 디 이그나이팅 스파크·스와이어 디 엘리건트 위트의 nlc 스킨 3종은 제출된 추출 파일에도 완전한 모델이 없어 새 선택지로 노출하지 않았다. 기존 리소스와 스킨은 유지한다. 현재 S.E.E.S. 대원 중 추가된 것은 마코토뿐이며, 추후 대원 추가 시 총공격 참여를 연결할 수 있다.

실제 선발 설정 화면에서도 마코토가 표시·선택되는 것을 확인했다(`recruit-selection.png`). 목록 화면의 다른 기존 오퍼레이터 아이콘은 이 독립 검증 환경에서 다운로드하지 않아 일부 비어 있다.

리소스 저장소에 검증 파일을 업로드했다(고정 커밋 `f4a1904e4df61f53602f51d48bf7c9213aa8ec43`). 게임 코드는 커밋·푸시·배포하지 않았다.
