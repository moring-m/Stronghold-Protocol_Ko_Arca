# 사키코 공식 이펙트·음원 및 전투 기록 보존 수정

## 사키코

공식 비눗방울 리소스는 기본 공격, 1스킬 8개 변형, 2스킬의 빠른/느린 음표, 3스킬의 물리/마법 음표로 구분되어 있습니다. 스킨 변형도 존재합니다. 기존 클라이언트는 `sakikoNotes`의 실제 좌표를 간소 그래픽으로만 그렸고, 공식 이펙트에는 해당 스냅샷 경로가 연결되지 않았습니다.

이제 각 비눗방울에 발사 당시의 투사체 키를 보존하고, 실제 보간 좌표로 공식 이펙트를 추적합니다. 모드 전환 후에도 이미 발사한 음표의 종류를 유지합니다. 삭제·명중·렌더 초기화 시 정리하고, 간소 설정 또는 해당 공식 리소스가 없는 경우에만 간소 비눗방울을 표시합니다.

음원은 공식 `audio_data.json`에 있지만 선발 오퍼레이터 데이터에 SFX 매핑이 없었습니다. 사키코는 표준 `ON_SKILL_START` 외에 `ON_ABILITY_ON`, `ON_CUSTOM_TRIGGER`, 전용 투사체 발사·명중 은행을 사용하므로 이를 연결했습니다. 실제 비눗방울 발사·명중 이벤트로 소리를 재생하고 일반 공격 이벤트의 중복 재생은 막습니다. 데이터 재생성 과정에도 같은 연결을 추가했습니다.

필요한 공식 음원 14개 모두 HTTP 200 응답을 확인했습니다. 브라우저에서 실제 MP3를 디코딩해 소리가 있는 PCM을 확인하고, 발사·명중 시 Web Audio 소스가 각각 시작되는 것을 확인했습니다(`browser-check.json`). 배포 리소스 목록에도 포함합니다.

이는 시뮬레이션 전체 플레이 영상이 아닌 실제 렌더러의 통제된 캡처입니다. 각 상태별 연결·좌표·정리와 실제 시뮬레이션의 노트 생성은 별도 테스트로 검증했습니다.

## 최근 전투 기록이 사라지는 현상

`fitToBudget`는 800,000자 한도에 맞지 않는 최근 상세 기록을 건너뛴 다음, 이미 요약된 작은 옛 기록을 저장할 수 있었습니다. 라운드별 상세 통계가 큰 최근 기록이 사라지고 옛 기록은 남는 현상을 재현했습니다. 업데이트가 기록 저장 키를 바꾸거나 직접 전체 기록을 초기화하는 경로는 확인되지 않았습니다.

수정 후에는 최근 기록이 한도에 맞지 않으면 상세 데이터부터 요약해 목록·통계를 유지합니다. 더 이상 최근 항목을 건너뛰고 옛 항목을 대신 넣지 않습니다. 브라우저 저장 공간이 부족할 때도 기록 수를 줄이기 전에 상세 데이터를 요약합니다. 여전히 최대 1,000건 및 저장 용량 한도를 적용합니다.

브라우저 검증에서 큰 상세 보고서가 있는 45개 기록을 모두 저장하고, 새로고침 뒤 같은 ID·순서로 복원되는 것을 확인했습니다. 44건은 요약으로 보존되었으며 저장 크기는 608,670자였습니다. [실제 목록 화면](history-retention.png).

이미 이전 저장 과정에서 삭제된 기록은 이 수정만으로 복구되지 않습니다. 복원용 내보내기 파일이 있을 경우 기존 가져오기 기능으로 병합할 수 있습니다.
