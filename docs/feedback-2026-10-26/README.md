## 검증

- 관련 시뮬레이션·UI·렌더·오디오·생성기 테스트 122개 통과.
- 운영 카탈로그 기반 울피아누스 일반/승급 식량, 엑시아 무대상 S3, 혼의 앞/뒤/스킨 및 스킬 대기 복귀, 돌파 즉시 차감/정산을 검증했다.
- 기존 오디오/스킬 모션 테스트의 별도 실패는 변경 전 체크아웃에서도 같은 항목으로 재현했다. 전체 테스트 통과를 뜻하지 않는다.
- 새 SFX 파일 2개의 원본 다운로드 URL은 HTTP 200으로 응답했다.
- 커밋/푸시 및 운영 배포는 하지 않았다.

## 후속 확인

- 통계·맹약 관련 테스트 122개 통과.
- 실제 Chromium에서 localStorage 쓰기를 12,000자로 제한해 최근 8개 기록이 모두 요약되는 조건을 강제로 만들었다. 별도 상세 저장 후 새로고침, 그래프 데이터 복원, 전체 상세 JSON 내보내기/가져오기, 실제 통계 화면의 8개 상세 열기 가능 상태, 상세 화면 진입을 확인했다.
- 전체 삭제 후 새로고침해도 상세가 되살아나지 않으며, 저장 중 삭제하는 순서도 검증했다.
- v0.3.1h1과 현재 코드 각각 울피아누스 일반/승급 장비 테스트 2개씩 통과. 두 실행 모두 동일한 현재 운영 카탈로그를 사용했다.
