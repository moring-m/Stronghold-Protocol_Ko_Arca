# 협력방어 기능 구조와 사막 경계 검증

공통 맵 외형은 유지하고, 협력방어의 중앙 보스 자리·연결 발판은 원래 협력방어의 중앙 통로와 차단 칸으로 교체했다. 침입·연결 표시도 원래 협력방어 위치와 일치시킨다. 원본 메시를 잘라 교체하므로 텍스처와 라이트맵을 유지하고 같은 면을 중복해서 그리지 않는다. 서버 데이터·전투 좌표·배치 판정·장치 설정은 변경하지 않았다. 대체 맵에도 같은 타일 구성을 적용했다.

사막 테마 9개 맵의 오른쪽 침입 지점 바깥 경계에는 반대편의 기존 언덕 타일을 복제했다. 대응 타일에 모서리 틈이 있으면 가장 가까운 온전한 언덕 타일을 사용한다. 새 지면이나 임의 장식을 만들지 않는다. 채운 칸은 추가 경계 복제에서 제외한다. 협력방어·보스전 양쪽에 적용된다.

## 이미지 대신 실제 메시 직접 검사

브라우저에서 생성된 실제 `BufferGeometry`의 위치·삼각형 인덱스와 메시 이동량을 읽어 검사했다. 물 셰이더와 아래를 향하는 면은 제외했다. 각 검사점과 위를 향하는 삼각형의 교차 여부·보간 높이를 계산한다. 스크린샷 색상이나 바운딩 박스, 타일 중앙만으로 판단하지 않는다.

- 대상: 사막 테마 9개 맵 × 협력방어/보스전 2개 모드.
- 제보된 오른쪽 경계: 보스전 `(행 3~6, 열 19)`, 협력방어 `(행 10~13, 열 19)`.
- 총 72개 경계 칸에 각 21×21개 지점, **31,752개 검사점**.
- 최초 직접 검사: **190개 검사점에 면이 없었음**. 모서리 틈을 발견해 보완했다.
- 수정 후 직접 검사: **31,752개 모두 면에 닿음**, 빈 검사점 **0개**.
- 추가 경계 중복 방지 처리 이후 대표 맵 두 모드를 다시 검사해 빈 검사점 0개를 확인했다.
- 관련 테스트 **101개 통과**. 전체 11개 맵의 협력방어 중앙 타일·침입 지점·원본 데이터 보존, 사막 9개 맵의 언덕 전면 검사와 작은 모서리 틈 재현을 포함한다.

바다 배경 전체를 제거하는 작업이 아니라, 제보된 전장 오른쪽 경계를 채운 결과다. 위 결과는 명시한 경계와 검사 해상도에 대한 검증이다.
