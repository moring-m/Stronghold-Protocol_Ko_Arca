# 마코토 전환·공격 / 공통 렌더 경계 / 제국 드론 점검

## 최종 변경

| 요청 | 확인한 문제 | 수정 및 결과 |
|---|---|---|
| 대역 ↔ 본체 전환 | 총공격 마무리를 idle처럼 반복하고 별도 복귀 모션이 더 붙음. 모델 교체 시 진행률 유실 | 원본 클립을 연속 단발 재생하고 진행률을 이어받음. 기본/스킨 및 앞/뒷면 교체 검증 |
| 대역 진입 끊김 | 늦은 전환 입력이 진입 모션을 처음부터 재생. 혼잡도에 따라 짧은 전환 모션 갱신이 생략될 수 있음 | 남은 구간부터 재생하고 마코토 전환 중에는 매 프레임 갱신 |
| 공격 경로 각도 | 몸체는 A 모션만, 공식 이펙트는 A/B를 번갈아 재생 | 몸체 A/B 순서를 연결. 공식 이펙트 재활성화 시에도 현재 몸체 모션을 기준으로 선택. B 모션도 캐시 경계 계산에 포함 |
| 이펙트 전반의 사각형 잘림 | 사전 샘플 경계 밖으로 나오는 혼합/부착 효과가 캐시 사각형에 잘릴 수 있는 경로 | 현재 실제 포즈도 경계를 검사하고 벗어나는 동안 직접 렌더링. 공식 GL 효과의 scissor/stencil 분리 처리도 유지. 모든 개별 이펙트의 동일 원인 여부까지 확정한 것은 아님 |
| 공격 후딜레이 무시 | 즉시 발동 스킬이 진행 중인 공격을 끊고 대역에 진입 | 마코토만 공격 선딜/실제 클립 후딜이 끝난 뒤 발동. 치명상에 의한 전환은 즉시 유지 |
| 대역 SP바 | 즉시 발동 스킬의 SP 상태만 전달하여 대역 지속시간이 보이지 않음 | 남은 대역 시간을 바에 전달. S3의 두 대역은 원래 종료 시각 공유 |
| 인형사 배치 판정 / 시라쿠사 은신 | PRTS에 재배치 판정 근거 없음. 전환 시 Buff 제거는 명시됨 | 배치 이벤트 추가/은신 유지 초안은 취소. 사용자가 지정한 카제마루와 마코토의 동일한 기존 처리를 실제 전투 테스트로 확인 |
| 제국 드론 폭격 | 표적에 붙어 자체 낙하하는 AttachToTarget 효과를 일반 투사체 이동으로도 운반 | 표적 위치에서 자체 낙하만 재생. 추적 → 위치 고정 → 낙하 → 착탄을 시뮬레이션 시간에 맞추고, 프리팹에 포함된 2.75초 대기는 중복 적용하지 않음 |
| SFX | 기존 마코토 음원의 연결/다운로드/디코딩 점검 | WebAudio 디코딩 정상. 사용자 요청에 따라 불필요한 음원 변경 없음 |

## PRTS 확인

[귀명 스펙터 — 특성의 인형사 분기 설명](https://prts.wiki/w/归溟幽灵鲨#特性)

> 切换动画开始时会清除自身一切Buff

전환 시작 시 Buff 제거를 명시하며, 재배치 효과 발동은 명시하지 않음. 사용자 최종 지시에 따라 카제마루의 기존 전환 규칙 유지. 은신이 별도로 재부여되거나 지속시간이 갱신되지 않는 비교 테스트 추가.

## 검증

- 관련 테스트 70개: 69개 통과, 기존 에셋 선택 테스트 1개 생략, 실패 0개.
- 수정 파일 ESLint 오류 0개. 기존 경고 6개.
- 기존 파투스 중복 보유자 테스트 1개는 별도 실행 시 실패. HEAD의 professions.js로 교체 로드한 비교 실행에서도 같은 값으로 실패하여 이 작업의 회귀로 처리하지 않음. 판정 변경 및 해당 테스트의 기대값 변경은 최종 코드에 남기지 않음.
- `entry/base.mp4`, `entry/skin.mp4`: 실제 게임 렌더러의 기본/스킨 대역 진입 촬영. 전환 입력을 직접 넣은 시각 점검이며 전체 전투 녹화는 아님. 혼잡도 2 및 기본 갱신 간격 4로 점검. 브라우저 오류 없음.
- `base.mp4`, `skin.mp4`: 실제 게임 렌더러의 총공격 마무리 → 본체 촬영.
- `drone/*.png`, `drone/validation.json`: 실제 공식 이펙트 렌더러에서 조준/낙하/착탄 촬영 및 좌표·시간 기록.
