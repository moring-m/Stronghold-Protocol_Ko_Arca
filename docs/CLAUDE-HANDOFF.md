## 추가로 기억할 사용자 선호

- 커밋·푸시는 지정 요청이 있을 때만 한다. 릴리즈 패치노트에는 최종 사용자에게 달라지는 내용만 적고 구현 중 수정 요청·대화 이력은 적지 않는다.
- UI는 기존 스타일을 유지하며 높이·간격·배치를 맞춘다. 전체 디자인을 임의로 바꾸지 않는다.
- 비교 스크린샷을 요청하면 실제 브라우저 화면을 찍는다. 합성/가짜 화면을 실제처럼 보고하지 않는다.
- 번역은 공식 명칭·제공받은 커뮤니티 번역과 기존 강조 태그를 따른다. 사용자에게 중국어로 질문하지 않는다.
- 보스 패턴 전체 변경 원복, 게임 플러그인 UI 미지원 등 기존 결정을 되살리지 않는다.
- 공식 리소스를 운영과 다르게 연결해 로컬 로딩을 빠르게 보이게 하지 않는다.
- 이 인계에는 과거 Codex 환경의 프로세스·터널·API 자격 증명·전체 대화가 포함되지 않는다. 이전 Tunnelmole 주소를 살아 있다고 가정하지 않는다.
