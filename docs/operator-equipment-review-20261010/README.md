# 오퍼레이터·장비·투석기 검토 — 2026-10-10

## 캐서린 특질

[PRTS 위수협약 맹약 기록](https://prts.wiki/w/卫戍协议：盟约_下半/PRTS盟约记录)에서 홀수 라운드의 휴식 진입 시 일반 1개, 승급 2개를 획득하는 조건을 확인했다. 해당 페이지에는 장비별 추첨 확률이 없다.

사용자가 확인해 준 장비 풀 규칙을 반영했다. 상점 레벨과 무관한 1~4티어 일반 장비이며, 다음 장비는 제외한다.

- 자금 관련: 맹약코인, 알뜰살뜰 인형, 돈독 오른 인형, 기사 저금통.
- 특수효과 망치: 전율의 빅토리아 해머, 견고한 빅토리아 해머, 가속의 빅토리아 해머, 불타는 빅토리아 해머.

일반 빅토리아 해머는 포함한다. 전용 `pool_equip_cathy_garrison`을 사용하며, 캐서린 전략의 `pool_equip_kathe`와 다른 장비 풀을 수정하지 않는다. 장비별 확률은 기존 균등 추첨을 유지한다. 원본의 정확한 확률을 확인했다는 뜻은 아니다. 풀이 비었을 때 제한 없는 임의 장비로 우회하는 처리도 제거했다.

배치되어 있을 때만 발동하며, 벤치·짝수 라운드에서는 지급하지 않는다. 일반·승급 지급 개수 및 상점 1레벨에서 1~4티어의 모든 허용 장비가 추첨되는 것을 검사했다. 비활성화된 커스텀 장비는 기존 매치의 장비 목록에서 제외되므로 이 풀에도 들어가지 않는다.

6개 스킨의 모델 메타데이터를 읽어 애니메이션·타격 시점을 보존했다. 관련 리소스 96개를 실제 HTTP GET으로 확인했으며 전부 성공했다. PNG 서명도 검사했다. 브라우저 전체 다운로드를 새로 수행했다는 의미는 아니다. [리소스 검사 기록](skin-resource-check.json)

선발 5명 × 5·6티어 × 일반·승급의 20개 구성에서 스킨을 제거한 복사본을 만들고 실제 `buildRecruits`를 실행해 목록이 다시 유지되는 것을 확인했다. 정식 한국어 이름이 확인되지 않은 네 스킨은 원문 기반 임시 번역을 별도 번역 목록에 넣었다.

## 수배 투석기

[PRTS 自制投石机](https://prts.wiki/w/自制投石机)와 비교했다.

- 이전: 명중 시 세 번의 피해를 즉시 처리하고 주 대상의 명중을 강제했다. 일반 상태에서도 입희 상태의 반경 0.5 값을 사용했다.
- 수정: 0.3초 간격으로 돌 세 개를 발사한다. 각 돌은 착탄 지점의 반경 1.5에 물리 피해를 준다. 발사된 돌은 고정 좌표로 날아가므로 이동한 주 대상의 명중을 강제하지 않는다.
- 위장 상태의 아군도 착탄 범위에 있으면 피해를 받는다.
- 저지 중인 아군을 우선 공격하지 않으며, 목표를 잃어도 진행 중인 공격 선딜레이를 취소하지 않는다.
- 발사된 돌은 투석기가 죽어도 착탄한다. 발사 전에 사망·기절·동결·수면·무장해제 등이 발생하면 아직 발사하지 않은 돌은 취소된다.
- 입희 상태 플래그가 있을 때는 원본 데이터의 ±3칸 무작위 좌표와 반경 0.5를 사용한다. 현재 위수협약 수배에는 입희 상태를 부여하는 경로가 없으므로 일반 상태가 적용된다.

다른 적의 기본 공격 선딜레이와 오퍼레이터의 타격 시점 처리에는 기존 조건을 유지했다.

## 황제의 은총과 우르수스 드론

- 황제의 은총 일반·승급 가격을 모두 4로 변경했다. 생성 스크립트와 운영용 카탈로그에도 반영했다.
- 드론 기본 크기 85%, 기본 범위 반경 2칸은 유지한다.
- 중첩에 따른 크기 0.2%, 범위 0.1% 증가는 6우르수스일 때만 적용한다.
- 3·5우르수스에서 1,000~2,000중첩이어도 기본 크기·범위를 유지하는 것을 검사했다.
- 전투 중 6→5→6 조건 변경 시 크기, 실제 범위 및 클라이언트 스냅샷도 축소·복원되는 것을 검사했다.
