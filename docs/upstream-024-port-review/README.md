# 원본 v0.2.4 기능별 이식 검토

대상: 원본 `bc50cac0` / v0.2.4. 전체 merge 대신 활성 구현에 기능별 이식했다. 기존 로컬 수정도 포함한 작업 트리이며, 버전 변경·커밋·푸시·운영 배포는 수행하지 않았다.

## 기존 요구사항 유지

- 적 공격 모션/이동 대기, 스킬 발동 선딜레이와 공격 준비 자세.
- 보스·협력방어 맵 구조, 좌우 방향, 장식 보완, 맵 캐시와 분할 사전 생성.
- 원본 맵의 타일 윤곽 분노 효과, Spine 페이지별 PMA 처리, 근접 무기 꼬리 제거.
- 우르수스 수치 및 6우르수스 전용 드론 성장, 캐서린 장비 규칙, 선발 비콘 금지.
- 선호/선발 프리셋, 스킬 선택, 진영 연동, 선발 개인 재고.
- 다운로드 병렬 처리·중단 재개·원인 표시, 중국어 음성 제외와 이미지 재시도.
- 한국어 기본 표시, 기존 대기실/전략 UI 배치, 채팅, 설정 분류.
- 상점 장비 좌측 설정·레벨업 슬롯 좌측 추가·접기 단축키, 전투 후 HP 차감 표시.
- 유형별 전투 통계·그래프·결과 화면.

원본 대기실 헤더 개편과 일본어 UI 용어 변경은 한국어 전용 UI 및 사용자 지정 배치를 덮어쓰지 않도록 적용하지 않았다. 원본의 테스트 대기 시간은 포크의 실제 배치·발동 지연에 맞게 조정했으며, 실행 코드를 즉시 공격으로 되돌리지 않았다.

## 검증

- 신규 이식 핵심 테스트: 54개 통과.
- 기존 애니메이션·다운로드·우르수스·선발·맵 캐시 등 회귀 테스트: 162개 통과.
- 맵·통계·이미지 복구·수치 표시: 97개 통과.
- 브라우저 렌더러 복구 테스트 6개 통과: 로컬/서버 전투 객체와 시간 유지, Pixi 재시도, 강제 단순 렌더러 유지, 맵 이미지·Three 복구. 실패 주입 테스트는 각각 독립 브라우저 저장소와 실제 운영 데이터 경로를 사용.
- 변경된 JavaScript 63개 파일 문법 검사 및 diff 공백 검사 통과.
- 브라우저 상점 배치·접기 및 단축키 변경: 페이지 오류 없음.
- 원본 맵 m01~m04 브라우저 확인: 레이아웃 캐시 재사용, WebGL context 손실 없음, 페이지/셰이더 오류 없음. 캐시 전환 6.2~12.5ms(이 환경 측정).

선택적 샴페인 폭탄 원본 모델은 실제 파일이 존재하는 환경에서만 사용한다. 모든 오퍼레이터·스킨의 전체 애니메이션을 이번 검증으로 완전히 보장하지 않는다.
