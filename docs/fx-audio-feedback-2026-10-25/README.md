# SFX·스킨 투사체·마코토 기절·먼지 성능 수정

2026-10-25. 커밋·푸시·배포하지 않은 로컬 수정이다.

| 제보 | 원인 | 수정 및 확인 결과 |
|---|---|---|
| 그레인버즈 2스킬 등 시전 SFX 누락 | 공식 `ON_SKILL_START.<스킬>`만 조회하고 `ON_ABILITY_START.<스킬>`을 누락. 이미 `null`로 생성된 슬롯은 보완 생성기도 건너뜀 | 정규 시전 은행을 우선하고 정확한 스킬 ID의 ability 은행만 보완. null 슬롯도 복구. 기존 연결은 유지. 공격형 자동/패시브 순간 스킬은 보완 대상으로 삼지 않아 공격음 중복을 방지 |
| 혼 스킨 기본 공격 공식 VFX 누락 | 스킨의 graphic 투사체 레코드로 전체 레코드를 교체해 원래 투사체의 명중/도착 효과를 잃음 | 외형 교체와 함께 원래 lifecycle 효과를 보존하고 스킨 효과로 치환. 스킨 자체에 명시된 효과는 우선. 원본 인덱스는 변형하지 않음 |
| 마코토 기절 진입 반복 | 진입을 포함한 단일 Stun 클립을 반복 재생 | 마코토만 단일 기절 클립을 한 번 재생 후 자세 유지. 본체·스킨·각 대역에서 반복 업데이트가 진입을 재시작하지 않고, 기절 해제 후 복귀하는 회귀 검증 |
| 시빌라이트 에테르나 공식 먼지의 큰 렌더 부담 | 먼지마다 13개 입자 시스템을 가진 루프 프리팹을 상시 생성. 3개면 39개, S2 6개면 78개의 입자 시스템 | 원본 0.3.2의 MoteRing/공식 모델 텍스처를 결합. 상시 공전은 공식 부착 이미지 3~6개로 표시. 기존 슬롯 소모·재생성·확장 반경·게임 시간/일시정지 동기화 유지. 모델 캐시 밖에서 움직여 캐시마다 입자를 다시 그리지 않음. 이미지가 없는 모델은 기존 경로 유지 |

시뮬레이션 코드, 피해·회복·충돌·공격 타이밍은 이번 수정에서 변경하지 않았다. 숨겨진 5단계 시빌라이트도 같은 이미지가 있는 모델에서는 가벼운 경로를 사용하며, 먼지가 닿을 때의 명중 효과 및 다른 오퍼레이터의 공전 투사체는 유지한다.

## 연결 범위

- 실제 운영 데이터 기준 **61명 / 91개 스킬 슬롯 / 추가 음원 12종**. [전체 SFX 연결 목록](skill-sfx-additions.json). 기본 data/ 재생성에도 같은 보완 규칙을 적용했다.
- 기본 매니페스트 보완에 필요한 추가 음원 총 23개를 다운로드했고, 운영 데이터의 12개 음원도 모두 로컬 파일 존재를 확인했다. 공식 리소스 URL을 다운로드 목록에 등록한다. 별도 음원 추출은 필요하지 않았다.
- [영향을 받는 스킨 투사체 연결](costume-impact-inheritance.json)은 인덱스 별칭까지 포함한 650개 연결 / 212개 스킨 키다. 이는 정적 연결 감사이며 모든 스킨을 실물 재현했다는 뜻은 아니다.

## 검증

- [집중 회귀 75개 모두 통과](focused-tests.log). 시전 은행 우선순위·정확한 fallback·null 복구/멱등성·원래 매핑 보존·공격음 중복 방지·스킨 도착 효과·마코토 각 형태의 기절과 전환·먼지 슬롯/시간/소멸/공전 포함.
- 기존 오디오 관련 범위 91개는 **수정 전/후 모두 87개 통과, 동일한 4개 실패**. 음원 pool 생성 데이터 2건, 회복 직후 타격 음원 테스트 1건, 모의 Makoto FX 객체에 ofx가 없는 테스트 1건이다. 전체 테스트가 통과한다고 주장하지 않는다. [수정 전](audio-tests-before.log) / [수정 후](audio-tests-after.log).
- 실제 Chromium으로 모델·공식 텍스처·먼지 3개를 확인했고 상시 입자 효과 인스턴스는 0개였다. [실제 화면](cetsyr-official-motes.png) / [측정값](browser-validation.json). 해당 화면의 자바스크립트 오류 없음. 실제 플레이 기기의 FPS 개선 폭은 측정하지 않았다.
- 변경 파일 lint 오류 0개(기존 units.js 경고 5개), strict import 검사 및 `git diff --check` 통과.

릴리스 상태 갱신: 이 문서는 검증 당시의 기록이며, 해당 변경은 이후 [v0.3.3a 릴리스](../releases/v0.3.3a/README.md)에 포함했습니다.
