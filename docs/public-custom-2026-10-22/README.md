# 공개 커스텀 방 및 적 증강 투표

- 증강 게임 모드는 적 증강 선택에 일반 참가자 투표를 기본 적용한다. 저장된 커스텀 선택 방식은 보존한다.
- 일반 투표에서 한 선택지가 전체 유효 투표권자의 절반을 넘으면 남은 시간이 10초보다 길 때만 10초로 줄인다. 절반만 받은 경우에는 줄이지 않는다. 이미 10초 이하면 연장하지 않는다. 가중치 투표에는 단축을 적용하지 않는다.
- 적 증강 선택 방식에 가중치 투표를 추가한다. 모든 참가자의 투표 후 득표 수를 가중치로 추첨한다. 3표/1표이면 75%/25%, 0표인 선택지는 당첨되지 않는다. 전체 리롤도 같은 방식으로 투표한다. 제한 시간이 끝나면 실제 투표만 반영하고, 표가 전혀 없으면 증강 선택지 중 균등 추첨한다. 기존 결과 확정 후 3초 대기는 유지한다.
- 보스 스펙 조정에 “보스 HP 증가 방식”을 추가한다. 증강을 켠 커스텀 모드에서 등급 누적을 선택하면 기본 100% × 등장 실버 1.3 / 골드 1.5 / 프리즘 1.7을 적용한다. 골드·골드·프리즘은 382.5%. 저장된 고정 HP 배율은 지우지 않는다. 고정 방식으로 돌아오면 그 값을 다시 사용한다.
- 커스텀 연합 방도 공개할 수 있다. 공개 후에는 모든 게임 모드 변경이 제한된다. 공개 확인창에 이 제한을 표시한다. 공개 커스텀 방의 설정 자체는 계속 수정 가능하다.
- 방 제목은 대기실의 중앙 정렬된 텍스트 옆 연필 아이콘으로 수정한다. 최대 15자, 빈 값은 기본 시뮬레이션 이름을 사용한다. 공개 목록에는 제목을 표시하며 긴 제목은 말줄임 처리한다. 기존 닉네임은 방 제목으로 대체 표시한다.
- 목록의 커스텀 방 모드 표시 오른쪽에 “설정 보기” 아이콘을 추가한다. 참가하지 않고도 기본값에서 변경된 현재 적용 설정만 읽기 전용으로 확인한다. 변경 없는 분류는 숨기고, 변경 사항이 없으면 기본 설정과 같다고 표시한다. 게임 규칙·증강·아군·일반 적·보스·추가 콘텐츠·밴 설정별로 나누고, 수치와 선택값을 구분한다. 비공개 방은 이 API로 조회할 수 없다. 모바일은 한 열로 표시한다.
- 재생 I/II/III는 초당 100/200/300으로 조정한다. 언어별 설명도 함께 반영했다.

- 일반 적 HP 증가 방식에 등급 누적 옵션을 추가한다. 증강 모드는 기본 100%에서 등장한 실버 ×1.1 / 골드 ×1.15 / 프리즘 ×1.2를 누적 곱한다. 커스텀에서도 동일한 방식을 선택할 수 있고, 기존 고정 배율 값은 보존한다. 보스 본체에는 일반 적 배율을 적용하지 않는다.
- 내장 “증강 모드” 프리셋을 추가한다. 불러온 설정은 자유롭게 수정할 수 있지만 내장 프리셋 자체는 덮어쓰기·삭제할 수 없다.

## 검증

- 관련 단위 검사에서 HP 누적 배율, 저장 설정 보존, 내장 프리셋 보호, 공개 모드 전환 제한, 방 제목 길이와 권한을 확인했다.
- 실제 화면: [데스크톱 설정](settings-desktop.png), [모바일 설정](settings-mobile.png). 공개 목록 화면은 `directory/`에 저장했다.

- 증강 모드의 일반 적은 공격력·방어력 기본 100%에서 증강 선택마다 +8%를 누적하고, 마법 저항은 기본 0에서 선택마다 +4를 누적한다. 보스에게는 이 규칙을 적용하지 않는다.
- 기본 방 제목은 “닉네임박사님의 N인 시뮬레이션”이다. 연필 클릭 시 같은 클릭의 기본 동작이 저장 버튼 제출로 이어지는 문제를 막고 실제 마우스 클릭으로 검증했다.

- 공개 방 설정 보기 아이콘을 실제 등록된 정보 아이콘으로 연결했다. 세로 중앙 정렬의 transform과 버튼 눌림 transform이 충돌해 위치가 튀는 문제를 제거했다. 실제 마우스 누름/떼기로 위치 유지와 설정 열림을 검증했다.

- 커스텀의 등급 누적 방식은 일반 적 HP·공격력·방어력·마법 저항 및 보스 HP에 개별 적용할 수 있다. 고정 값은 보존하고 증강을 끄면 고정 값으로 동작한다. 내장 증강 프리셋도 모든 해당 옵션을 활성화한다. 설정 설명에는 선택 가능한 방식만 표시한다.
- 방 설정 열람 아이콘은 커스텀 텍스트와 같은 줄에서 세로 중앙 정렬한다.
