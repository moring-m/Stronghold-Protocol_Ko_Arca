# 맵 미리 준비 및 분노 장판

- 공격 후 이동은 기존 규칙을 유지합니다. 이동 공격을 명시한 적을 제외하면 공격 모션의 남은 시간이 끝나야 걷습니다. 공격 선딜/렌더링의 최대 4배속 제한에 이동 재개 계산도 맞췄습니다.
- 분노 장판은 원래 바닥 텍스처를 유지하고 붉은 바닥 글로우와 위로 흐르는 붉은 글로우 카드를 추가했습니다. 월드 좌표에 배치하며 원본 맵에서만 적용합니다. 각 타일의 실제 원본 메쉬 표면 높이를 구해 글로우를 배치합니다. 바닥은 가산 합성, 상승 부분은 반투명 합성으로 밝은 바닥에서도 붉은 색감이 드러나도록 합니다. 간단한 대체 맵에서는 새 글로우를 생성하지 않습니다. 타일 네 변을 따라 세운 면들을 한 메쉬로 합칩니다. 별도 그림자는 생성하지 않습니다. 원본 이펙트 파일 자체를 재생하는 구현은 아닙니다.
- 게임 전장 초기화 후 현재 테마의 일반·협력방어·보스전 구조를 별도 루트에서 준비합니다. 원본 메쉬의 재질별 작업과 장치/환경 생성 단계 사이에서 idle 작업으로 실행을 양보합니다. 셰이더도 별도 장면으로 미리 컴파일합니다. 현재 맵, 카메라, 배치한 장치는 바꾸지 않습니다.
- 동일한 맵 상태 업데이트는 준비 작업을 다시 시작하지 않습니다. 맵 변경/렌더러 종료 시 준비 작업을 취소하고 부분 생성 리소스를 정리합니다. 캐시 제한은 기존 4개(현재 맵 포함)를 유지합니다.
- 준비가 끝나기 전에 곧바로 전환하면 기존 즉시 생성 경로를 사용합니다. 각각의 재질 메쉬 작업 내부까지 시간을 제한하는 방식은 아니므로 모든 기기의 프레임 지연이 0임을 보장하지 않습니다.

검증: 렌더러 수명/구조 16개 통과, 공격 모션/이동 12개 통과. 실제 Chromium의 원본 act2 m01–m04 맵 모두에서 미리 준비한 협력방어 구조를 사용했고 WebGL 컨텍스트 손실 및 페이지 오류가 없었습니다. 전체 카메라 전환 호출 처리 시간은 6.8–12.6ms였으며 첫 프레임 표시 완료 시간과는 구분합니다. 붉은 상승 글로우 셰이더도 실제 WebGL에서 오류 없이 그렸습니다. 상세 브라우저 결과는 browser-results.txt를 참조합니다.
