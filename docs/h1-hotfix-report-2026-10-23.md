## 검증

- 기능 및 콘텐츠 관련 테스트 64개 통과. 추가 클레멘티아 표시 배속/정리 회귀 테스트 포함 후 별도 재확인.
- 배포 경로·접속 유지 테스트 49개 통과, 브라우저 조건 테스트 2개는 별도 실행. 릴리스 브라우저 검사 3개 통과.
- 언어 초기 다운로드 영어·일본어·중국어·한국어 전환 및 설정의 언어 전환 브라우저 검사 통과.

- 실제 UI 캡처: `h1-ui-audit-2026-10-23`.

## 남은 리소스 한계

이전 추출본의 스킨 15종·투사체 43개는 특수 발사 지점 바인딩을 확정할 수 없어 스킨의 기본 muzzle로 대체합니다. 정확한 특수 지점은 보완한 추출기로 다시 추출한 메타데이터가 필요합니다. 모든 스킨·스킬을 실제 플레이로 전수 촬영한 것은 아닙니다.
