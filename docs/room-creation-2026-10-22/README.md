# 방 생성·탐색·번역 정리

## 최종 동작 (생성 창 변경 원복 후)

- 방 만들기는 설정 창을 띄우지 않고 바로 생성한다. 기존처럼 커스텀 모드로 시작하며 저장된 커스텀 설정을 유지한다. 실험실·연습실 진입은 그대로다.
- 연합 시뮬레이션 카드의 기존 관전 체크 위치에 공개 체크를 둔다. 기본 켜짐이며 마지막 선택을 저장한다. 체크를 끄면 비공개로 바로 생성한다.
- 연합 방 관전은 공개 여부와 무관하게 항상 8석이다. 구 클라이언트가 관전 0석을 요청해도 비활성화하지 않는다. 단독 방은 기존처럼 관전 대상이 아니다.
- 방 제목 자동 생성의 언어 처리와 탐색 버튼은 유지한다. 자동 제목은 한국어·영어·일본어·중국어에 맞추고, 닉네임과 직접 입력한 제목은 번역하지 않는다.
- 대기실에서도 공개/비공개와 모드를 변경할 수 있다. 진행 중인 전투에서는 변경하지 않는다. 커스텀으로 돌아오면 저장된 설정을 복구한다.
- 탐색은 참가 가능한 공개 방 수 / 전체 방 수를 표시한다. 전체에는 단독·비공개·진행 중인 방을 포함한다. 비공개는 개수만 집계하고 이름·코드·설정은 공개하지 않는다.

## 증강 등급 누적 옵션 잠금 확인

운영의 `/js/ui/customExtensions.js`를 직접 확인했고 로컬과 같은 조건이었다. 커스텀 규칙 `augments`가 꺼져 있으면 `ByAugment` 옵션을 비활성화한다. 폐기한 생성 창은 클래식이 기본이라 커스텀 편집 전체도 비활성화될 수 있었다. 직접 생성/커스텀 기본값을 복원했고, 비활성 옵션에는 증강 모드를 켜야 한다는 title 안내를 추가했다.

실제 브라우저에서 증강 꺼짐 → 옵션 잠김, 켜짐 → 옵션 선택 가능, 누적 선택 → 고정 HP 입력 잠김/설정 저장을 확인했다. 임의로 증강 규칙을 켜거나 저장된 값을 초기화하지 않는다.

## 번역 원인과 수정

공식 데이터에 있는 원문 이름은 사전에 있어도, 한국어로 작성된 커스텀 UI가 동일 명칭을 조회할 때 자동 번역이 먼저 선택되는 경로가 있었다. 영어·일본어의 공식 명칭과 그 한국어 별칭을 마지막 우선순위로 등록해 고쳤다.

영어의 맹약은 Alliance, 핵심 맹약은 Core Alliance, 부가 맹약은 Add-on Alliance로 통일했다. 맹약을 Bond/Oath/Pledge 등으로, 증강을 Augmentation/Reinforcement 등으로, 밴을 van으로 번역한 항목과 중첩 표기도 정리했다. 공식 고유명사(예: Exusiai the New Covenant)는 치환에서 보호한다. 한국어의 보조 맹약/보조맹약은 부가 맹약으로 통일했다.

[번역 변경 목록](terminology-changes.json)에 283개 사전 항목의 원문·변경 전후·파일을 기록했다. 보조 번역을 다시 생성할 때도 용어 정리 도구를 실행해 같은 문제가 복구되지 않게 했다. 미번역 검사는 품질 전체에 대한 보증이 아니므로, 모든 문장이 자연스럽다고 단정하지는 않는다.

## v0.3.1g 추가 검증

- 돌파는 일반 전장의 플레이어별 추가 HP 차감을 라운드당 10으로 제한한다. 실제 진입과 전투 포기 시 남은 적을 합산하며, 결과 재전송은 중복 차감하지 않는다. 공유 HP에도 같은 상한이 적용되고 연합방어에는 추가 차감하지 않는다. 기존 라운드 종료 HP 정산은 별개다.
- 탐색 숫자의 기존 Bender 지정과 `num` 클래스를 제거하고 Novecento 표시 폰트를 지정했다. Chromium 플랫폼 폰트 조회에서 두 숫자 모두 Novecentowide-Normal, 1600px 화면에서 44px로 실제 적용됨을 확인했다. [실제 렌더링](room-count-font.png).
- 방 참가·관전 여부를 탭 저장소에 기록한다. 새로고침 시 방에 있으면 해당 버전을 유지하고 메인·로비면 최신 버전을 선택한다. 방 초대 링크는 소유 버전을 우선한다. 실제 Chromium에서 두 버전을 활성화하며 검증했다.
- 패치노트와 돌파 힌트의 한국어·영어·일본어·중국어 사전을 갱신하고 언어팩 해시를 재생성했다. 텍스트 커버리지 검사 미해결 항목은 0이다.
