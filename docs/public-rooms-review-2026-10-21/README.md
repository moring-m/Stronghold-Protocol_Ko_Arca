# 공개 방 UI 재검토

## 수정과 평가

- 로비 공개 방 버튼은 다른 시뮬레이션 카드와 같은 배경 레이어, 육각형 아이콘, 영문 소제목, 제목 구조를 사용합니다. 배경·패딩·아이콘 크기/모양·제목 크기·아이콘 상단 위치가 실제 계산 스타일에서 같은지 검증했습니다.
- 방 목록의 난이도 이름은 번역 후 ‘시뮬레이션’을 제거합니다. 번역 전에 한국어 접미어를 제거하던 기존 구현에서는 축약이 작동하지 않아 값이 두 줄이 됐습니다.
- 4개 항목 구분선과 모드/상태별 색은 유지하고, 값은 22px에서 17px, 카드 안쪽 여백은 20px에서 14px로 줄였습니다. 실제 카드 높이는 250px 미만이며 한 줄에 4개를 유지합니다.
- 1600px, 1280px, 390px에서 값이 줄바꿈되거나 가로로 넘치지 않는지 검사했습니다. 1600px에서는 한 줄에 카드가 4개인지 확인했습니다.
- 필터, 자동 갱신, 관전 진입, 공개 전환과 커스텀 비활성화 검증도 통과했습니다.
