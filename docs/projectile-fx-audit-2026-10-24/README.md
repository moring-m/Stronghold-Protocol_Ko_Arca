# 위 특질·기본/스킨 투사체 점검

## 확인 및 수정

| 대상 | 원인 / 확인 내용 | 변경 결과 |
|---|---|---|
| 위 특질의 상점 레벨 제한 | PRTS 및 원본 특질 문구는 `若同一行有3名干员，随机获得1名当前人数最多盟约的干员`이며 상점 레벨 상한이나 연속 배치 조건이 없다. 정예는 행 인원 조건도 없다. | 상점 레벨 제한을 새로 넣지 않았다. 상점 1레벨·띄어진 세 칸에서도 6단계 지급 가능 여부를 테스트했다. |
| 위 보상 미지급 | 기존 행 인원 계산은 빈 칸을 무시하고 같은 행의 오퍼레이터를 모두 세고 있었다. 그러나 인원이 가장 많은 맹약이 비활성화된 맹약이면 공통 추첨 단계가 지급을 막았다. | 위의 인원수 기반 추첨에만 비활성 맹약의 지급 가능 오퍼레이터도 허용한다. 개별 밴·선발 자격·재고 검사는 유지한다. |
| 라플란드 더 데카덴차 스킨 3스킬 | 소환체 전용 계획이 기본 유닛과 기본 투사체를 직접 읽어서 스킨 치환을 건너뛰었다. | 소환체·추적 표식·부착 표식·타격·시작 효과에 설치된 스킨 치환 및 가상 그래픽 투사체를 적용한다. 기본 계획을 변형하지 않으며 스킨 변경 시 기존 소환체 표시를 정리한다. |
| 같은 원인의 다른 스킨 | 골든글로우 3종, 카예라 1종, 미니멀리스트 1종, 록록 1종도 소환체 계획에 치환할 키가 있었다. | 라플란드 포함 7종을 공통 수정으로 처리했다. 정확한 스킨 ID와 변경 키는 아래 JSON에 기록했다. |
| 시빌라이트 에테르나 먼지 | 서버에는 소모·회복·충돌 효과가 있으나 회전 중인 먼지의 표시 상태가 없었다. | 일반/1/2/3스킬의 공식 먼지 투사체를 각각 연결했다. 슬롯별 소모·재생성, 수량, 스킬 전환, 배치 방향, 소유자 이동과 높이를 반영한다. 간소 표시도 추가했다. |
| 리드 더 플레임 섀도우 2스킬 | 화염구 충돌 효과는 연결되어 있으나 아군 주위를 도는 독립 투사체가 없었다. 타격 이벤트도 운반 아군을 원본 시전자로 표시했다. | 화염구 3개가 부여된 아군을 따라가고, 시전자 스킨으로 렌더링한다. 타격의 시전자 식별도 수정했다. 스킬 종료/사망 시 정리한다. |
| 호시구마 이격 2스킬 (`char_1044_hsgma2`) | 실제 회전 방패의 위치는 서버가 계산하나 표시에는 장판/타격 이벤트만 있었다. | 서버가 계산한 실제 회전 위상과 감속된 속도로 공식 방패 투사체를 연결했다. 스킬 종료/사망 시 정리한다. |

## 점검 범위와 검증

- `node tools/audit-projectile-costumes.mjs`: 등록된 오퍼레이터 220개, 기본/설치된 스킨 투사체 참조 1,058건. 참조된 그래픽 키 중 설치된 프리팹이 없는 항목은 0건이다. 이는 전체 투사체를 영상으로 재현했다는 뜻은 아니다.
- `projectiles.json`: 오퍼레이터·스킨별 투사체, 이동 클래스, 주 이펙트, 관련 키와 누락 여부.
- `funnel-skins.json`: 같은 원인으로 영향받는 소환체 스킨 목록(리소스 별칭 포함). `projectiles.json`의 `changedFunnelSkins`는 별칭을 제외한 7종이다.
- 위의 실제 매치 보상 테스트, 먼지 상태의 실제 전투 테스트, 공식 먼지의 스킨·추적·소모·재생성·정리 테스트, 소환체 스킨 회귀 테스트를 실행했다.
- 기존 시빌라이트 에테르나 전투 테스트 3개와 호시구마 S2 전투 테스트 2개는 수정 전 코드로 되돌려 실행해도 같은 실패가 재현된다. 해당 전투 판정 실패를 이번 VFX 수정의 통과 결과에 포함하지 않았다.
- 게임 코드의 커밋·푸시·배포는 수행하지 않았다.
