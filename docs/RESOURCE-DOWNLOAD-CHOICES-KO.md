# 리소스 다운로드 선택

첫 다운로드와 재다운로드는 같은 안내를 사용한다. 음성은 한국어/일본어, 전투 이펙트는 간소/공식을 선택하며 기본은 한국어·간소다. 선택한 파일만 배포용 및 미리보기 워커의 준비 목록에 포함한다. 기존에 저장한 다른 선택의 파일은 지우지 않고 유지한다.

공식 이펙트의 `/assets/local/fx/` 파일은 간소 선택의 사전 다운로드에서 제외한다. 미다운로드 상태에서 설정의 ‘전체’를 누르면 같은 다운로드 안내를 띄우며, 성공적으로 완료한 뒤 전체를 적용한다. 다운로드 실패나 취소 시 완료 표시와 전체 활성화를 하지 않는다. 설정의 간소는 기존 커스텀 전투 이펙트를 사용한다. 자동은 공식 팩 보유 여부와 기기 조건을 따른다.

실제 전투의 공식 이펙트가 활성화되어 있을 때는 커스텀 공격, 피격 불꽃, 스킬 활성화·범위, 공격 영역 이펙트를 함께 그리지 않는다. 피해 수치, SP 회복 수치, 게임 진행 안내 및 적 애니메이션 명령은 유지한다. 설정 전환 시 남아 있던 커스텀 이펙트도 정리한다.

다운로드 선택과 진행 여부는 로컬 저장소에 보관하고 새로고침 후 재개한다. 워커의 완료 표시는 음성·이펙트 선택별로 구분하며, 다른 선택으로 바꿔도 이미 받은 공통 파일은 재사용한다. 저장 공간이 부족해 보일 때는 기존 캐시를 제외한 누락 파일 크기로 다시 검사한다.

접힌 진행도 창은 정수 MB 용량과 아이콘 버튼만 한 줄로 표시한다. 파일 개수, 진행 막대와 상세 내용은 펼쳤을 때 표시한다. 하단의 얇은 진행 바는 유지한다.

아로마의 공식 전방 공격·스킬 스트림은 배치 방향으로 한 타일 앞에서 시작하도록 보정한다. 피격 및 개인 버프의 기준점은 이동하지 않는다. 유닛을 따라가는 이펙트에도 같은 보정을 적용한다.

검증: `test/ui/resource-selection.test.js`, `test/ui/resource-selection-workers.test.js`, `test/ui/resource-redownload.browser.test.js`, 기존 캐시·음성·렌더링 회귀 테스트. 실제 로컬 전장에서도 간소 준비 중 공식 이펙트 파일 요청이 0회이고 전체 선택 시 다운로드 안내가 표시되는 것을 확인했다.
