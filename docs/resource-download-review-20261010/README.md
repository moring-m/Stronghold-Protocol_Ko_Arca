# 리소스 다운로드·이미지 검증 (2026-10-10)

## 확인한 원인과 수정

- 이전 음성 목록의 중국어·일본어 원격 디렉터리 오류는 76011a9에서 수정했다. 일본어 음성 파일명에도 `cn_` 접두사가 있으므로 파일명이 아니라 음성 언어 디렉터리를 기준으로 처리한다. 중국어 음성은 제외한다.
- 실제 추가 음성·스킨·선발 리소스가 예상 용량에 포함되지 않았다. 기존 안내는 383,322,082바이트였지만, 캐시된 모든 파일의 실제 본문은 1,150,816,729바이트였다. 출처가 일치하는 파일별 측정치를 저장하고 빌드 시 합산한다. CacheStorage의 실제 용량 산정은 본문보다 크므로 공간 검사에는 추가 여유를 둔다.
- 저장소 쓰기 실패가 출처 다운로드 실패와 동일하게 처리되어 다른 미러와 재시도를 반복했다. `QuotaExceededError`는 공간 부족으로 표시하고 재시도를 중단한다. 이미 받은 파일은 삭제하지 않는다.
- 모든 출처가 실패했을 때 마지막 오류만 남겨 앞선 HTTP 오류를 알 수 없었다. 출처별 HTTP·시간 초과 원인을 함께 표시한다.
- 의태물질의 세 번째 복사본이 공용 풀 재고를 요구하여 재고 소진 시 다른 오퍼레이터 보상으로 바뀌었다. 복사본 생성은 풀 재고를 요구하지 않도록 수정했다. 정상 병합과 실제 풀 반환량을 검사했다.
- 화면이 1초 이상 지연되면 자동 품질 조절에서 지연을 무시했다. 화면이 보이는 동안의 긴 지연도 반영하고, 숨긴 탭에서 복귀할 때만 시간 기준을 초기화한다. 공격·스킬 타이밍을 줄이지 않는다.

## 실제 다운로드 검증

- 새 Chromium 프로필로 시작, 기존 리소스 캐시 없음.
- 실제 공개 HTTPS 출처에서 16,276개 파일 다운로드 완료. 약 727초 소요. 4,000개 구간도 통과했다.
- 최종 누락 파일 0개, 초상화·아바타 1,386개 브라우저 로딩 성공.
- 50개의 원격 요청은 최초 출처에서 실패했지만 대체 출처 또는 재시도로 복구됐다. 해당 실행의 개별 원격 오류 목록은 테스트 결과 저장 과정의 환경 디스크 부족으로 보존되지 않았다. 각 50건의 HTTP 상태를 확정한 것은 아니다.
- 실행 환경의 Chromium 인증서 설정 제약 때문에 테스트에만 루프백 중계를 사용했다. 중계의 Node HTTPS 요청은 인증서 검증과 환경 프록시를 유지했다. 테스트용 중계는 제품 코드에 포함하지 않았다.

## 회귀 검사와 제한

- 다운로드·용량·자동 품질·의태물질 검사 13개, 실제 브라우저 다운로드 검사 1개, 관련 보상·이미지 회귀 검사 33개: 총 47개 통과, 실패·취소·건너뜀 0개.
- 별도 일반 오퍼레이터 284개 의태물질 병합 검사 통과.
- 전체 테스트 실행은 5,762개 중 5,291개 통과, 444개 실패, 1개 취소, 26개 건너뜀이었다. 전체 테스트 통과를 의미하지 않는다. 기존 공격 타이밍·변경된 콘텐츠 수치 등을 기대하는 검사도 포함되어 있다.
- `map-frame-results.json`은 탐색적 실행이다. 녹화 메타데이터가 강제 맵 선택을 덮어써 모든 맵 검사로 사용할 수 없다. 이 환경은 소프트웨어 GPU이므로 기록된 프레임 수치를 실제 사용자 기기의 성능으로 해석하지 않는다. 협력전의 실제 기기 멈춤이 완전히 해소됐다고 확인한 상태는 아니다.
