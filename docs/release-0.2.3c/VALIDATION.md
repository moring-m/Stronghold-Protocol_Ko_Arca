# 0.2.3c 검증

기준 커밋: 0b5c6ff. 변경 목록은 CHANGELOG.md 및 shared/patchNotes.js의 0.2.3c 항목을 참조합니다.

## 그래프 원인과 수정

전투는 피해 유형별 수치를 집계했지만 server/sim/spec.js의 compactResult가 기존 다섯 지표만 전송하여 물리·마법·고정·원소 피해와 추가 통계가 유실됐습니다. 모든 COMBAT_METRICS를 전송하도록 수정했습니다. 소수 피해도 보존합니다.

실제 전투 결과를 compactResult와 fitResult로 처리한 다음 서버 라운드 기록에 저장해 유형별 수치와 총 피해 일치를 확인했습니다. 이전에 유형이 유실된 저장 기록은 복원할 근거가 없으므로 유형 미기록 피해로 표시합니다. 브라우저에서 유형별 막대와 기존 기록 막대의 너비·높이가 양수임을 확인했습니다. graph-fixed.png는 확인용 데이터를 실제 CombatReport 컴포넌트에 넣은 캡처입니다. 물음표 초상화는 검증용 가상 오퍼레이터 ID입니다.

## 검증 범위

- 전투 통계 및 압축·저장 경로: 7개 통과.
- 운영 카탈로그: 5개 통과. 체력 0.5%, 기존 공격력 기여 비율 10% + 중첩당 0.015%p를 검사합니다.
- 프리셋·우르수스 체력: 32개 통과.
- 비콘 사용 차단·일반 비콘 회귀·맹약 표시 폭: 9개 통과.
- 임시 특질 중복과 이스티나: 9개 통과.
- 투석기 관련: 5개 통과.
- 관전 전환 쿨타임과 투사체 스타일: 4개 통과.
- 맹약 접기: 실제 브라우저에서 높이 0px, 목록 hidden, 펼치기 버튼 visible 확인.
- 이전 협력방어 구조·맵 리소스 수명 검증과 스킨 원격 파일 확인은 인접 검증 문서를 참조합니다.

넓은 범위의 기존 테스트도 실행했습니다. 171개 중 163개 통과, 8개 실패(우르수스 전체 스킬/캐시 로스터·기존 수치 기대값 등). 클라이언트 전투 검사 47개 중 46개 통과, 1개 실패(기존 진행 상태의 resolved:null 필드 기대값 불일치). 적 전체 검사에도 기존 실패가 있습니다. 전체 테스트 통과를 주장하지 않습니다. 수정 대상인 운영 카탈로그의 낡은 밸런스 기대값은 현재 적용값으로 갱신했습니다.
