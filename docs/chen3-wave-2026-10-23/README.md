# 첸 더 던스트릭 3스킬 공식 검기

공식 리소스는 `projectile_chr_chen3_s3`의 `chen3_skill_03_trail_01`에 존재한다. 시뮬레이션은 지형에 부딪혀 방향을 바꾸는 검기를 일반 투사체 스냅샷 대신 `chen3Wave` 이벤트로 보낸다. 공식 렌더러는 이 이벤트를 처리하지 않았고, 공식 모드에서는 기존 간소 qi 효과도 숨겨져 검기가 보이지 않았다.

이벤트 좌표·방향을 추적하는 공식 인스턴스를 연결했다. 갱신마다 새 인스턴스를 만들지 않고 하나를 갱신한다. 이벤트 사이에는 최대 0.12초만 이동을 보간/예측한다. 스킬 종료·퇴각·전장 초기화 시 종료하며, 갱신이 끊기거나 소유자가 사라져도 정리한다. 간소 모드는 기존 효과 경로를 유지한다. 전투 판정과 피해량은 바꾸지 않았다.

`shots/char_1050_chen3-official.png`는 실제 전장 렌더러에서 이벤트를 전달해 촬영한 공식 검기다. 정지 캡처는 전체 스킬 시퀀스나 모든 지형 충돌을 재현한 것은 아니다. 좌표·방향 전환·중복 방지·종료 정리·간소 모드 분기는 `test/render/chen3-official-wave.test.js`로 검증한다.
