# 원본 v0.2.5 맵 비교

## 결론

기존에 추가한 맵과 v0.2.5는 같은 공식 씬을 사용한다. 11개 씬과 11개 조명 데이터 파일은 원본의 고정 리소스 버전과 MD5가 모두 같다. 관련 맵 테마·셰이더 번들까지 포함해 검사한 40개 파일 모두 일치했다. 다른 맵을 가져온 것이 아니라 추출·표현 방식이 달라졌다.

기존 맵 전체를 원본 구현으로 대체하면 8인 연결, 보스 미리보기 공간, 경계 보완과 재질 표현이 바뀐다. 기존 재질과 사용자 지정 배치는 보존하고, 원본의 바이너리 로딩·구역 선택·같은 재질의 메시 병합을 필요한 곳에 도입하는 방식이 적절하다.

## 시각적 비교

`public/dev/map-compare/index.html`의 슬라이더로 도시·사막 × 일반·협력방어·보스의 6쌍을 비교할 수 있다. 동일한 카메라와 1280×800 해상도를 사용했다. 비교용으로 v0.2.5의 BoardScene/재질 코드를 별도로 읽었으며 실제 게임 구현을 전환하지 않았다.

- 기존: 노멀 맵, 금속/광택, 발광 텍스처와 조명 보정이 있어 밝고 입체적으로 보인다. 보스 뒤에 옮겨 둔 미리보기 구역과 연결된 배경을 유지한다.
- 원본: 기본 색상 텍스처와 베이크된 간접광·그림자 마스크를 사용하는 단순한 셰이더다. 도시에서는 더 어둡고 반사가 덜하다. 씬의 `HIDDEN@n` 구역을 필요에 따라 선택한다.
- 원본 구현도 Unity의 게임용 셰이더를 그대로 실행하는 것은 아니다. 두 구현 모두 웹용으로 재현한 재질이다.
- 기존 보스 전장의 추가 배경/미리보기 구역은 원본 씬의 동일 구역에 그대로 있지 않으므로 배경 구성과 지오메트리 수가 다르다.
- 원본은 기본 21열 전장을 사용한다. 기존 8인 협력방어는 37열로 확장하며 원본 메시의 반복·연결·중앙 보완이 필요하다. 원본 맵 로더만으로 8인 전장을 대체할 수 없다.

## 렌더링 구조 비교

아래 값은 동일 카메라에서 지도만 그렸을 때의 Three.js 카운터다. 기물·이펙트·UI는 제외했다. CPU 시간과 FPS는 충분히 안정화된 벤치마크를 실시하지 않아 성능 수치로 제시하지 않는다. 특히 보스·협력방어는 기존 보완 배경의 유무도 호출 수에 영향을 준다.

| 맵 / 구역 | 렌더링 호출: 기존 → 원본 | 삼각형: 기존 → 원본 | GPU 텍스처 객체: 기존 → 원본 |
| --- | --- | --- | --- |
| 도시 / 일반 | 14 → 12 | 61,626 → 79,862 | 22 → 13 |
| 도시 / 협력방어 | 37 → 12 | 91,817 → 86,769 | 22 → 13 |
| 도시 / 보스 | 29 → 12 | 75,871 → 85,775 | 22 → 13 |
| 사막 / 일반 | 23 → 18 | 20,582 → 17,506 | 26 → 23 |
| 사막 / 협력방어 | 68 → 19 | 46,608 → 23,223 | 27 → 24 |
| 사막 / 보스 | 52 → 17 | 35,001 → 27,235 | 26 → 19 |

원본이 모든 조건에서 더 가벼운 것은 아니다. 도시 일반 전투에서는 호출 수가 줄어도 삼각형은 약 30% 늘어난다. 사막 협력방어는 호출 수와 삼각형이 모두 줄어든다.

## 데이터 형식

- 기존: 압축 JSON → 숫자 배열 → 필요한 부분을 자르고 이어서 GPU 지오메트리 생성.
- 원본: `scene.json` + `scene.bin`, 정점의 위치/UV와 8비트 노멀·색상을 TypedArray로 읽는다. 로딩 과정의 숫자 객체 생성과 파싱 비용을 줄일 여지가 있다.
- 바이너리가 다운로드 용량까지 작다는 뜻은 아니다. 지오메트리만 동일 gzip 조건으로 비교하면 도시는 기존 1,590,527 B / 원본 1,829,407 B, 사막은 기존 700,702 B / 원본 841,747 B다. 원본의 별도 scene.json 및 이미지 파일은 이 수치에 포함하지 않았다.

## 검증 범위

- 소스 씬·조명 데이터 22개 및 관련 맵 테마·셰이더 번들을 포함한 40개 파일의 체크섬 비교.
- 도시·사막 6개 구역의 두 구현 실제 렌더링 및 스크린샷 12장.
- 원본 분기에서는 `official` 씬이 사용됐고 기존 분기에서는 기존 네이티브 씬이 사용됐음을 확인했다.
- 비교용 페이지의 6가지 전환과 슬라이더 작동을 확인했다. 렌더러의 context loss나 셰이더 오류는 없었다. 비교 촬영용 임시 빈 페이지의 기본 favicon 요청 1건만 404였다.
- 공장 맵도 추출했지만 로컬 자료에 배경 번들 하나가 없어 시각적 판단 대상에서는 제외했다.
- 기존 게임용 local-assets.json에 원본 씬 그룹을 등록하지 않았다. 운영 서버·기존 맵·커밋 상태는 변경하지 않았다.
