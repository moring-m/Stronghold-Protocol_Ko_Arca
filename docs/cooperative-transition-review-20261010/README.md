# 협력방어 전환·오른쪽 전투 구역 수정

## 전환 시 멈춤

전환할 때 먼저 이전 표시 구역으로 새 전장을 만들고, 카메라 이동용 합집합 구역으로 다시 만들고, 카메라 이동 완료 시 최종 구역으로 다시 만들었다. 메쉬를 모두 폐기하면서 같은 장식의 연결 요소 분석과 경계 자르기도 반복했다.

- 전장과 표시 구역을 한 번에 적용한다. 서로 다른 구조로 전환할 때는 폐기할 임시 합집합 배치를 생성하지 않는다.
- 같은 좌표·인덱스 버퍼의 장식 연결 요소는 재사용한다. 옮기거나 다른 삼각형으로 구성한 버퍼는 별도로 분석한다.
- 범위 밖 삼각형은 속성 복사·보간 전에 제외한다. 경계의 실제 자르기와 텍스처 보간은 유지한다.
- 만들어 둔 전장을 보관하고 재사용한다. 사용 중인 배치를 포함하여 최대 네 가지를 보관하며, 오래된 배치와 종료 시 GPU 자원을 해제한다.
- 구조물은 현재 전투 구역에 맞춰 갱신한다. 동적 장치의 핸들은 유지한다. 각 배치의 조명과 기지·입구 메쉬도 복원한다.

실제 Chromium에서 반복 전환을 측정했다. 수정 전 협력방어 생성은 한 번에 약 5.1~5.7초였고 이를 세 차례 반복했다. 수정 후 첫 생성은 약 2.16초, 같은 전장으로 돌아오는 복원은 약 0.2~0.3ms였다. 첫 생성 비용이 사라진 것은 아니다. 소프트웨어 GPU 환경이므로 사용자 기기의 프레임이나 전체 로딩 시간과 같다고 해석하지 않는다. [측정 기록](transition-results.json)

## 오른쪽 전투 구역

협력방어가 보스전의 구조를 옮겨 쓰면서 오른쪽 전투 구역의 모양까지 반전됐다. 협력방어 오른쪽 구역의 상단 높은 타일과 전투 타일 전체(R8~12, C12~18)는 원본 협력방어 메쉬의 동일 좌표에서 가져온다. 타일 기호가 같더라도 교체하므로 텍스처 방향도 원본을 따른다. 주변 장식 배치는 보스전 외형을 유지한다. 시뮬레이션의 경로·좌표·판정은 변경하지 않는다.

11개 맵의 실제 원본 메쉬를 생성해 오른쪽 구역의 원래 정점 위치와 텍스처 UV가 표시 메쉬에 보존되는지 검사했다. 클리핑이 만드는 경계 정점은 별도의 경계·중복 면 검사가 검증한다. 보스전 맵은 변경하지 않는다.

## 검증

관련 129개 검사 통과. 실패·취소·건너뜀 없음. 메쉬 경계, 겹침 방지, 카메라 투영, 구조물, 캐시 재사용·퇴거·종료 시 자원 해제, 11개 원본 맵의 오른쪽 좌표·UV 검사를 포함한다. 공격·스킬 애니메이션 및 타이밍은 수정하지 않았다.
