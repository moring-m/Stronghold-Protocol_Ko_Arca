# 맹약·범위·타수형 적·인형사 검토

- 맹약 24개를 PC 1280px, 모바일 390px에서 표시해 가로 넘침이 없음을 확인. 한 줄 맞춤과 접기 시 아래쪽 1/3을 남기는 그라데이션 확인.
- 배치/방향/선택 범위와 전투 스킬 타일, 원형 공격 범위 및 보스 직사각형 표시를 실제 전투 구역 기준으로 제한. 카메라 투영 전에 세계 좌표에서 처리.
- 원작 act2autochess `effectBuffInfoDataDict`: `aceffect_enemy_2`, `_2_2`(보급선)는 타수형 기물 14종을 `enemy_exclude`에 포함. `_3`, `_4`, `_5`(공성 장비)는 포함하지 않음. 이에 따라 모든 배율을 무시하던 동작을 수정해 `hpMul / supplyHpMul` 적용. 정수 타수 반올림은 기존 원본 저장소 구현을 유지하며 원작의 소수 처리 방식은 별도로 확정하지 못함.
- 원작 데이터: https://github.com/Kengxxiao/ArknightsGameData/blob/master/zh_CN/gamedata/excel/activity_table.json
- 원작 모드 자료: https://prts.wiki/w/卫戍协议：盟约_下半
- 일반 사망 소환 적 4마리가 연합방어까지 살아남으면 기지 HP 4 차감 확인. 수배 적의 연합방어 사망 소환물은 기존 규칙상 중복 수배/LP 청구 대상에서 제외; 이 예외는 변경하지 않음.
- 인형사: 카제마루·스펙터 디 언체인드 일반/승급, 선택 가능한 스킬·모듈 전체를 순회해 치명타→대역(저지0)→원본 복귀/최대HP 확인. 카제마루 S2 별도 소환 및 S1 자해 전환, 스펙터 S2 종료 전환, 대역 재사망, 관전 초기 모델 형태 검사 통과. 보고된 오류는 재현하지 못해 동작 코드를 임의 변경하지 않음.
- 예전 카제마루 스킬 검사는 배치 다음 프레임에 즉시 공격한다고 가정해 실패했음. 실제 배치/공격 선딜을 기다리도록 검사 변경; 게임의 선딜은 유지.
- 관련 집중 검사 통과. 전체 적/소환물 검사에는 인형사 이외의 공격 타이밍·소환물 수명 등 실패가 남아 있으므로 전체 회귀 검사가 통과했다고 보지는 않음.
