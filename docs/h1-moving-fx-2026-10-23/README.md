# Kit-managed moving visuals

Actual battle-renderer captures; `captures.json` records loaded prefabs and renderer errors (none).

- Ho'olheyak S3: three independently tracked `heyak_skill_03_trail_01` effects; hit/end events stop only the corresponding wind. The kit's real positions and directions drive the visuals.
- Clementia S2: `clemnt_skill_02_buff_01` is the official body effect. The extracted set has no dedicated moving cabin or stationary vortex asset. Those two portions use simplified ground indicators rather than duplicating an unrelated official slash or body buff. Existing official attacks remain enabled.

These are controlled renderer captures, not recordings of a complete match. Simplified captures show the renderer's simplified skill accent, not every event in a complete skill cycle.
