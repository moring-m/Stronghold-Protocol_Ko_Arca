# 점검 안내

서버 컴퓨터에서 명령으로 점검 안내를 띄웁니다. 접속한 모든 사람에게 화면 상단 배너로 보이고, 모든 방의 채팅에 시스템 알림이 올라갑니다.

## 명령

```bash
# 운영 서버(릴리스 게이트웨이): 토큰 파일을 지정하면 게이트웨이(127.0.0.1:3000)를 거쳐 모든 워커에 반영됩니다.
export SP_RELEASE_TOKEN_FILE=/path/to/release-token

node tools/maintenance.mjs --start "2026-11-07 14:00" --end "2026-11-07 15:00" --message "밸런스 업데이트"
node tools/maintenance.mjs --in 30 --for 60      # 30분 뒤 시작, 60분 동안
node tools/maintenance.mjs --status
node tools/maintenance.mjs --clear
```

- 시간대가 없는 시각은 `--tz`(기본 `Asia/Seoul`)로 읽습니다.
- `SP_RELEASE_TOKEN_FILE`이 없으면 단일 서버의 `http://127.0.0.1:$PORT/__maintenance`로 보냅니다. 이 주소는 같은 컴퓨터에서 직접 보낸 요청만 받습니다(터널·프록시를 거친 요청은 거부).
- 다른 주소는 `--url`로 지정합니다.
- 문구(`--message`)는 최대 200자이며 번역되지 않고 그대로 보입니다.

## 동작

- 배너: 점검 전에는 시각과 남은 시간, 점검 중에는 "점검 중"을 표시합니다. 닫을 수 있으며, 안내가 바뀌거나 점검이 시작되면 다시 보입니다. 시각은 각자 브라우저의 시간대로 보입니다.
- 채팅: 시작 30·10·5·1분 전과 시작 시점에 한 번씩 모든 방에 시스템 알림을 남깁니다. 이미 지난 시점의 알림은 보내지 않습니다.
- 점검 종료 시각이 지나면 안내가 자동으로 사라집니다.
- 게이트웨이는 안내를 상태 파일에 저장하고, 나중에 등록되는 워커에도 전달합니다. 워커를 재시작하면 워커의 안내는 사라지므로 다시 설정해야 합니다(게이트웨이를 통해 다시 보내면 됩니다).
- 점검 안내는 알림만 합니다. 서버를 멈추거나 새 게임을 막지는 않습니다.
