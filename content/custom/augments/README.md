# 증강 모드

원본 목록은 `hex.csv`이며 `npm run build:augments`로 런타임 목록을 생성합니다. 현재 95개 원본 항목에서 진영별 지원 증강을 확장합니다.

커스텀 규칙에서 활성화하면 4·7·10라운드에 실버/골드/프리즘을 설정한 가중치 ÷ 총합 확률로 결정합니다(기본 1:2:1, 즉 25/50/25%). 실버가 두 번 연속 등장하면 다음에는 골드/프리즘만 등장합니다. 같은 등급에서 개인 아군 선택(실제 플레이어가 둘 이상이면 60초), 3초 전환, 방장 적 증강 선택(같은 시간제한 규칙), 3초 전환을 진행합니다. 리롤은 아군·적별 설정을 사용하며 기본은 각 선택지당 1회입니다. 등급 가중치와 리롤 설정만 제공하며 개별 증강 등장 설정은 없습니다. 지나간 선택지는 후보가 소진될 때까지 제외합니다. 적 증강은 일반·협력방어·보스·히든 보스 모두에 적용됩니다.

아군 증강은 효과 목록 왼쪽에 별도 아이콘 목록으로 표시되고 적 증강은 게임 정보의 적 증강 탭에 표시됩니다. 선택 내역은 판 기록에 저장됩니다. 맹약 관련 증강은 해당 맹약 아이콘을 사용합니다. 지급 보상은 상점 재고를 소비하지 않으며 공간이 없으면 지급을 보류합니다.

아이콘은 ArknightsAssets2의 위기협약 runeicon 원본을 사용합니다. 고정 커밋·원본 경로·Git blob·SHA256은 `icons.json`에 기록되어 있습니다. `npm run assets:augments`로 검증하며 다시 다운로드할 수 있습니다. 프록시 환경에서는 `NODE_USE_ENV_PROXY=1`을 함께 사용합니다.

검증: 증강·전투·모션·HUD 관련 테스트 130개 통과. 8인 전체 라운드 진행은 테스트용 전투 엔진으로 검증했으며, 실제 브라우저에서는 개인 리롤·선택·3초 전환·방장 선택·효과 목록 표시를 확인했습니다. 화면 예시는 `docs/augment-preview`에 있습니다.

소드마스터는 35% 확률로 연쇄 발동할 수 있으며 추가 공격의 모션 속도는 공격간격 0.1초를 기준으로 합니다. 추가 공격은 원래 공격 대기시간을 초기화하지 않습니다. 조화 지원 증강은 제외하며 장비 지원에는 지급되는 장비 이름과 수량을 표시합니다.

추가 공격은 현재 공격의 전체 후반 모션이 끝난 뒤 시작하며, 연쇄 발동도 이전 추가 공격의 전체 모션 종료 후 진행합니다. 소드마스터 아이콘은 지정된 `g_char_atk_p1.png`를 사용합니다.
