# 누락 기본 FX 추가분

PC 한국 클라이언트에서 추출한 자료 중 기존 공식 묶음에 없는 9명에 필요한 파일만 포함한다. 기존 공식 키는 덮어쓰지 않는다. `supplement.json`이 추가 인덱스·목록·SHA-256을 기록하며, `files/`는 필요한 프리팹·텍스처·메시 264개(약 3.83 MiB)다.

설치는 `node tools/fx-supplement.mjs install`로 수행한다. 원본 공식 묶음 설치 다음에 실행해야 한다. 새 리소스 저장소에 게시한 자료는 아니며 현재 Docker 빌드에서는 서버 정적 파일로 제공한다.
