# 라이타니엔 로컬 실험

기존 운영 데이터는 변경하지 않고 `.cache/leithanien-data`에 별도 카탈로그를 생성합니다. 기존 작업 중인 v0.2.4c 수정 위에서 실행합니다.

```sh
node tools/build-leithanien.mjs
NODE_USE_ENV_PROXY=1 node tools/fetch-leithanien-assets.mjs
NODE_USE_ENV_PROXY=1 node scripts/start-leithanien-local.mjs
```

기본 포트는 3015입니다. `STRONGHOLD_PREVIEW_PORT`로 변경할 수 있습니다. 일반 모드는 커스텀 설정의 **맹약 추가 → 라이타니엔**, 실험실은 전투 준비 전 **커스텀 설정 → 라이타니엔**을 선택합니다. 우르수스와 각각 독립적으로 활성화할 수 있으며, 활성화한 커스텀 핵심 맹약마다 밴 정원이 1개 증가합니다. 기존 핵심 맹약 최소 5개 유지, 밴 제외·강제 밴·비활성화 규칙을 그대로 사용합니다.

장비는 통합전략 소장품 ‘의식용 종’ (`rogue_3_relic_res_9`)과 ‘낡은 악보 조각’ (`rogue_1_relic_r07`)의 이미지를 사용합니다. 효과는 요청한 커스텀 수치이며 원래 소장품 효과와 다릅니다. 승급 특질은 기존 커스텀 규칙처럼 증가량 2배, 발동 횟수 제한 동일로 구성했습니다. 에벤홀츠는 별도 수치로 일반 +1%·승급 +2%를 적용합니다.

속세의 음은 적용 당시 공격력을 저장하고, 1초 후부터 각 중첩의 독립적인 만료 시점까지 매초 피해를 입힙니다. 같은 시점·시전자·대상·지속시간은 합산해 저장하고, 같은 프레임에 발생하는 피해는 시전자·대상별로 합산합니다. 피해 기여는 시전자에게 귀속되며 자체 피해는 다시 속세의 음을 적용하지 않습니다. 6시너지의 적 피해 감소는 곱연산 0.75이며 여러 중첩으로 추가 감소하지 않습니다.

검증:

```sh
node --test test/content/leithanien.test.js test/match/leithanien.test.js
```

대상 체력바 바로 위에 속세의 음 중첩 수를 작은 글씨로 표시합니다. 표시값은 현재 남아 있는 중첩의 합계이며, 각 중첩이 만료되면 감소합니다.

속세의 음 매초 피해는 80 + 시전자 공격력의 1% (맹약 중첩당 +0.01%)이며 같은 오퍼레이터가 같은 적에게 다시 부여하는 대기 시간은 0.1초입니다. 다른 적에 대한 부여는 이 대기 시간을 공유하지 않습니다. 6시너지에서 지속시간은 기본 10초에 25중첩당 1초가 추가됩니다. 중첩 성장 추정은 [BALANCE.md](BALANCE.md)를 참고하세요.

위치킹 NPC 원화: PRTS `文件:Avg avg npc 1116 1-1$1.png` (https://prts.wiki/w/文件:Avg_avg_npc_1116_1-1$1.png). 위키 이미지 다운로드가 실패하여 같은 공식 원화의 ArknightsAssets2 사본을 사용했습니다. 전략 아이콘은 이 NPC 얼굴을 기준으로 카셰이 아이콘의 민트 필터·스캔라인·텍스트 스타일을 적용했습니다.

위치킹의 오퍼레이터 보상은 다음 휴식 기간 진입 시 상점 등급 이하에서 지급하며, 라운드당 1회만 지급합니다. 디아만테 특질은 전투당 최대 5회, 비비아나는 5단계입니다.

비비아나의 속세의 음 부여 특질은 활성화된 라이타니엔/기민 중첩 일반 +2/+1·승급 +4/+2를 지급하며 최대 10회 발동합니다. 속세의 음 피해는 시전자에게 귀속되고 전투 기록의 독립 피해 유형으로 집계됩니다. 적용 중인 적에게 중첩 수와 무관한 라이타니엔 색 효과가 표시됩니다.

속세의 음이 적용된 적에게는 보라색 높은음자리표 이펙트를 표시합니다. 이펙트는 중첩 수와 관계없이 하나만 표시하며 모든 중첩이 만료되면 사라집니다.

레싱은 재배치 시간이 50% 감소하며, 배치 시 활성화된 라이타니엔·기습 맹약의 중첩 수를 각각 일반 +4·승급 +8만큼 늘립니다(전투당 최대 8회).
